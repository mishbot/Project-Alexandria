>[!note] Linear Discriminants
>A **linear discriminant** is a function $g(\mathbf{x}) = \mathbf{w}^T\mathbf{x} + b$ of the input $\mathbf{x} \in \mathbb{R}^d$, with weight vector $\mathbf{w} \in \mathbb{R}^d$ and bias $b \in \mathbb{R}$. A two-class rule assigns $\mathbf{x}$ to class $1$ when $g(\mathbf{x}) > 0$ and to class $0$ when $g(\mathbf{x}) < 0$. The sign of $g$ decides the class. The **decision boundary** is the set $g(\mathbf{x}) = 0$, a $(d-1)$-dimensional hyperplane. Its geometry has three parts:
>
>- **Orientation**: $\mathbf{w}$ is normal to the boundary. Two boundary points $\mathbf{x}_A, \mathbf{x}_B$ satisfy $g(\mathbf{x}_A) = g(\mathbf{x}_B) = 0$, so $\mathbf{w}^T(\mathbf{x}_A - \mathbf{x}_B) = 0$.
>- **Signed distance**: a point $\mathbf{x}$ lies at signed distance $r(\mathbf{x}) = g(\mathbf{x})/\|\mathbf{w}\|$ from the boundary. It is positive on the class-$1$ side, the side $\mathbf{w}$ points to.
>- **Offset**: the origin has $g(\mathbf{0}) = b$, so the boundary lies at distance $|b|/\|\mathbf{w}\|$ from the origin. For a fixed $\mathbf{w}$, changing $b$ shifts the boundary parallel to itself.
>
>With $K$ classes, there are three common constructions (Bishop, *PRML*, sec. 4.1.2):
>
>- **$K$ discriminants with argmax**: each class gets $g_k(\mathbf{x}) = \mathbf{w}_k^T\mathbf{x} + b_k$, and the rule predicts $\arg\max_k g_k(\mathbf{x})$. Classes $k$ and $j$ meet on the hyperplane $(\mathbf{w}_k - \mathbf{w}_j)^T\mathbf{x} + (b_k - b_j) = 0$. Every decision region is convex.
>- **One-vs-rest**: $K$ binary classifiers each separate one class from all others. Some inputs are claimed by two classes or by none.
>- **One-vs-one**: $K(K-1)/2$ binary classifiers each separate a pair of classes and then vote. Some inputs end in a tied vote.
>
>**Linear discriminant analysis** (LDA) obtains $g$ from the [[4.1. Bayes Classifier|Bayes classifier]]. It assumes Gaussian classes with a shared covariance, $\mathbf{x} \mid y = k \sim \mathcal{N}(\boldsymbol\mu_k, \boldsymbol\Sigma)$, with priors $\pi_k$. For two classes the posterior log-odds are then linear in $\mathbf{x}$, with
>$$\mathbf{w} = \boldsymbol\Sigma^{-1}(\boldsymbol\mu_1 - \boldsymbol\mu_0), \qquad b = -\tfrac{1}{2}\boldsymbol\mu_1^T\boldsymbol\Sigma^{-1}\boldsymbol\mu_1 + \tfrac{1}{2}\boldsymbol\mu_0^T\boldsymbol\Sigma^{-1}\boldsymbol\mu_0 + \log\frac{\pi_1}{\pi_0}.$$
>Here $\boldsymbol\mu_k$ is the mean of class $k$ and $\boldsymbol\Sigma$ is the shared covariance. In practice $\pi_k = n_k/n$, and $\boldsymbol\mu_k$ is the sample mean of the $n_k$ points in class $k$. The estimate of $\boldsymbol\Sigma$ is the pooled within-class covariance. With $K$ classes, LDA predicts the class with the largest score
>$$\delta_k(\mathbf{x}) = \mathbf{x}^T\boldsymbol\Sigma^{-1}\boldsymbol\mu_k - \tfrac{1}{2}\boldsymbol\mu_k^T\boldsymbol\Sigma^{-1}\boldsymbol\mu_k + \log \pi_k,$$
>which is linear in $\mathbf{x}$. **Quadratic discriminant analysis** (QDA) gives each class its own covariance $\boldsymbol\Sigma_k$. Its score
>$$\delta_k(\mathbf{x}) = -\tfrac{1}{2}\log|\boldsymbol\Sigma_k| - \tfrac{1}{2}(\mathbf{x} - \boldsymbol\mu_k)^T\boldsymbol\Sigma_k^{-1}(\mathbf{x} - \boldsymbol\mu_k) + \log \pi_k$$
>is quadratic in $\mathbf{x}$, where $|\boldsymbol\Sigma_k|$ is the determinant, so QDA boundaries are curved.
>
>**Fisher's linear discriminant** drops the Gaussian assumption. It picks the direction along which the projected class means are far apart compared with the spread within each class:
>$$J(\mathbf{w}) = \frac{\big(\mathbf{w}^T(\mathbf{m}_1 - \mathbf{m}_0)\big)^2}{\mathbf{w}^T\mathbf{S}_W\mathbf{w}}, \qquad \mathbf{w}^* \propto \mathbf{S}_W^{-1}(\mathbf{m}_1 - \mathbf{m}_0).$$
>Here $\mathbf{m}_k$ are the class sample means and $\mathbf{S}_W = \sum_k \sum_{i : y_i = k}(\mathbf{x}_i - \mathbf{m}_k)(\mathbf{x}_i - \mathbf{m}_k)^T$ is the within-class scatter matrix. This is the LDA direction. Fisher's criterion fixes only the direction, so the threshold $b$ is chosen separately. Other linear classifiers fit $\mathbf{w}$ and $b$ by other criteria: the [[1. Perceptrons|perceptron]], [[4.3. Logistic Regression|logistic regression]] and [[4.4. Support Vector Machines|support vector machines]].

# Intuition

A discriminant is a function that tells classes apart. A linear one computes a weighted sum of the features plus a constant. The weighted sum $\mathbf{w}^T\mathbf{x}$ measures how far the input lies along the direction $\mathbf{w}$. The bias sets the cut-off on that scale. All inputs on one side of the cut-off get the same class. The boundary is therefore a flat hyperplane perpendicular to $\mathbf{w}$.

Linear discriminants differ in how they choose $\mathbf{w}$ and $b$. LDA assumes Gaussian classes with a shared covariance and reads the boundary off Bayes' rule. Fisher's method searches for the direction along which the projected classes sit farthest apart relative to their spread. Both reach the same direction, $\boldsymbol\Sigma^{-1}(\boldsymbol\mu_1 - \boldsymbol\mu_0)$. The raw mean difference $\boldsymbol\mu_1 - \boldsymbol\mu_0$ points from one class center to the other. The inverse covariance tilts it away from directions where the classes are noisy.

The gray plane shows $g(\mathbf{x})$ above every input. The boundary is the line where the plane crosses zero. The distance to the boundary is $g(\mathbf{x})/\|\mathbf{w}\|$, which differs from $g(\mathbf{x})$ when $\|\mathbf{w}\| \ne 1$.

# Properties

#### *(Convex Regions)* The argmax rule cannot capture a class whose points form two separate clusters.

Take two points $\mathbf{x}_A, \mathbf{x}_B$ in region $\mathcal{R}_k$ and any point $\mathbf{x} = \lambda\mathbf{x}_A + (1-\lambda)\mathbf{x}_B$ between them, with $0 \le \lambda \le 1$. Linearity gives $g_k(\mathbf{x}) = \lambda g_k(\mathbf{x}_A) + (1-\lambda) g_k(\mathbf{x}_B)$, and the same holds for every $g_j$. Since $g_k > g_j$ at both endpoints, $g_k(\mathbf{x}) > g_j(\mathbf{x})$, so $\mathbf{x}$ is in $\mathcal{R}_k$ too. Each region is therefore one convex piece, with none of the gaps of one-vs-rest. It also means no linear discriminant can solve XOR-type data, where one class occupies two opposite corners. Nonlinear features or a nonlinear model are then needed, as in [[4.4b. Kernel SVM|kernel SVMs]] or [[2. Neural Networks|neural networks]].

#### *(Nearest Mean in Mahalanobis Distance)* LDA assigns each input to the closest class mean, measured in the metric of the shared covariance.

Adding the term $-\tfrac{1}{2}\mathbf{x}^T\boldsymbol\Sigma^{-1}\mathbf{x}$, which is the same for every class, turns $\delta_k$ into $-\tfrac{1}{2}(\mathbf{x} - \boldsymbol\mu_k)^T\boldsymbol\Sigma^{-1}(\mathbf{x} - \boldsymbol\mu_k) + \log\pi_k$. The quadratic form is the squared **Mahalanobis distance**, a distance that counts steps in units of the class spread. With $\boldsymbol\Sigma = \sigma^2\mathbf{I}$ and equal priors, LDA reduces to nearest-centroid classification in ordinary distance. The Mahalanobis distance between the two means, $\Delta = \sqrt{(\boldsymbol\mu_1 - \boldsymbol\mu_0)^T\boldsymbol\Sigma^{-1}(\boldsymbol\mu_1 - \boldsymbol\mu_0)}$, sets the difficulty. With equal priors the Bayes error is $\Phi(-\Delta/2)$, where $\Phi$ is the standard normal CDF.

#### *(LDA Versus Logistic Regression)* LDA and logistic regression produce the same linear log-odds but estimate them differently.

LDA fits the joint distribution of $\mathbf{x}$ and $y$ by Gaussian maximum likelihood. Logistic regression fits only the conditional distribution of $y$ given $\mathbf{x}$. When the classes are Gaussian, LDA uses that extra information and has lower variance. Efron (1975) measured the cost of ignoring that information, as quoted in ESL (sec. 4.4.5). In the worst case, logistic regression loses about 30% efficiency in error rate, asymptotically. LDA estimates its means and covariance from every point, including points far from the boundary. Outliers and heavy-tailed classes therefore pull LDA's boundary, while logistic regression mostly ignores well-classified points. LDA also has a closed form and stays finite on separable data, where unregularized logistic regression diverges.

#### *(QDA Needs More Data)* QDA estimates $K$ covariance matrices instead of one, which multiplies its covariance parameters by $K$.

A $d \times d$ covariance has $d(d+1)/2$ free entries. With $d = 50$ and $K = 3$, LDA estimates $1275$ covariance entries and QDA estimates $3825$. When a class has $n_k \le d$ points, its sample covariance is singular, and QDA cannot invert it. **Regularized discriminant analysis** (Friedman 1989; ESL sec. 4.3.1) blends the two models with $\boldsymbol\Sigma_k(\alpha) = \alpha\boldsymbol\Sigma_k + (1-\alpha)\boldsymbol\Sigma$. [[2.3.2. Cross-Validation|Cross-validation]] chooses $\alpha \in [0, 1]$. The blend trades QDA's flexibility against LDA's lower variance, as described in [[2.3.1. Bias-Variance Decomposition]].

#### *(At Most $K - 1$ Directions)* With $K$ classes, Fisher's criterion yields at most $\min(K-1, d)$ useful projection directions.

The multi-class version replaces the squared mean difference with the between-class scatter $\mathbf{S}_B = \sum_k n_k(\mathbf{m}_k - \mathbf{m})(\mathbf{m}_k - \mathbf{m})^T$, where $\mathbf{m}$ is the overall mean. The $K$ centered means sum to zero after weighting, so $\mathbf{S}_B$ has rank at most $K-1$. The useful directions are the top eigenvectors of $\mathbf{S}_W^{-1}\mathbf{S}_B$. Ten digit classes thus give at most nine directions, whatever the number of pixels. Projecting onto them is called reduced-rank LDA. It is a supervised alternative to [[7.1. Principal Component Analysis|PCA]], which ignores the labels.

# Derivation

We want to show that Gaussian classes with a shared covariance give linear log-odds. The Gaussian density of class $k$ is proportional to $\exp\!\big(-\tfrac{1}{2}(\mathbf{x} - \boldsymbol\mu_k)^T\boldsymbol\Sigma^{-1}(\mathbf{x} - \boldsymbol\mu_k)\big)$, and the normalizing constant is the same for both classes. Bayes' rule gives the log-odds
$$\log\frac{\mathbb{P}(y = 1 \mid \mathbf{x})}{\mathbb{P}(y = 0 \mid \mathbf{x})} = -\tfrac{1}{2}(\mathbf{x} - \boldsymbol\mu_1)^T\boldsymbol\Sigma^{-1}(\mathbf{x} - \boldsymbol\mu_1) + \tfrac{1}{2}(\mathbf{x} - \boldsymbol\mu_0)^T\boldsymbol\Sigma^{-1}(\mathbf{x} - \boldsymbol\mu_0) + \log\frac{\pi_1}{\pi_0}.$$
Expanding both quadratic forms, the terms $\mathbf{x}^T\boldsymbol\Sigma^{-1}\mathbf{x}$ cancel. The cross terms give $\mathbf{x}^T\boldsymbol\Sigma^{-1}(\boldsymbol\mu_1 - \boldsymbol\mu_0)$, using the symmetry of $\boldsymbol\Sigma^{-1}$. The rest are constants, which form $b$. So the log-odds equal $\mathbf{w}^T\mathbf{x} + b$ with the $\mathbf{w}$ and $b$ of the callout, and $\mathbb{P}(y = 1 \mid \mathbf{x}) = \sigma(\mathbf{w}^T\mathbf{x} + b)$ with the sigmoid $\sigma(z) = 1/(1 + e^{-z})$. With separate covariances the $\mathbf{x}^T\boldsymbol\Sigma_k^{-1}\mathbf{x}$ terms no longer cancel, which gives QDA.

For Fisher's criterion, write the numerator as $\mathbf{w}^T\mathbf{S}_B\mathbf{w}$ with $\mathbf{S}_B = (\mathbf{m}_1 - \mathbf{m}_0)(\mathbf{m}_1 - \mathbf{m}_0)^T$. Setting the gradient of the ratio to zero gives
$$(\mathbf{w}^T\mathbf{S}_B\mathbf{w})\,\mathbf{S}_W\mathbf{w} = (\mathbf{w}^T\mathbf{S}_W\mathbf{w})\,\mathbf{S}_B\mathbf{w}.$$
The vector $\mathbf{S}_B\mathbf{w}$ equals $(\mathbf{m}_1 - \mathbf{m}_0)$ times the scalar $(\mathbf{m}_1 - \mathbf{m}_0)^T\mathbf{w}$. Dropping all scalars, $\mathbf{S}_W\mathbf{w} \propto \mathbf{m}_1 - \mathbf{m}_0$, so $\mathbf{w} \propto \mathbf{S}_W^{-1}(\mathbf{m}_1 - \mathbf{m}_0)$. The scatter $\mathbf{S}_W$ is $n - 2$ times the pooled covariance, so this is the LDA direction.

# Examples

>[!example] (Easy) How Far From Approval
>A bank scores loan applicants with $g(\mathbf{x}) = 2x_1 + x_2 - 10$. Here $x_1$ is income in tens of thousands of dollars and $x_2$ is years at the current job. A positive score means approval. One applicant has $\mathbf{x} = (3, 2)$.
>
>>[!example]- Is the applicant approved? How far are they from the boundary, and which boundary point is nearest?
>>The score is $g = 6 + 2 - 10 = -2$, so the loan is declined. With $\|\mathbf{w}\| = \sqrt{5} = 2.236$, the signed distance is $-2/\sqrt{5} = -0.894$. The nearest boundary point lies along $\mathbf{w}$, at $\mathbf{x} - (g/\|\mathbf{w}\|^2)\,\mathbf{w} = (3, 2) + 0.4\,(2, 1) = (3.8, 2.4)$. A check gives $g(3.8, 2.4) = 7.6 + 2.4 - 10 = 0$. The cheapest change in this metric is $\$8000$ more income and $0.4$ more years on the job. The boundary sits $|b|/\|\mathbf{w}\| = 10/\sqrt{5} = 4.472$ from the origin.

>[!example] (Medium) A Hot Day Explains Some Vibration
>A plant monitors pumps with two standardized sensors, vibration $x_1$ and motor temperature $x_2$. Hot days raise both readings, so they are correlated within each class. Healthy pumps (class $0$) have mean $\boldsymbol\mu_0 = (1, 2)$, and faulty pumps (class $1$) have mean $\boldsymbol\mu_1 = (3, 2)$. Both classes share
>$$\boldsymbol\Sigma = \begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix},$$
>and half the pumps are faulty.
>
>>[!example]- Find the LDA discriminant and classify a pump reading $\mathbf{x} = (2.5, 3.5)$.
>>The inverse is $\boldsymbol\Sigma^{-1} = \tfrac{1}{3}\begin{bmatrix} 2 & -1 \\ -1 & 2 \end{bmatrix}$. The weights are $\mathbf{w} = \boldsymbol\Sigma^{-1}(2, 0) = (4/3, -2/3)$. The quadratic forms are $\boldsymbol\mu_1^T\boldsymbol\Sigma^{-1}\boldsymbol\mu_1 = 14/3$ and $\boldsymbol\mu_0^T\boldsymbol\Sigma^{-1}\boldsymbol\mu_0 = 2$, so $b = -7/3 + 1 + 0 = -4/3$. For the new pump, $g = 10/3 - 7/3 - 4/3 = -1/3$, so LDA calls it healthy, with $\mathbb{P}(\text{faulty} \mid \mathbf{x}) = \sigma(-1/3) = 0.417$. Its vibration of $2.5$ is closer to the faulty mean. Temperature gets a negative weight even though both classes have the same mean temperature. A hot reading signals a hot day, which explains part of the high vibration.

>[!example] (Hard) Vibration Alone Versus Fisher's Direction
>An engineer for the same plant proposes to ignore temperature and threshold vibration alone, at its midpoint between the two class means.
>
>>[!example]- Compare the error rate of this rule with that of LDA.
>>A projection $v = \mathbf{u}^T\mathbf{x}$ onto any direction $\mathbf{u}$ is Gaussian in each class, with variance $\mathbf{u}^T\boldsymbol\Sigma\mathbf{u}$. The means then sit $\sqrt{J(\mathbf{u})}$ standard deviations apart. A midpoint threshold errs with probability $\Phi(-\sqrt{J}/2)$ in each class. Vibration alone uses $\mathbf{u} = (1, 0)$, so $J = 2^2/2 = 2$, and the error is $\Phi(-0.707) = 0.240$. Fisher's direction $(2, -1)$ has $\mathbf{u}^T\boldsymbol\Sigma\mathbf{u} = 6$, so $J = 4^2/6 = 8/3$. Its error is $\Phi(-0.816) = 0.207$, the Bayes error $\Phi(-\Delta/2)$ with $\Delta^2 = 8/3$. Adding the two sensors, $\mathbf{u} = (1, 1)$, does worst, with $J = 2/3$ and error $0.342$. Temperature alone carries no class information. Used with the right sign, it still cuts the error from $24.0\%$ to $20.7\%$.
