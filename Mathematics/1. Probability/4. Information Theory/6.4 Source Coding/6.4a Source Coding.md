>[!note] Source Coding
>**Source coding** is the process of encoding *purely random* information from the symbols $x \in \mathcal{X}$ into a bit string representation that uses the most compressed sequence of bits for which it is possible to recover the symbols.
>
>Source coding is governed by the **Source Coding Theorem**, which states that any source coding scheme must use, on average, at least as many bits per symbol as the [[6.1 Entropy|entropy]] of the source, ensuring that the encoded message retains all the original information. 
>
>Mathematically, for a sequence of symbols $X_{1}, X_{2}, \ldots, X_{n}$ with a R.V. binary length $l(X)$, and an arbitrarily small $\epsilon > 0$, there is a source coding scheme from which the sequence can be recovered with high probability (i.e. $p > 1-\epsilon$), such that
>$$H(X) \leq \lim_{ n \to \infty }\mathbb{E}\left[ \frac{l(X_{1}, \ldots, X_{n})}{n} \right] \leq H(X) + \epsilon,$$
>where $\frac{l(X_{1}, \ldots, X_{n})}{n}$ represents the average bits per symbol of the sequence.
