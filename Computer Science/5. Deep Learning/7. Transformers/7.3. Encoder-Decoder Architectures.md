>[!note] Encoder-Decoder Transformer Architectures
>Transformers are built from two fundamental computational blocks called **encoders** and **decoders**, which can be composed in different ways to produce distinct model families. These blocks differ in their attention structure and the type of information they are designed to model.
>
>An **encoder** is a stack of transformer layers that applies **bidirectional self-attention** to an input sequence. Given embeddings $X = [x_1,\ldots,x_N] \in \mathbb{R}^{N \times d},$ an encoder layer computes
>$$\begin{aligned} Z &= X + \mathrm{MHSA}(X), \\ H &= Z + \mathrm{FFN}(Z), \end{aligned}$$
>with layer normalization applied around each block. Encoders learn **bidirectional**, content-dependent representations of the entire input $H=[h_{1}, \ldots, h_{N}]$. They are not autoregressive and do not generate tokens.
>
>A **decoder** is a transformer stack designed for **auto-regressive generation**, using **masked self-attention** so that each position only attends to earlier ones, such that $\alpha_{mn} = 0$ for all tokens $m > n$ (implemented by adding $-\infty$ to the logits above the diagonal before softmax). Masked self-attention ensures that the decoder does not "cheat" during training by peeking into future tokens. Given a partially generated sequence $Y = [y_1,\dots,y_{t-1}]$, a decoder layer computes
>$$\begin{aligned} Z_1 &= Y + \mathrm{MHSA}(Y),\\ Z_2 &= Z_1 + \mathrm{CA}(Z_1, H_{\text{enc}}),\\U &= Z_2 + \mathrm{FFN}(Z_2), \end{aligned}$$
>where $\mathrm{CA}(\cdot)$ is **cross-attention**, which conditions the decoder on the encoder's output. In cross-attention, queries come from the decoder while keys and values come from the encoder:
>$$\mathbf{q}_i = \mathbf{x}_i\mathbf{W}^Q,\quad i = 1, \dots, n \quad\text{(from decoder hidden states)},$$
>$$\mathbf{k}_j = \tilde{\mathbf{x}}_j\mathbf{W}^K,\quad \mathbf{v}_j = \tilde{\mathbf{x}}_j\mathbf{W}^V,\quad j = 1, \dots, m \quad\text{(from encoder hidden states)},$$
>where $\tilde{\mathbf{x}}_1, \dots, \tilde{\mathbf{x}}_m$ are the top-layer encoder outputs and $\mathbf{x}_1, \dots, \mathbf{x}_n$ are the current decoder hidden states. The attention scores and output follow the same scaled dot-product formula as self-attention, but over an $n \times m$ (decoder-by-encoder) matrix rather than $n \times n$. Cross-attention is the **only component** where the input and output sequences interact. LayerNorm is applied around each block.
>
>Encoders and decoders can be used in tandem to design different transformer model families:
>- **Autoencoding Transformers** consist of **only an encoder** and learn contextual representations through reconstruction or denoising objectives, such as
>$$\mathcal{L}_{\text{AE}} = - \sum_{t \in M} \log p_\theta(x_t \mid x_{\setminus M}).$$
>- **Autoregressive Transformers** consist of **only a decoder** with masked self-attention. The mask ensures a strict left-to-right factorization; cross-attention is absent. The model is fully generative (e.g., GPT, Mistral, LLaMA).
>- **Sequence-to-Sequence (Seq2Seq) Transformers** combine an encoder and a decoder. The encoder produces contextual representations H; the decoder autoregressively generates $y_t$ while attending to $H$ via cross-attention. This provides a clean separation between _understanding_ the input and _generating_ the output. The model is also fully generative (e.g., T5, BART, original transformer).
