>[!note] Bayesian Poisson Regression
>The **Bayesian Poisson regression** model (also called **log-linear** model) is
>$$y_i \mid \boldsymbol\beta, \mathbf{x}_i \;\sim\; \text{Poisson}(\exp(\mathbf{x}_i^\top \boldsymbol\beta)), \qquad \boldsymbol\beta \sim N(\boldsymbol\beta_0, \boldsymbol\Sigma_0).$$
>The log-link forces $\lambda_i = \exp(\mathbf{x}_i^\top \boldsymbol\beta) > 0$. The likelihood is
>$$p(\mathbf{y} \mid \boldsymbol\beta) = \prod_{i=1}^n \frac{e^{-\lambda_i}\lambda_i^{y_i}}{y_i!}, \qquad \log p(\mathbf{y} \mid \boldsymbol\beta) = \sum_i [y_i\, \mathbf{x}_i^\top \boldsymbol\beta - \exp(\mathbf{x}_i^\top \boldsymbol\beta)] + \text{const}.$$
>Like logistic regression, the Poisson likelihood is not conjugate to any standard prior on $\boldsymbol\beta$; inference uses the [[3.9 Laplace Approximation|Laplace approximation]] or MCMC.
>
>**MAP via Newton (IRLS analog).** The log-posterior is concave in $\boldsymbol\beta$. The gradient and Hessian are
>$$\nabla \log p(\boldsymbol\beta \mid \mathbf{y}) = \mathbf{X}^\top(\mathbf{y} - \boldsymbol\lambda(\boldsymbol\beta)) - \boldsymbol\Sigma_0^{-1}(\boldsymbol\beta - \boldsymbol\beta_0),$$
>$$-\nabla^2 \log p(\boldsymbol\beta \mid \mathbf{y}) = \mathbf{X}^\top \operatorname{diag}(\boldsymbol\lambda(\boldsymbol\beta))\mathbf{X} + \boldsymbol\Sigma_0^{-1}.$$
>Newton's method converges quadratically, giving the MAP $\hat{\boldsymbol\beta}$ and the Laplace-posterior covariance $\boldsymbol\Sigma_{\text{Lap}} = (\mathbf{X}^\top \operatorname{diag}(\hat{\boldsymbol\lambda})\mathbf{X} + \boldsymbol\Sigma_0^{-1})^{-1}$.
>
>**Laplace approximation:** $p(\boldsymbol\beta \mid \mathbf{y}) \approx N(\hat{\boldsymbol\beta}, \boldsymbol\Sigma_{\text{Lap}})$. This Gaussian serves equally well as an approximate posterior summary or as a **proposal distribution for Metropolis-Hastings** when Laplace's accuracy is insufficient — see [[3.11.1 Metropolis-Hastings]].
>
>**Posterior predictive** for a new input $\mathbf{x}_\star$: conditional on $\boldsymbol\beta$, $\tilde y_\star \sim \text{Poisson}(\exp(\mathbf{x}_\star^\top \boldsymbol\beta))$; marginally $\tilde y_\star \mid \mathbf{y}$ is a Poisson-lognormal mixture. A useful approximation uses a Gamma-Poisson ([[3.5.3 Gamma-Poisson Model|Gamma-Poisson]]) matching: moment-match $\exp(\mathbf{x}_\star^\top \boldsymbol\beta)$ to a Gamma distribution, yielding a Negative-Binomial predictive with explicit overdispersion.
>
>**Overdispersion caveat.** Real count data typically have $\operatorname{Var}(y) > \mathbb{E}(y)$, violating the Poisson equidispersion assumption. Bayesian remedies: (a) add an observation-level random effect $\eta_i \sim N(0, \tau^2)$ so that $y_i \sim \text{Poisson}(\exp(\mathbf{x}_i^\top \boldsymbol\beta + \eta_i))$ — the **log-normal Poisson** model; (b) replace Poisson with Negative Binomial (arising as a Gamma-Poisson mixture over $\lambda_i$) at the likelihood level. Both remove the rigid mean-variance coupling.

# Intuition

Poisson regression models the log of the rate as a linear function of covariates: each unit increase in $x_j$ multiplies the rate by $e^{\beta_j}$. The log link ensures positivity without constraint, at the cost of breaking conjugacy with Gaussian priors on $\boldsymbol\beta$. The log-posterior is the sum of a Poisson log-likelihood (strictly concave in $\boldsymbol\beta$) and a Gaussian log-prior (quadratic), so the posterior is globally log-concave with a unique maximum — ideal for Laplace approximation.

The concavity makes Newton's method converge quickly from any reasonable starting point. Each Newton step reweights observations by $\lambda_i = e^{\mathbf{x}_i^\top \boldsymbol\beta_k}$: observations with high predicted rate carry proportionally more weight, mirroring the Fisher information of a Poisson variate (whose variance equals its mean). The Bayesian addition is the regularization term $\boldsymbol\Sigma_0^{-1}$, which guarantees invertibility of the Newton step even when the data are sparse or the design matrix is rank-deficient.

The overdispersion problem is the elephant in the Poisson room. Empirical count data almost always have variance-to-mean ratios well above 1, and fitting Poisson regression to them produces posterior intervals that are too narrow. The cleanest fix is a log-normal random effect per observation — which, integrated out, gives a log-normal-Poisson mixture with adjustable overdispersion. Bayesian software handles this naturally because the random effect fits into the hierarchical-model framework ([[3.6 Hierarchical Models]]) and the Laplace approximation extends straightforwardly.

# Properties

#### *(Log-Link Forces Positive Rates)* $\lambda_i = \exp(\mathbf{x}_i^\top \boldsymbol\beta) > 0$ for every $\boldsymbol\beta$.

This sidesteps any positivity constraint on the linear predictor but means that coefficients are interpreted multiplicatively: $e^{\beta_j}$ is the **rate ratio** for a unit increase in $x_j$. A posterior credible interval for $\beta_j$ translates to a credible interval for the rate ratio via exponentiation.

#### *(Log-Posterior is Strictly Concave)* The MAP is unique and globally optimal.

The Hessian $-\nabla^2 \log p(\boldsymbol\beta \mid \mathbf{y}) = \mathbf{X}^\top \operatorname{diag}(\boldsymbol\lambda)\mathbf{X} + \boldsymbol\Sigma_0^{-1}$ is positive definite (positive semi-definite first term, positive definite second term), so the log-posterior is strictly concave. Newton's method converges quadratically to the MAP from any reasonable starting point. The prior-precision term is what rescues the non-informative case: the raw Poisson likelihood alone can have a non-strictly-concave posterior if the design has linear dependence.

#### *(Laplace as MH Proposal)* The Laplace Gaussian is a standard Metropolis-Hastings proposal distribution.

When full MH is required (e.g., with non-Gaussian priors or skewed posteriors), the proposal $N(\hat{\boldsymbol\beta}, c^2 \boldsymbol\Sigma_{\text{Lap}})$ with $c^2 = 2.38^2/d$ (Roberts-Gelman-Gilks optimal scaling for random-walk MH targeting a Gaussian) gives high acceptance rates in practice. This combines Laplace's locality with MH's exactness: if the true posterior *is* nearly Gaussian, the proposal is near-perfect; if it deviates, MH corrects. See [[3.11.1 Metropolis-Hastings]].

#### *(Offset Terms Handle Exposure)* Known exposures $t_i$ enter as offsets in the linear predictor.

If observation $i$ is a count over exposure $t_i$ (time, area, population at risk), the model becomes $y_i \sim \text{Poisson}(t_i \exp(\mathbf{x}_i^\top \boldsymbol\beta))$. Equivalently, a fixed term $\log t_i$ is added to the linear predictor:
$$\log \lambda_i = \log t_i + \mathbf{x}_i^\top \boldsymbol\beta.$$
This **offset** carries no coefficient — its effect is fixed to 1. Bayesian and frequentist software support this as standard; the posterior structure on $\boldsymbol\beta$ is unchanged.

#### *(Overdispersion Diagnostic)* A log-normal-Poisson or Negative-Binomial extension fixes equidispersion failures.

If Pearson residuals from the fitted Poisson model have variance $\gg 1$, the data are overdispersed. Two Bayesian extensions:
- **Log-normal Poisson:** $\eta_i \sim N(0, \tau^2)$ with $y_i \sim \text{Poisson}(\exp(\mathbf{x}_i^\top \boldsymbol\beta + \eta_i))$. Integrating out $\eta_i$ gives a log-normal-Poisson marginal with unbounded dispersion; fit by Laplace or MCMC.
- **Negative-Binomial:** $\lambda_i \sim \text{Gamma}(r, r/\mu_i)$ with $y_i \sim \text{Poisson}(\lambda_i)$, integrating to $y_i \sim \text{NegBin}(r, \mu_i)$. Fit by MCMC; $r$ is a learned overdispersion parameter.
The log-normal version fits naturally into the [[3.6 Hierarchical Models|hierarchical-models]] framework and is the default in Bayesian GLMM software.

#### *(Evidence for Model Comparison)* Laplace approximation gives closed-form log-marginal-likelihood.

$$\log p(\mathbf{y}) \;\approx\; \log p(\mathbf{y} \mid \hat{\boldsymbol\beta}) + \log p(\hat{\boldsymbol\beta}) + \tfrac{d}{2}\log(2\pi) - \tfrac{1}{2}\log |\mathbf{X}^\top \operatorname{diag}(\hat{\boldsymbol\lambda})\mathbf{X} + \boldsymbol\Sigma_0^{-1}|.$$
This enables Bayes-factor-based model selection and evidence-tuned prior precisions; see [[3.7 Marginal Likelihood]]. The asymptotic BIC surrogate drops the prior-density term and uses $\log n$ in place of the Hessian log-determinant.

#### *(Sparse Counts Require Informative Priors)* When most $y_i = 0$, flat priors lead to unstable estimates.

In sparse count data (e.g., rare disease incidence), the MLE can be extreme or undefined for covariate levels that appear only with $y_i = 0$. A weakly informative prior (e.g., $\boldsymbol\beta \sim N(\mathbf{0}, 2.5^2 \mathbf{I})$ on standardized covariates) stabilizes the MAP and preserves sensible credible intervals. This is the count-data analog of logistic regression's separability problem.

# Examples

>[!example]- Example 1: Single-Covariate Poisson Regression
>Data $\{(x_i, y_i)\}_{i=1}^{50}$ with $x_i \sim N(0, 1)$ and $y_i \sim \text{Poisson}(\exp(1 + 0.3 x_i))$ (baseline rate $e \approx 2.72$, rate ratio $e^{0.3} \approx 1.35$). Prior $\boldsymbol\beta = (\beta_0, \beta_1) \sim N(\mathbf{0}, 10 \mathbf{I})$.
>
>*Newton iteration:* converges in 4 iterations to $\hat{\boldsymbol\beta} \approx (1.02, 0.31)$.
>*Laplace posterior standard deviations:* from $\boldsymbol\Sigma_{\text{Lap}}$ diagonals, $\sigma_{\beta_0} \approx 0.09$, $\sigma_{\beta_1} \approx 0.07$.
>*95% CI for rate ratio $e^{\beta_1}$:* $e^{0.31 \pm 1.96 \cdot 0.07} = [1.18, 1.55]$, bracketing the true 1.35.
>*Posterior predictive at $x_\star = 1$:* posterior mean rate $\hat\lambda_\star = \exp(1.02 + 0.31) = 3.78$; predictive mean matches, but predictive distribution is Poisson-lognormal with inflated variance relative to $\text{Poisson}(3.78)$.

>[!example]- Example 2: Exposure-Adjusted Disease Incidence
>A public-health study tallies disease cases in $J = 50$ counties over one year, with county populations $t_j$ (offset) and a single risk covariate $x_j$ (e.g., average pollutant concentration).
>
>*Model:* $y_j \sim \text{Poisson}(t_j \exp(\beta_0 + \beta_1 x_j))$. The offset $\log t_j$ is fixed; coefficient $\beta_1$ measures the log-rate increase per unit pollution.
>*Prior:* $\beta_0 \sim N(-10, 5)$ (placing the baseline rate near $e^{-10} \approx 5 \times 10^{-5}$ per person-year), $\beta_1 \sim N(0, 1)$ (weakly informative).
>*Posterior:* Laplace approximation with Newton's method.
>*Interpretation:* if posterior mean $\hat\beta_1 = 0.15$ with SD 0.05, the rate ratio for one unit of pollution is $e^{0.15} = 1.16$ with 95% CI $[1.05, 1.28]$, a 16% per-unit increase significantly different from 1.
>*Model check:* compare fitted variances to observed variance across counties. If Pearson residuals show large dispersion, add a county-level random effect $\eta_j \sim N(0, \tau^2)$ to upgrade to a log-normal Poisson hierarchical model.

>[!example]- Example 3: Laplace Proposal for Metropolis-Hastings
>Suppose the analyst prefers full MCMC over Laplace point estimates (perhaps for better tail summaries or for a non-Gaussian prior). Use the Laplace-approximate posterior as the MH proposal:
>
>1. *Preprocess:* Newton-iterate to MAP $\hat{\boldsymbol\beta}$; compute Laplace covariance $\boldsymbol\Sigma_{\text{Lap}}$.
>2. *MH step $t$:* propose $\boldsymbol\beta^* \sim N(\boldsymbol\beta^{(t-1)}, c^2 \boldsymbol\Sigma_{\text{Lap}})$ with $c = 2.38/\sqrt{d}$ (Roberts-Gelman-Gilks optimal scaling).
>3. *Accept* with probability $\alpha = \min(1, \exp[\log p(\boldsymbol\beta^*) - \log p(\boldsymbol\beta^{(t-1)})])$ — proposal is symmetric, so no proposal-density ratio is needed.
>
>For the Poisson regression in Example 1, this typically achieves acceptance rates near the 23% optimum for $d = 2$ and produces effective sample sizes comparable to conjugate Gibbs samplers. See [[3.11.1 Metropolis-Hastings]].

# Derivation

Goal: derive the Laplace approximation and IRLS-analog Newton updates for Poisson regression.

The log-posterior (up to $\boldsymbol\beta$-free constants):
$$\mathcal L(\boldsymbol\beta) = \sum_{i=1}^n [y_i \mathbf{x}_i^\top \boldsymbol\beta - \exp(\mathbf{x}_i^\top \boldsymbol\beta)] - \tfrac{1}{2}(\boldsymbol\beta - \boldsymbol\beta_0)^\top \boldsymbol\Sigma_0^{-1}(\boldsymbol\beta - \boldsymbol\beta_0).$$
Differentiating once:
$$\nabla \mathcal L = \sum_i \mathbf{x}_i(y_i - \lambda_i) - \boldsymbol\Sigma_0^{-1}(\boldsymbol\beta - \boldsymbol\beta_0) = \mathbf{X}^\top(\mathbf{y} - \boldsymbol\lambda) - \boldsymbol\Sigma_0^{-1}(\boldsymbol\beta - \boldsymbol\beta_0).$$
Differentiating twice:
$$\nabla^2 \mathcal L = -\sum_i \mathbf{x}_i \mathbf{x}_i^\top \lambda_i - \boldsymbol\Sigma_0^{-1} = -\mathbf{X}^\top \operatorname{diag}(\boldsymbol\lambda)\mathbf{X} - \boldsymbol\Sigma_0^{-1},$$
which is negative definite. The MAP is the unique solution to $\nabla \mathcal L = \mathbf{0}$, found by Newton's method:
$$\boldsymbol\beta_{k+1} = \boldsymbol\beta_k - [\nabla^2 \mathcal L]^{-1}\nabla \mathcal L = \boldsymbol\beta_k + (\mathbf{X}^\top \mathbf{W}_k \mathbf{X} + \boldsymbol\Sigma_0^{-1})^{-1}[\mathbf{X}^\top(\mathbf{y} - \boldsymbol\lambda_k) - \boldsymbol\Sigma_0^{-1}(\boldsymbol\beta_k - \boldsymbol\beta_0)],$$
with $\mathbf{W}_k = \operatorname{diag}(\boldsymbol\lambda_k)$. Defining the working response $z_{k,i} = \mathbf{x}_i^\top \boldsymbol\beta_k + (y_i - \lambda_{k,i})/\lambda_{k,i}$ casts this as a weighted least-squares fit, the Poisson analog of IRLS.

At convergence, $\hat{\boldsymbol\lambda}_i = \exp(\mathbf{x}_i^\top \hat{\boldsymbol\beta})$ and the Laplace covariance is
$$\boldsymbol\Sigma_{\text{Lap}} = (\mathbf{X}^\top \operatorname{diag}(\hat{\boldsymbol\lambda})\mathbf{X} + \boldsymbol\Sigma_0^{-1})^{-1}.$$

*Log-marginal-likelihood:* substituting into the standard Laplace formula ([[3.9 Laplace Approximation]]),
$$\log p(\mathbf{y}) \approx \log p(\mathbf{y} \mid \hat{\boldsymbol\beta}) + \log p(\hat{\boldsymbol\beta}) + \tfrac{d}{2}\log(2\pi) + \tfrac{1}{2}\log|\boldsymbol\Sigma_{\text{Lap}}|.$$
