>[!note] Phasor
>A **phasor** is a [[7.2a Complex Exponentials|complex number representation]] of a sinusoidal function that helps simplify the analysis of sinusoidal steady-state behavior in electrical circuits. It represents both the amplitude and the phase of a sinusoidal wave. In mathematical terms, a phasor can be expressed as:
>$$X = |X|e^{j\phi} \iff X = |X| \angle \phi,$$
>where $|X|$ is the phasor's peak amplitude, and $\phi$ is its phase angle.
>
>Using [[7.2b Euler's Theorem|Euler's theorem]], any [[2.2j.1 Sinusoidal Signals|time-varying sinusoidal signal]] $x(t)$ can be expressed in the form
>$$x(t) = \mathscr{Re}\{X e^{j\omega t} \},$$
>where $x(t) = \mathscr{Re}\{|X|e^{j\phi}e^{j\omega t}\} = \cos(\omega t + \phi).$ Only the real part of its phasor is taken, as its imaginary part does not have any physical-world implications.
>
>To gain some intuition, provided is a table of some standard time-variant functions and their phasor representations:
>
>|                  $x(t)$                  |              $X$               |
| :--------------------------------------: | :----------------------------: |
|            $A \cos (\omega t)$             |              $A$               |
|        $A \cos(\omega t + \phi)$         |          $Ae^{j\phi}$          |
|        $-A \cos(\omega t + \phi)$        |     $Ae^{j(\phi \pm \pi)}$     |
|            $A \sin \omega t$             |      $Ae^{-j\pi/2} = -jA$      |
|        $A \sin(\omega t + \phi)$         |     $Ae^{j(\phi - \pi/2)}$     |
|        $-A \sin(\omega t + \phi)$        |     $Ae^{j(\phi + \pi/2)}$     |
|          $\frac{d}{dt} x(t)$           |          $j\omega X$           |
| $\frac{d}{dt} [A \cos(\omega t + \phi)]$ |      $j\omega Ae^{j\phi}$      |
|            $\int x(t) \, dt$             |     $\frac{1}{j\omega} X$      |
|   $\int A \cos(\omega t + \phi) \, dt$   | $\frac{1}{j\omega} Ae^{j\phi}$ |
>>[!warning] Note!
>>Differentiation of a time function $x(t)$ in the time domain is equivalent to multiplication of its phasor counterpart $X$ by $j\omega$ in the phasor domain. Similarly, integration of $x(t)$ in the time domain is equivalent to dividing its phasor $X$ by $j\omega$ in the phasor domain.

# Intuition
The phasor (frequency) domain is generally used for simplification of mathematical derivations. In the phasor domain, as seen above, operations such as differentiation and integration become straightforward.
