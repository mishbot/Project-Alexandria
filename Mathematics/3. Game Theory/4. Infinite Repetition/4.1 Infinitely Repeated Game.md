>[!note] Repeated Game
>A repeated game is an [[3.1 Extensive Form Game|extensive form game]] that consists of one [[2.1 Strategic Form Game|strategic form]] stage game $n$ times. If $n$ has no fixed end, the repeated game never ends, and is therefore an **infinitely repeated game**.

# Example
>[!example] Rationale for Infinite Repetition



#### (Equilibria) If there is a stage-game Nash equilibrium, then that Nash equilibrium is an SPNE for the repeated game.
