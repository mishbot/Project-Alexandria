>[!note] Greedy Search
>**Greedy Search** is a search algorithm that selects the frontier node with the lowest heuristic value $h(n)$, meaning the state it estimates to be closest to a goal. It uses a priority queue for its frontier, but unlike Uniform Cost Search, which prioritizes by actual path cost, Greedy prioritizes purely by heuristic values. 
>
>It is neither complete nor optimal: it may fail to find a solution even if one exists, and when it does find a solution, it is not guaranteed to be the least-cost path, hence the name. Its behavior is highly dependent on the quality of the heuristic: with a good heuristic, it can quickly reach a goal, but with a poor one, it may behave like a misled depth-first search. Its time and space complexities are $O(b^m)$ in the worst case, where $m$ is the maximum search depth.
>
>The following is an example of Greedy Search on a 5x5 grid. Note that since there are no obstacles, the optimal solution is not unique.
