>[!note] Uniform Cost Search
>**Uniform Cost Search (UCS)** is a graph traversal algorithm that expands the lowest-cost frontier node first, implemented with a priority queue ordered ascending by the path cost function $g(n)$, which represents the cumulative cost from the start state to node $n$.
>
>It is complete and optimal as long as all edge costs are nonnegative, ensuring the discovery of the lowest-cost path to the goal. Its runtime is $O(b^{C^*/\epsilon})$, where $C^*$ is the **cost of the optimal solution** and $\epsilon$ is the **minimum edge cost**, with space complexity of the same order.

# Proof
We now prove the time and space complexity of UCS. 
- **Time Complexity.** The longest possible path with cost $\le C^*$ has depth at most $C^* / \epsilon$, since each edge cost is $\ge \epsilon$. Therefore, the number of expandable UCS nodes is bounded by $O(b^{C^* / \epsilon})$, such that the algorithm explores $1+b+b^2+\ldots+b^{C^* / \epsilon}=\frac{b^{C^* / \epsilon + 1} - 1}{b-1}$. This is a very weak bound.
- **Space Complexity.** UCS stores the entire frontier of nodes with path cost $\le C^*$, which is maximized around the bottom level $C^* / \epsilon$, such that the number of nodes saved is $b^{C^* / \epsilon} + b^{C^* / \epsilon+1}$. As such, the space complexity is asymptotically $O(b^{C^* / \epsilon})$.
