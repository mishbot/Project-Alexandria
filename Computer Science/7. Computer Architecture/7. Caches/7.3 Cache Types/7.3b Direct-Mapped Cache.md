>[!note] Direct-Mapped Cache
>An $N$-byte, $K$-bytes-per-block direct-mapped cache of $\frac{N}{K}$ blocks requires only a [[7.2a Write Policies|write policy]] to store memory blocks using an **index** that governs the cache row on which the memory block is written, such that $N_i=\log_2(\frac{N}{K})$. The length of the tag is therefore equal to
>$$N_t=N-N_i-N_o,$$
>where $N_o=log_2(K)$ is the number of bits allocated to the offset, or the length of every block:

>    
>    % Draw the inner boxes for Data

>    \draw[thick] (1,2) rectangle (5,3) node[midway] {$K$ bytes};
>    \node at (0.25, 1.5) {$\vdots$};
>    \draw[thick] (1,0) rectangle (5,1) node[midway] {$K$ bytes};
>    
>    % Add text labels

>\end{tikzpicture}

>\end{document}
>```
