>[!note] Classification
>**Classification** is the task of assigning an input vector $x \in \mathbb{R}^D$ to one of $K$ discrete classes $C_k$, where $k = 1, 2, \dots, K$. When $K = 2$, the problem is called **binary classification**, and when $K > 2$, it becomes **multi-class classification**. 
>
>The central goal is to learn a function that partitions the input space into decision regions, each corresponding to one class. The boundaries between these regions are $(D-1)$-dimensional hyperplanes called **decision boundaries** or **decision surfaces**. Their form determines how the model distinguishes between different categories.
>
>Geometrically, classification can be visualized in terms of these boundaries: 
>- In one-dimensional data, the decision boundary is a single point dividing two regions. 
>- In two dimensions, the boundary becomes a line.
>- In three dimensions, it forms a plane. 
>
>Datasets whose classes can be separated by a linear decision surface are said to be **linearly separable**, meaning that a single linear function can perfectly divide the classes without overlap.
>
>There are three main approaches to solving classification problems:
>1. **Discriminant functions** directly map an input to a class without explicitly modeling probabilities. Support Vector Machines (SVMs) are a common example of this approach; they find the separating boundary that maximizes the margin between classes.
>⠀
>2. **Generative probabilistic models** model the class-conditional distribution $p(x | C_k)$ and the prior probability $p(C_k)$, then apply Bayes’ theorem to obtain the posterior probability $p(C_k | x)$. Naïve Bayes is a well-known example of this method.
>⠀
>3. **Discriminative probabilistic modeling** directly models $p(C_k | x)$ without needing to describe how the data are generated. Logistic regression is a classic example, learning the parameters that best separate the classes in the feature space by optimizing likelihood or minimizing cross-entropy loss.
