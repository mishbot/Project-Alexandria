>[!note] Breadth-First Search
>**Breadth-First Search (BFS)** is a graph traversal algorithm that expands the shallowest frontier node first, using a FIFO queue, breaking ties by selecting the leftmost branch. 
>
>It is complete because it will eventually reach the shallowest goal node, and it is optimal only when all edge costs are equal. Its time complexity is $O(b^s)$, where $s$ is the level of the shallowest solution, and its space complexity is also $O(b^s)$ . The following is a representation of BFS on a 3-level graph.

# Proof
We now prove the time and space complexity of BFS. 
- **Time Complexity.** Consider a tree with $m$ tiers/levels, such that the maximum branching factor of any node is $b$. Let the goal node be on level $s \le m$. Then, the worst-case scenario occurs when the goal is the last expanded node on level $s$. Since we truncate the tree to account for the solution on level $s$, there are $1+b+b^2+\ldots+b^s=\frac{b^{s+1}-1}{b-1}$ nodes to be searched in this truncated tree. This means that the time complexity is $O(b^s)$.
- **Space Complexity.** Consider the same tree as above. BFS needs to store all nodes at the current level, plus their children (i.e., the nodes on the next level). As such, the space complexity is $O(b^s +b^{s+1})=O(b^s)$.
