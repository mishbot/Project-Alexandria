**Clustering** splits unlabeled data points into groups, so that points in the same group are similar to each other. It is a core task of [[1. Learning Paradigms#Unsupervised Learning|unsupervised learning]], since no labels tell the algorithm what the groups should be. K-means gives each point exactly one cluster. A Gaussian mixture model gives each point a probability for each cluster and models the density of the data. Hierarchical clustering builds a tree of merges, which gives a clustering for every number of clusters.
