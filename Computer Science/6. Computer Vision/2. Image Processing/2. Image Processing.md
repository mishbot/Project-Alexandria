# Image Processing

Image processing changes pixel values and keeps every pixel in place. Warps, which move pixels, are covered in [[3. Image Transformations]]. This section covers point operations, linear and nonlinear filters, the frequency-domain view of images, sampling and pyramids, blending, and compression. These tools reappear throughout computer vision, from feature detection to image generation.

## Prerequisites

- [[1.1. Digital Images]]: images as functions and as arrays of pixel values.
- [[2.9c Fourier Transform]]: the Fourier transform of 1D signals.
- [[2.10 Sampling Theory]]: sampling, reconstruction and the Nyquist rate.
- [[2.8b Change of Basis]]: the linear-algebra view of the Fourier transform.
