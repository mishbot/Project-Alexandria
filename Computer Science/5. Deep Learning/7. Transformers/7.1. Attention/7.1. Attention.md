>[!note] Attention
>**Attention** is a lookup table that can be learned with gradient descent. The table stores $N$ pairs of a **key** $\mathbf k_m$ and a **value** $\mathbf v_m$. A **query** $\mathbf q$ asks for the values whose keys match it. A hash table would return the value of the one key that equals the query. Attention returns a weighted average of all the values, and keys more similar to the query get more weight:
>$$s_m = \frac{\mathbf q^T\mathbf k_m}{\sqrt{D_k}}, \qquad a_m = \frac{\exp(s_m)}{\sum_{j=1}^{N}\exp(s_j)}, \qquad \mathbf o = \sum_{m=1}^{N} a_m\mathbf v_m.$$
>Here $D_k$ is the length of queries and keys, and $s_m$ is the **score** of key $m$. The **attention weights** $a_m$ are positive and sum to $1$. The lecture calls this operation **queryable softmax pooling**. It has no parameters of its own.
>
>The learned parts produce the queries, keys and values. Stack $N$ token vectors $\mathbf x_n \in \mathbb R^D$ as the rows of $\mathbf X \in \mathbb R^{N \times D}$. Then
>$$\mathbf Q = \mathbf X\mathbf W_q + \mathbf 1\boldsymbol\beta_q^T, \qquad \mathbf K = \mathbf X\mathbf W_k + \mathbf 1\boldsymbol\beta_k^T, \qquad \mathbf V = \mathbf X\mathbf W_v + \mathbf 1\boldsymbol\beta_v^T,$$
>with $\mathbf W_q, \mathbf W_k \in \mathbb R^{D \times D_k}$, $\mathbf W_v \in \mathbb R^{D \times D_v}$, bias vectors $\boldsymbol\beta$ and the all-ones vector $\mathbf 1 \in \mathbb R^N$. Row $n$ of $\mathbf Q$ is the query $\mathbf q_n$ of token $n$, and likewise for $\mathbf K$ and $\mathbf V$. All $N$ lookups then take two matrix products:
>$$\mathrm{Attn}(\mathbf Q, \mathbf K, \mathbf V) = \mathrm{softmax}\!\left(\frac{\mathbf Q\mathbf K^T}{\sqrt{D_k}}\right)\mathbf V \in \mathbb R^{N \times D_v}.$$
>The softmax acts on each row separately. Entry $(n, m)$ of the $N \times N$ **attention matrix** $\mathbf A$ is the weight $a_{nm}$ that query $n$ gives key $m$.
>
>Three forms of attention differ in who fills the table and who queries it:
>- **Self-attention**: one sequence makes the queries, the keys and the values. Every token can read every token, including itself.
>- **Causal (masked) self-attention**: token $n$ may read only tokens $m \le n$. The scores for $m > n$ are set to $-\infty$ before the softmax, so their weights are $0$.
>- **Cross-attention**: the queries come from one sequence, such as a decoder. The keys and values come from another, such as an encoder.

>[!warning] Rows Versus Columns
>This note stores tokens as the rows of $\mathbf X$, as HW10 and PyTorch do. The lecture and Prince store them as columns, $\mathbf X_{\mathrm P} = \mathbf X^T \in \mathbb R^{D \times N}$. Their queries are $\mathbf Q_{\mathrm P} = \boldsymbol\beta_q\mathbf 1^T + \boldsymbol\Omega_q\mathbf X_{\mathrm P}$ with $\boldsymbol\Omega_q = \mathbf W_q^T$, so $\mathbf Q_{\mathrm P} = \mathbf Q^T$. Their output is $\mathbf V_{\mathrm P}\,\mathrm{Softmax}[\mathbf K_{\mathrm P}^T\mathbf Q_{\mathrm P}]$, with the softmax taken over each column. That softmax matrix is $\mathbf A^T$, so their output equals $(\mathbf A\mathbf V)^T$. The lecture writes $a[\mathbf x_m, \mathbf x_n]$ for the weight that query $n$ gives key $m$, which is $a_{nm}$ here.

# Intuition

The lecture reaches attention by trying to build a hash table that gradient descent can train. A decoder step forms a query, and the encoder has stored keys with values. Four ideas follow, each fixing the problem of the one before:

1. **Exact match.** Return the value whose key equals the query. With random initial weights, no key ever matches. A small change to the query still matches nothing, so no gradient exists.
2. **Closest match.** Return the value of the most similar key. The returned value now gets a gradient. A small change to the query or the keys usually keeps the same winner, so their gradients are $0$.
3. **Several close matches.** Return the average of the values of the few most similar keys. The question becomes how to weight them.
4. **Weighted average.** Weight every value by a similarity score turned into a probability with a softmax. Each weight now changes smoothly with the query and the keys, so all three get gradients.

The fourth idea is attention. Take the decoder step that writes "book" in a translation model. It can put its weight on the encoder state for "book", wherever that word sits. This is a skip connection, as in a [[6.4. U-Net|U-Net]], whose address is computed from the content.

The same formula appears in the Fall 2022 lecture 17 notes, which make [[6.1. K-Means|k-means]] trainable by gradient descent. The hard assignment of a point $\mathbf x$ to its closest center becomes soft weights $\alpha_j \propto \exp(-\gamma\|\mathbf x - \mathbf r_j\|^2)$. The weighted center $\hat{\mathbf r} = \sum_j \alpha_j\mathbf r_j$ is then a softmax-weighted average. The point plays the role of the query, and the centers play the roles of both keys and values.

# Properties

#### *(Why Scale by $\sqrt{D_k}$)* Random queries and keys give scores whose variance grows like $D_k$, and the scale $1/\sqrt{D_k}$ keeps it at $1$.

Let the entries of $\mathbf q$ and $\mathbf k$ be independent with mean $0$ and variance $1$. Then $\mathbf q^T\mathbf k = \sum_{i=1}^{D_k} q_i k_i$ has mean $0$ and variance $D_k$, as HW9 shows. With $D_k = 64$, raw scores have standard deviation $8$. A softmax of such scores puts nearly all weight on one key, and its gradient is nearly $0$. Dividing by $\sqrt{D_k}$ brings the standard deviation back to $1$. The Spring 2023 lecture 14 notes explain why the scale is not $1/D_k$. That scale would give scores with standard deviation $1/\sqrt{D_k}$. The weights would stay close to uniform, and selecting one key would need very large vectors.

#### *(Softmax Versus Argmax)* Attention with an argmax gives zero gradient to the queries and keys, but the softmax does not.

The softmax derivative $\partial a_m/\partial s_j = a_m(\delta_{mj} - a_j)$ gives
$$\frac{\partial \mathbf o}{\partial \mathbf q} = \frac{1}{\sqrt{D_k}}\sum_{j=1}^{N} a_j(\mathbf v_j - \mathbf o)\,\mathbf k_j^T.$$
Each term pulls the output toward value $\mathbf v_j$ when the query moves toward key $\mathbf k_j$. An argmax picks one key, and small changes leave the winner unchanged. Its derivative with respect to the scores is $0$ wherever the maximum is unique. Only the chosen value gets a gradient, as in HW9. The same formula shows that a saturated softmax behaves like an argmax. If one weight is near $1$, every term $a_j(\mathbf v_j - \mathbf o)$ is near $\mathbf 0$.

#### *(Self Versus Cross)* Self-attention and cross-attention run the same computation and differ only in where the queries, keys and values come from.

In self-attention the sequence that writes the table also reads it. In cross-attention, a decoder with $N'$ tokens forms $\mathbf Q \in \mathbb R^{N' \times D_k}$. An encoder with $N$ tokens forms $\mathbf K$ and $\mathbf V$. The attention matrix is then $N' \times N$, and each decoder token gets one weighted average of encoder values. The key and value maps sit in the decoder layer and are trained by the decoder's loss. They learn how to read the encoder's output for the decoder's task.

#### *(The Causal Mask Allows Parallel Training)* With a causal mask, one forward pass gives every position the output it would get from its own prefix.

Under the mask, the output of a layer at position $n$ depends only on the inputs at positions $1, \dots, n$. Stacked layers keep this property, so the final output at $n$ ignores all later tokens. A decoder can therefore compute all $N$ next-token predictions and their losses in one pass. Without the mask, it would have to run once for each prefix. Adding $-\infty$ to a score gives $\exp(-\infty) = 0$ in the softmax. In code a large negative number, such as $-10^9$, plays this role.

#### *(Permutation Equivariance)* If the tokens of unmasked self-attention are permuted, its outputs are permuted in the same way.

Let $\mathbf P$ be a permutation matrix and replace $\mathbf X$ by $\mathbf P\mathbf X$. Then $\mathbf Q$, $\mathbf K$ and $\mathbf V$ become $\mathbf P\mathbf Q$, $\mathbf P\mathbf K$ and $\mathbf P\mathbf V$. The scores become $\mathbf P\mathbf Q\mathbf K^T\mathbf P^T$. A row-wise softmax commutes with reordering rows and columns, so the output is $\mathbf P\mathbf A\mathbf P^T\mathbf P\mathbf V = \mathbf P\mathbf A\mathbf V$. The words of a sentence would then carry no order. [[7.4. Positional Encoding]] adds the order back. A causal mask breaks this symmetry, because it depends on the positions.

#### *(Inner Product or RBF)* An RBF similarity gives the same weights as the inner product whenever all keys have the same norm.

The Spring 2023 lecture 14 notes name two similarity choices, the inner product and the RBF kernel $\exp(-\gamma\|\mathbf q - \mathbf k_m\|^2)$. Expanding the square gives
$$\exp(-\gamma\|\mathbf q - \mathbf k_m\|^2) = \exp(2\gamma\,\mathbf q^T\mathbf k_m)\,\exp(-\gamma\|\mathbf q\|^2)\,\exp(-\gamma\|\mathbf k_m\|^2).$$
The factor with $\|\mathbf q\|^2$ is the same for every key, so it cancels in the softmax. If the keys share one norm, that factor cancels too. Only $\exp(2\gamma\,\mathbf q^T\mathbf k_m)$ remains, which is dot-product attention with scale $2\gamma$. Practice uses the inner product, which is cheaper and fits matrix multiplication. Other similarity [[3.10.1 Kernels|kernels]] give other forms of attention.

#### *(A Table Instead of a State)* With attention, a sequence model stores information in a table that it writes and reads, not in a state.

An [[5.3.1. RNNs|RNN]] must carry everything it may need later in its state $\mathbf h_t$. With self-attention, each token writes its key and value into a table, and later tokens look them up. The Fall 2022 lecture 17 notes describe this as writing notes to yourself instead of keeping an internal memory. The weights are still shared across positions, as in an RNN. A gradient reaches an earlier token directly through the attention weight, not through a long chain of state updates. Self-attention is also a [[6.1.1. Message Passing|message-passing]] layer on the complete graph of tokens, with learned edge weights.

#### *(Reading an Attention Map)* Row $n$ of $\mathbf A$ states exactly how the output at position $n$ mixes the values of all positions.

The weights in a row are nonnegative and sum to $1$. The output $\mathbf o_n$ is therefore a convex combination of the values. Plotting $\mathbf A$ as a heat map, as in HW10, shows which tokens each token reads. A model has one map per head and per layer, and different heads often read different things. A map shows where a head reads, not what it does with the values. Later layers also mix tokens that were already mixed, so one map does not explain a prediction.

#### *(Cost)* Self-attention over $N$ tokens computes an $N \times N$ score matrix, so its time and memory grow as $N^2$.

The product $\mathbf Q\mathbf K^T$ takes $N^2 D_k$ multiply-adds, and $\mathbf A\mathbf V$ takes $N^2 D_v$. Storing $\mathbf A$ takes $N^2$ numbers per head. A causal mask removes about half the pairs, but the growth is still quadratic. An RNN takes $O(N)$ sequential steps, while attention computes all pairs in parallel. [[7.1.2. Efficient Attention]] covers methods that reduce the memory or the arithmetic.

# Examples

>[!example] (Easy) One Lookup
>A query $\mathbf q = (1, 0, 1, 0)$ reads a table with three keys of length $D_k = 4$: $\mathbf k_1 = (2, 0, 2, 0)$, $\mathbf k_2 = (0, 2, 0, 2)$ and $\mathbf k_3 = (1, 1, 1, 1)$. The values are $\mathbf v_1 = (1, 0)$, $\mathbf v_2 = (0, 1)$ and $\mathbf v_3 = (1, 1)$.
>
>>[!example]- Compute the scores, the weights and the output. Compare the output with argmax attention.
>>The inner products are $4$, $0$ and $2$. Dividing by $\sqrt 4 = 2$ gives the scores $s = (2, 0, 1)$. The exponentials are $e^2 = 7.389$, $e^0 = 1$ and $e^1 = 2.718$, with sum $11.107$. The weights are
>>$$a = (0.665,\ 0.090,\ 0.245).$$
>>The output is $\mathbf o = 0.665\,(1, 0) + 0.090\,(0, 1) + 0.245\,(1, 1) = (0.910,\ 0.335)$. Argmax attention would return $\mathbf v_1 = (1, 0)$. The softmax output is close to it but also contains $\mathbf v_3$, whose key is second most similar.

>[!example] (Medium) A Causal Mask
>Three tokens have the scaled scores below, with row $n$ for query $n$ and column $m$ for key $m$. Their values are $\mathbf v_1 = (1, 0)$, $\mathbf v_2 = (0, 2)$ and $\mathbf v_3 = (2, 2)$.
>$$\mathbf S = \begin{bmatrix} 1 & 2 & 0 \\ 0 & 1 & 3 \\ 2 & 0 & 1 \end{bmatrix}$$
>
>>[!example]- Apply the causal mask, compute $\mathbf A$ and the three outputs, and check which outputs change if token 3 changes.
>>The mask sets the entries above the diagonal to $-\infty$. Row $1$ keeps only $s_{11}$, so $a_{11} = 1$. Row $2$ keeps the scores $0$ and $1$, giving weights $1/(1 + e) = 0.269$ and $e/(1 + e) = 0.731$. Row $3$ keeps all three scores $(2, 0, 1)$, which give $(0.665, 0.090, 0.245)$ as in the Easy example:
>>$$\mathbf A = \begin{bmatrix} 1 & 0 & 0 \\ 0.269 & 0.731 & 0 \\ 0.665 & 0.090 & 0.245 \end{bmatrix}.$$
>>The outputs are $\mathbf o_1 = (1, 0)$, $\mathbf o_2 = 0.269\,(1, 0) + 0.731\,(0, 2) = (0.269, 1.462)$ and $\mathbf o_3 = (1.155, 0.670)$. Without the mask, row $2$ would have given most of its weight to key $3$, whose score is $3$. With the mask, changing token $3$ changes its key, value and query, which affect only row $3$. The outputs $\mathbf o_1$ and $\mathbf o_2$ stay the same.

>[!example] (Hard) Gradient of a Saturating Lookup
>A query $q \in \mathbb R$ reads two keys $k_1 = 1$ and $k_2 = -1$ with values $v_1 = 1$ and $v_2 = 0$. Here $D_k = 1$.
>
>>[!example]- Find $\partial o/\partial q$ from the general formula, and evaluate it at $q = 0$, $1$ and $3$. What does argmax attention give?
>>The scores are $s_1 = q$ and $s_2 = -q$. The first weight is $a_1 = e^q/(e^q + e^{-q}) = \sigma(2q)$, where $\sigma$ is the logistic function. The output is $o = a_1 v_1 + a_2 v_2 = a_1$. The general formula gives
>>$$\frac{\partial o}{\partial q} = a_1(v_1 - o)k_1 + a_2(v_2 - o)k_2 = a_1(1 - a_1) + a_2\,a_1 = 2a_1a_2.$$
>>Differentiating $\sigma(2q)$ directly gives $2\sigma(2q)(1 - \sigma(2q))$, the same result.
>>
>>At $q = 0$ the weights are $(0.5, 0.5)$ and the gradient is $0.5$. At $q = 1$ they are $(0.881, 0.119)$ and the gradient is $0.210$. At $q = 3$ they are $(0.9975, 0.0025)$ and the gradient is $0.0049$. As the query grows, the softmax approaches an argmax and the gradient falls toward $0$. Argmax attention returns $o = 1$ for every $q > 0$, so its derivative is exactly $0$ there.
