>[!note] Integrator-Adder-Gain Block Diagram
>An **integrator-adder-gain block diagram** is a graphical representation used to illustrate **continuous-time** systems that involve signal integration, summation (addition), or scaling by a gain factor. IAG structures take the input $x(n)$ and output $y(n)$ of a system, and represent the system's manipulation of the input to obtain the output using
>- Integrator blocks ($\boxed{\tiny\int}$), which delay any signal $g(n)$ by 1 unit of time, such that $g(n) \to \boxed{D} \to g(n-1)$.
>- Adder blocks ($\oplus$), which sum two or more signals $f(n)$ and $g(n)$ to produce $f(n) + g(n)$.
>- Gain blocks ($\rhd^{\alpha}$), which scale a signal by a number $\alpha \in \mathbb{R}$.
