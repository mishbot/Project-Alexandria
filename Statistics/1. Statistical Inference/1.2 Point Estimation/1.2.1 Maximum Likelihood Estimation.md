>[!note] Maximum Likelihood (ML) Estimate
>The **maximum-likelihood (ML) estimate**  chooses the [[1.1 Estimators|estimator]] under which the observations are “most probable” by maximizing their likelihood. Let $X=(X_1,\dots,X_n)$ be observed data described by the joint PMF $p_{X}(x;\theta)$ whose form depends on the unknown parameter $\theta$, known as the **likelihood function**. Then, the **maximum-likelihood estimate** of $\theta$ is that value which maximizes the likelihood function, such that
>$$\hat{\theta}_{\text{ML}}(x) = \arg \max_{\theta} p_{X \mid \Theta}(x_{1}, \ldots, x_{n} \mid \theta).$$
>If the observations in $X$ are independent, the likelihood function can be decomposed as $p_{X \mid \Theta}(x_{1}, \ldots, x_{n} \mid \theta)=\prod\limits^{n}_{i=1}p_{X_{i} \mid \Theta}(x_{i} \mid\theta)$. Then, one may employ the **log-likelihood function**, denoted
>$$\ln p_{X \mid \Theta}(x_{1}, \ldots, x_{n} \mid \theta)=\sum^{n}_{i=1}\ln p_{X_{i} \mid \Theta}(x_{i} \mid \theta).$$
>>[!warning] Working With Continous Data
>>For the case where the observation vector $X$ consists of continuous data, one may simply use the likelihood function $f_{X}(x;\theta)$.

# Properties
#### (*Invariance*) For some function $h$, if $\zeta = h(\theta)$, then $\hat\zeta_{n} \in h(\hat\Theta_{n})$.

#### (*Asymptotic Normality*) If $\theta$ is scalar, $\dfrac{\hat\Theta_{n}-\theta}{\sigma(\hat\Theta_{n})} \to \mathcal{N}(0, 1)$.

# Examples
>[!example] MLE of Uniform Distribution
>Find the MLE of $\theta$ given $X_1, \ldots, X_n \sim_{\text{iid}} \text{Uniform}([0,θ])$.
>>[!example]- Solution
>>Since the distribution is uniform, it follows that $p_{X}(x;\theta)=\frac{1}{\theta} \mathbb{1}_{\{ 0 \leq x \leq \theta \}}$. Given i.i.d. variables, the likelihood function can be written using log-likelihood as 
>>$$p_{X}(x_{1}, \ldots, x_{n};\theta)=\sum^{n}_{i=1}\ln p_{X}(x_{i}; \theta) \mathbb{1}_{\{ 0 \leq x_{i} \leq \theta \}}.$$
>>When $\hat\theta = \max_{i} X_{i}$, 
>>$$p_{X}(x_{1}, \ldots, x_{n};\theta)=-n\ln \theta.$$
>>Taking the derivative of the log-likelihood on the domain $[\max_{i}X_{i}, +\infty)$, we have
>>$$\frac{\delta}{\delta \theta}(-n\ln \theta)=-\frac{n}{\theta}<0.$$
>>This means that the likelihood is strictly decreasing in $\theta$. As such, $\hat\theta = \max_{i} X_{i}$.

>[!example] MLE of the Gaussian
>Consider the Gaussian distribution $\mathcal{N}(\mu, \sigma^2)$, such that
>$$P(x) = \frac{1}{\sqrt{ 2\pi }\sigma}\exp\left(-{\frac{(x-\mu)^2}{2\sigma^2}}\right).$$
>
>Now, let $\{ X_{i} \}_{i=1}^{n}$ be a set of iid Gaussian random variables. We can find the maximum likelihood estimates $\hat{\mu}$ and $\hat{\sigma}^2$ by first taking the maximum likelihood as
>$$\begin{align}P(X \mid \mu, \sigma^2) &= \prod^{n}_{i=1} P(X_{i} \mid \mu, \sigma^2) \\ &= \sum^{n}_{i=1}\ln P(X_{i} \mid \mu, \sigma^2) \\ &\propto -N\frac{(x-\mu)^2}{2\sigma^2}\end{align}$$



>[!example] Maximum Likelihood Estimation for the Binary Symmetric Channel
>You are testing a digital link that corresponds to a BSC with some error probability $\epsilon \in [0,0.5]$.
>Suppose that you observe an input bit $X$ and an output bit $Y$. Calculate the MLE of $\epsilon$.
>>[!example] Solution.
>>Here, we want to find 
>>$$\hat\epsilon_{\text{MLE}}=\arg\max\limits_{\epsilon \in [0, 0.5]}\mathbb{P}_{\epsilon}(X=x, Y=y),$$
>>i.e., we need to first figure out the joint distribution $\mathbb{P}_{\epsilon}(X=x, Y=y)$.
