>[!note] Gaussian Mixture Models
>The **Gaussian Mixture Model (GMM)** is a probabilistic model that represents the distribution of data as a **weighted combination** of $K$ [[6.2 Multivariate Gaussian Distribution|multivariate Gaussian components]]:
>$$p(\mathbf{x} \mid \pi, \mu_1, \Sigma_1, \ldots, \mu_K, \Sigma_K) = \sum_{k=1}^{K} \pi_k\, \mathcal{N}(\mathbf{x} \mid \mu_k, \Sigma_k),$$
>where $\pi \in \mathbb{R}^{K}$ is a vector, such that each $\pi_{z}=P(Z)$ is a **prior** on the $Z$-th cluster center (i.e., $\sum \pi_{k}=1$). Given a data point $x$, we can use **total probability** to compute the marginal $p(x_{n})$, and **Bayes’ rule** to compute the probability that $x_{n}$ belongs to the $k$-th cluster:
>$$p(z = k \mid \mathbf{x}, \boldsymbol{\pi}, \{\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k\}) = \frac{\pi_k \, \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_{k})} {\sum_{j=1}^{K} \pi_j \, \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)}.$$
>These posterior probabilities $p(z=k \mid \mathbf{x})$ represent the **soft assignments** of data points to clusters, meaning that each point is assigned a probability of being in each cluster.
>
>Because there is no closed-form solution for the log-likelihood $p(x \mid \pi)$, the **Expectation-Minimization (EM) algorithm** provides an iterative way to optimize this likelihood. To begin, initialize by making guesses about the distributions $\{\pi_k, \mu_k, \Sigma_k\}_{k=1}^K$. Then:
>1. **E-Step:** Compute the **soft-assignments** (probabilities) of each point $x_{n}$ being in cluster $k$, $\gamma_{nk} = p(z_n = k \mid x_n) \in [0, 1]$, and the **expected log-likelihood objective function,**
>$$\begin{align*}
Q(\pi, \{ \mu_{k}, \Sigma_{k}\}_{k=1}^{K})&= \mathbb{E}_{Z}[\ln p(X,Z \mid \theta)]\\
&=\sum_{n=1}^{N}\sum_{k=1}^{K}\gamma_{nk}(\ln \pi_{k} + \ln\mathcal{N}(x_{n} \mid \mu_{k}, \Sigma_{k})).
\end{align*}$$
>1. **M-Step:** Find the new parameters of $\arg \max\limits_{\pi, \mu, \Sigma}Q(\pi, \{ \mu_{k}, \Sigma_{k} \}_{k=1}^{K})$:
>
>$$N_{k}=\sum_{n=1}^{N}\gamma_{nk} \implies \pi_{k}=\frac{N_{k}}{N}, \quad \mu_{k}=\frac{1}{N_{k}}\sum_{n=1}^{N}\gamma_{nk}x_{n}, \quad \Sigma_{k} = \frac{1}{N_{k}}\sum_{n=1}^{N}\gamma_{nk}(x_{n}-\mu_{k})^T(x_{n}-\mu_{k}).$$
