>[!note] Depth-First Search
>**Depth-First Search (DFS)** is an acyclic graph traversal algorithm that always expands the deepest frontier node first, implemented with a LIFO stack such that ties are broken by choosing the leftmost branch. 
>
>DFX is not complete, since cycles can lead to infinite search, and not optimal, as it simply finds the leftmost solution without considering path cost. Its time complexity is $O(b^m)$, where $m$ is the maximum level of the graph, and space complexity is $O(bm)$. 
>

# Proof
We now prove the time and space complexity of DFS. 
- **Time Complexity.** Consider a tree with $m$ tiers/levels, such that the maximum branching factor of any node is $b$. Since the worst-case scenario occurs when the tree is perfectly full with $1+b+b^2+\ldots+b^m=\frac{b^{m+1}-1}{b-1}$, and since the $b^m$ term dominates the geometric sum as $m$ grows large, then the time complexity is $O(b^m)$.
- **Space Complexity.** Consider the same tree as above. DFS goes down one path at a time, so it must only remember that path and the unexplored siblings. In the worst case, that is $b$ nodes at each of the $m$ levels on the frontier when starting at the root. As such, the space complexity is $O(bm)$.
