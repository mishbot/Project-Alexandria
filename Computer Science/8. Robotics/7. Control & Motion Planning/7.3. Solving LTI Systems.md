>[!note] Solving LTI Systems
>The closed-form solution of a continuous-time LTI system $\dot{x}(t) = Ax(t) + Bu(t)$ with initial condition $x(0)$ is
>$$x(t) = \underbrace{e^{At}\,x(0)}_{\text{homogeneous}} + \underbrace{\int_0^t e^{A(t-\tau)}\,B\,u(\tau)\,d\tau}_{\text{particular (convolution)}}.$$
>The first term is the **homogeneous** or *zero-input* response — how the system evolves from initial conditions alone. The second is the **particular** or *zero-state* response — the convolution of the input with the system's impulse response. The matrix $e^{At}$ is the **state transition matrix**, defined by its power series
>$$e^{At} = I + At + \frac{(At)^2}{2!} + \frac{(At)^3}{3!} + \cdots,$$
>which converges for all $t$ because $A$ is bounded.
>
>If $A$ has a full set of eigenvectors (i.e., is diagonalizable), $A = V \Lambda V^{-1}$ with $\Lambda = \mathrm{diag}(\lambda_1, \ldots, \lambda_n)$, then
>$$e^{At} = V e^{\Lambda t} V^{-1}, \qquad e^{\Lambda t} = \mathrm{diag}(e^{\lambda_1 t}, \ldots, e^{\lambda_n t}).$$
>This **eigendecomposition** is the standard computational tool: instead of summing the power series, diagonalize $A$, exponentiate the eigenvalues, and transform back. It also exposes the system's **modes** — the components $e^{\lambda_i t} v_i$, each evolving independently along an eigenvector direction.
>
>In discrete time, $x[i+1] = A x[i] + B u[i]$ has solution
>$$x[i] = A^i x[0] + \sum_{k=0}^{i-1} A^{i-1-k} B u[k],$$
>with natural response $A^i = V \Lambda^i V^{-1}$. Continuous-time natural responses are **linear combinations of exponentials** $e^{\lambda_j t}$; discrete-time responses are **linear combinations of powers** $\lambda_j^i$.
>
>>[!warning] Non-Diagonalizable $A$
>>If $A$ has repeated eigenvalues without a full eigenvector set (i.e., Jordan blocks), the closed form involves $t^k e^{\lambda t}$ terms. The matrix exponential is still well-defined and computable, but the cleanly separable modes above do not apply. For physics problems with distinct resonances, $A$ is almost always diagonalizable over $\mathbb{C}$.

# Intuition
The state transition matrix generalizes the scalar formula $x(t) = e^{at} x(0)$ for $\dot{x} = ax$. Replacing the scalar $a$ with a matrix $A$ produces $e^{At}$ — no longer a single number, but a matrix that evolves the entire state vector forward in time. Because $e^{At}$ is defined by the same power series as the scalar exponential, it inherits many of the same algebraic properties: $e^{A \cdot 0} = I$, $e^{At_1}e^{At_2} = e^{A(t_1 + t_2)}$, $\frac{d}{dt}e^{At} = A e^{At}$.

Eigendecomposition reveals the system's **modes**. Each eigenvalue $\lambda_i$ is the growth (or decay) rate of a mode, and each eigenvector $v_i$ is the state-space direction along which that mode evolves. A system's trajectory is a linear combination of mode trajectories; the initial condition $x(0) = \sum c_i v_i$ determines which modes get excited. In the coordinates of the eigenbasis (i.e., $z = V^{-1}x$), the system diagonalizes into $n$ independent scalar equations $\dot{z}_i = \lambda_i z_i$, each with the familiar exponential solution.

The convolution integral for the particular response is the linear-system analog of "add up the response to each impulse in the input, scaled by the input's value at that time." The kernel $e^{A(t-\tau)}B$ is the *impulse response matrix*: if the input is an instantaneous kick $u(\tau) = \delta(\tau)$ in a given direction, the system evolves from that kick via $e^{A(t-\tau)}B$. Integrating over all $\tau$ superposes the responses to the full input history — which works because the system is linear.

# Properties

## State Transition Matrix

#### *(Definition)* $e^{At} = \sum_{k=0}^{\infty} \frac{(At)^k}{k!}$, convergent for all $t$.

The power series always converges because $\|(At)^k/k!\| \leq (\|A\| t)^k/k!$, which is the Taylor series for $e^{\|A\| t}$. The series is the formal definition; practical computation uses eigendecomposition or specialized routines (Padé approximation, scaling and squaring).

#### *(Semigroup property)* $e^{A(t_1 + t_2)} = e^{At_1} e^{At_2}$, and $e^{A \cdot 0} = I$.

These identities encode time-invariance: propagating the state forward by $t_1 + t_2$ equals propagating by $t_1$ and then by $t_2$, and "no time" means "no change." They require $A$ to be constant; for time-varying $A(t)$, the analogous property involves a time-ordered product.

#### *(Derivative)* $\frac{d}{dt}e^{At} = A e^{At} = e^{At} A$.

Differentiating the power series term-by-term gives this identity. The commutativity $Ae^{At} = e^{At}A$ follows because $A$ commutes with its own powers. It does *not* hold for $e^{A+B}$ when $A$ and $B$ fail to commute — a common trap.

#### *(Invertibility)* $e^{At}$ is always invertible, with $(e^{At})^{-1} = e^{-At}$.

LTI dynamics are time-reversible from a mathematical standpoint: given $x(t)$, you can always recover $x(0)$. Physical dissipation enters through the signs of eigenvalues (decaying modes), not through loss of invertibility.

## Eigendecomposition

#### *(Diagonalization)* If $A$ has $n$ linearly independent eigenvectors, $A = V\Lambda V^{-1}$.

Columns of $V$ are the eigenvectors; $\Lambda$ is the diagonal matrix of eigenvalues. The condition "full eigenvector set" is generic — random matrices almost always satisfy it — but fails for specific matrices with repeated eigenvalues (e.g., Jordan blocks).

#### *(Modal coordinates)* In the eigenbasis $z = V^{-1}x$, the system decouples into $n$ independent scalar equations.

Substituting $x = Vz$ into $\dot{x} = Ax$ gives $\dot{z} = \Lambda z$, so $\dot{z}_i = \lambda_i z_i$. Each mode evolves independently as $z_i(t) = e^{\lambda_i t} z_i(0)$. Transforming back, $x(t) = V\,\mathrm{diag}(e^{\lambda_i t})\,V^{-1}\,x(0)$.

#### *(Mode excitation)* Mode $i$ is excited by $x(0)$ in proportion to $(V^{-1} x(0))_i$.

Initial conditions aligned with a single eigenvector excite only that mode; random initial conditions excite all modes simultaneously. A stable system's slow modes (smallest $|\mathrm{Re}(\lambda)|$) dominate the long-time response.

## Real Systems with Complex Eigenvalues

#### *(Complex conjugate pairs)* Real $A$ with complex eigenvalues has them in conjugate pairs $\lambda, \bar{\lambda}$ with conjugate eigenvectors.

The entries of $A$ are real, so the characteristic polynomial has real coefficients, so non-real roots come in pairs. The corresponding modes $e^{\lambda t} v$ and $e^{\bar{\lambda}t} \bar{v}$ combine to produce a real-valued oscillation $e^{\sigma t}(\alpha \cos\omega t + \beta \sin\omega t)$ where $\lambda = \sigma + i\omega$.

#### *(Decay and oscillation)* $\lambda = \sigma + i\omega$ produces $e^{\sigma t}\cos(\omega t + \phi)$ — decay rate $\sigma$, oscillation frequency $\omega$.

$\sigma < 0$ gives damped oscillation; $\sigma = 0$ gives steady oscillation; $\sigma > 0$ gives unstable growing oscillation. The scalar analog is the response of a second-order RLC circuit or a damped harmonic oscillator.

## Discrete Time

#### *(Power form)* Discrete-time solution uses $A^i$ instead of $e^{At}$: $x[i] = A^i x[0] + \sum_{k=0}^{i-1} A^{i-1-k} B u[k]$.

The convolution sum replaces the continuous integral. Modes evolve as $\lambda^i$ (powers) instead of $e^{\lambda t}$ (exponentials). Stability condition changes from "$\mathrm{Re}(\lambda) < 0$" to "$|\lambda| < 1$" — see [[7.5. Stability]].

# Examples
>[!example] Scalar First-Order System
>Solve $\dot{x} = -2x + u$ with $x(0) = 1$ and constant input $u(t) = 1$.
>>[!example]- Solution
>>Scalar case: $A = -2$, $B = 1$. $e^{At} = e^{-2t}$.
>>
>>Homogeneous: $e^{-2t}(1) = e^{-2t}$.
>>
>>Particular: $\int_0^t e^{-2(t-\tau)} \cdot 1\, d\tau = \frac{1 - e^{-2t}}{2}$.
>>
>>Total: $x(t) = e^{-2t} + \frac{1 - e^{-2t}}{2} = \frac{1}{2} + \frac{1}{2}e^{-2t}$. The state decays from $1$ toward the steady state $\tfrac{1}{2}$.

>[!example] Undamped Harmonic Oscillator
>Mass-spring system with $k/m = 1$: $A = \begin{bmatrix} 0 & 1 \\ -1 & 0 \end{bmatrix}$. Compute $e^{At}$ and the trajectory from $x(0) = (0, 1)^T$ with $u = 0$.
>>[!example]- Solution
>>Eigenvalues: $\lambda_{1,2} = \pm i$, eigenvectors $v_{1,2} = (1, \pm i)^T$.
>>
>>$V = \begin{bmatrix} 1 & 1 \\ i & -i \end{bmatrix}, \quad \Lambda = \begin{bmatrix} i & 0 \\ 0 & -i \end{bmatrix}, \quad V^{-1} = \tfrac{1}{2} \begin{bmatrix} 1 & -i \\ 1 & i \end{bmatrix}.$
>>
>>$e^{At} = V e^{\Lambda t} V^{-1} = \begin{bmatrix} \cos t & \sin t \\ -\sin t & \cos t \end{bmatrix}$ (after simplification using Euler's formula).
>>
>>Trajectory: $x(t) = e^{At} \begin{bmatrix} 0 \\ 1 \end{bmatrix} = \begin{bmatrix} \sin t \\ \cos t \end{bmatrix}$. Position oscillates as $\sin t$, velocity as $\cos t$ — consistent with an undamped oscillator.

>[!example] Stable System with Step Input
>System $A = \begin{bmatrix} 0 & 1 \\ -2 & -3 \end{bmatrix}$, $B = \begin{bmatrix} 0 \\ 1 \end{bmatrix}$ with $x(0) = 0$ and unit-step input $u(t) = 1$ for $t \geq 0$. Find the steady-state response.
>>[!example]- Solution
>>Eigenvalues of $A$: characteristic polynomial $\lambda^2 + 3\lambda + 2 = (\lambda + 1)(\lambda + 2)$, so $\lambda = -1, -2$. Both have negative real parts, so the system is stable and the transient decays to zero.
>>
>>Steady state: $\dot{x}_{ss} = 0$ gives $0 = A x_{ss} + B$, so $x_{ss} = -A^{-1}B = \begin{bmatrix} 1/2 \\ 0 \end{bmatrix}$.
>>
>>The full solution $x(t) = \int_0^t e^{A(t-\tau)}B\,d\tau$ can be computed via eigendecomposition, but the long-time behavior is simply $x_{ss}$.
