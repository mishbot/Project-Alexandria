>[!note] Kernel SVM
>A **kernel SVM** fits a linear [[4.4. Support Vector Machines|SVM]] in a feature space $\boldsymbol\phi(\mathbf{x})$ without ever computing $\boldsymbol\phi$. Labels are $y \in \{-1, +1\}$. The [[4.4a. SVM Dual|dual problem]] uses the data only through inner products. The **kernel trick** replaces each $\mathbf{x}_i^T\mathbf{x}_j$ with a kernel $k(\mathbf{x}_i, \mathbf{x}_j) = \boldsymbol\phi(\mathbf{x}_i)^T\boldsymbol\phi(\mathbf{x}_j)$:
>$$\max_{\boldsymbol\alpha}\ \sum_{i=1}^n \alpha_i - \frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \alpha_i\alpha_j y_iy_j\, k(\mathbf{x}_i, \mathbf{x}_j) \quad \text{s.t.} \quad 0 \le \alpha_i \le C, \quad \sum_{i=1}^n\alpha_i y_i = 0.$$
>Here $\alpha_i$ are the dual multipliers and $C$ is the slack penalty. The weight vector $\mathbf{w} = \sum_i \alpha_i y_i \boldsymbol\phi(\mathbf{x}_i)$ lives in feature space and is never formed. The score and the bias use kernel values only:
>$$f(\mathbf{x}) = \sum_{i:\,\alpha_i > 0} \alpha_i y_i\, k(\mathbf{x}_i, \mathbf{x}) + b, \qquad b = y_s - \sum_{i} \alpha_i y_i\, k(\mathbf{x}_i, \mathbf{x}_s).$$
>Here $s$ is a free support vector, with $0 < \alpha_s < C$. The boundary $f(\mathbf{x}) = 0$ is a hyperplane in feature space and a curved surface in input space.
>
>The kernel must be symmetric and positive semidefinite. Every Gram matrix $\mathbf{K}$ with entries $K_{ij} = k(\mathbf{x}_i, \mathbf{x}_j)$ must be [[4.2e Positive Semidefinite Matrix|PSD]]. The dual then stays a convex QP, and a feature map $\boldsymbol\phi$ exists by Mercer's theorem ([[3.10.1 Kernels]]). Four kernels are common:
>
>- **Linear**: $k(\mathbf{x}, \mathbf{z}) = \mathbf{x}^T\mathbf{z}$, which gives the plain linear SVM.
>- **Polynomial**: $k(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T\mathbf{z} + c)^p$ with $c \ge 0$. For $c > 0$ its features are all $\binom{d + p}{p}$ monomials of degree at most $p$.
>- **RBF (Gaussian)**: $k(\mathbf{x}, \mathbf{z}) = \exp(-\gamma\|\mathbf{x} - \mathbf{z}\|^2)$ with $\gamma > 0$. It is the squared-exponential kernel with $\gamma = 1/(2\ell^2)$ for length-scale $\ell$. Its feature space is infinite-dimensional.
>- **Sigmoid**: $k(\mathbf{x}, \mathbf{z}) = \tanh(\kappa\,\mathbf{x}^T\mathbf{z} + c)$. It is not PSD for all $\kappa$ and $c$, so the dual can lose convexity.
>
>The RBF kernel is the usual default. Its hyperparameters $C$ and $\gamma$ are tuned together by [[2.3.2. Cross-Validation|cross-validation]] on a logarithmic grid. Training uses the $n \times n$ Gram matrix and takes between $O(n^2)$ and $O(n^3)$ time. Prediction costs $O(n_{\text{SV}}\, d)$ per query for the RBF and polynomial kernels, where $n_{\text{SV}}$ is the number of support vectors.

# Intuition

A hyperplane in the original inputs cannot separate some classes. A nonlinear map of the inputs can make them separable. For example, a ring of positives around a cluster of negatives becomes separable once $x_1^2 + x_2^2$ is added as a feature. Adding all such features explicitly is expensive. A cubic map of $100$ inputs has $176{,}851$ monomial features. The SVM dual needs only the inner products of the features. A kernel computes each inner product in $O(d)$ time. This substitution is the **kernel trick**.

A kernel value $k(\mathbf{x}_i, \mathbf{x})$ measures how similar two inputs are. The score $f(\mathbf{x})$ is then a weighted vote of the support vectors. Each support vector votes for its own label, with weight $\alpha_i$ times its similarity to the query. Boser, Guyon and Vapnik (1992) combined kernels with the maximum-margin classifier. Schölkopf and Smola (2002) and ESL ch. 12 cover the method in depth.

# Properties

#### *(Sparse Representer Form)* The solution is a weighted sum of kernels centered at the support vectors, which is sparser than kernel ridge regression.

A regularized loss $\sum_i \ell(y_i, f(\mathbf{x}_i)) + \lambda\|\mathbf{w}\|^2$ in feature space has a minimizer in the span of $\boldsymbol\phi(\mathbf{x}_1), \dots, \boldsymbol\phi(\mathbf{x}_n)$. This is the **representer theorem** (Kimeldorf and Wahba 1971; Schölkopf, Herbrich and Smola 2001). [[3.2.1. Ridge Regression|Kernel ridge regression]] has the same form with coefficients $(\mathbf{K} + \lambda\mathbf{I})^{-1}\mathbf{y}$, and generically every coefficient is nonzero. The hinge loss is zero beyond the margin, so most SVM coefficients are exactly zero. Prediction then needs only the support vectors. On noisy data the sparsity is limited, because every misclassified training point is a support vector. The number of support vectors then grows roughly in proportion to $n$ (Steinwart 2003).

#### *(Kernel Width)* Small $\gamma$ makes an RBF SVM nearly linear, and large $\gamma$ makes it memorize the training set.

Each support vector affects the score mainly within a distance of about $1/\sqrt{\gamma}$, where its kernel falls to $e^{-1}$. For large $\gamma$ the Gram matrix approaches the identity, and every training point becomes a support vector. The Gaussian Gram matrix of distinct points is positive definite (Micchelli 1986). With large $C$, an RBF SVM can therefore fit any labeling of the training set, which is the [[2.3. Generalization|overfitting]] regime. For small $\gamma$ the kernel varies slowly. As $\gamma \to 0$ with $C$ growing like $1/\gamma$, the RBF SVM approaches a linear SVM (Keerthi and Lin 2003). $C$ and $\gamma$ interact, so they are tuned jointly. A common grid is $C \in \{2^{-5}, 2^{-3}, \dots, 2^{15}\}$ and $\gamma \in \{2^{-15}, 2^{-13}, \dots, 2^{3}\}$ (Hsu, Chang and Lin 2003). The scikit-learn default is $\gamma = 1/(d \cdot \mathrm{Var}(\mathbf{X}))$, with the variance taken over all entries of $\mathbf{X}$. Standardized features keep such defaults sensible.

#### *(Far From the Data)* An RBF SVM predicts the bias $b$ for inputs far from every support vector.

Every RBF kernel value tends to $0$ as $\|\mathbf{x} - \mathbf{x}_i\| \to \infty$, so $f(\mathbf{x}) \to b$. Far from the data, the sign of $b$ alone decides the class. When $|b|$ is small, such queries also sit near the boundary. A query unlike any training input still receives a label, with no warning. A polynomial kernel has the opposite behavior. Its score can grow like $\|\mathbf{x}\|^p$ far away, so its predictions become extreme. Neither kernel extrapolates reliably. Inputs far from the training data need a separate out-of-distribution check.

#### *(Cost in n)* Kernel SVMs become expensive when $n$ reaches about $10^5$, because the Gram matrix has $n^2$ entries.

For $n = 100{,}000$ the Gram matrix holds $10^{10}$ numbers, or $80$ GB in 64-bit floats. SMO avoids storing it by computing columns on demand and caching recent ones. Its running time still grows between quadratically and cubically in $n$ (Bottou and Lin 2007). Prediction is also slow. With $2{,}000$ support vectors and $d = 50$, each query needs $2{,}000$ kernel evaluations. That is about $100{,}000$ multiplications, against $50$ for a linear SVM. Two approximations restore linear cost in $n$. Random Fourier features (Rahimi and Recht 2007) map inputs to $D$ random cosine features. Their inner products approximate the RBF kernel. The Nyström method (Williams and Seeger 2001) builds a low-rank Gram matrix from $m$ sampled points. A linear SVM then trains on either feature set.

# Examples

>[!example] (Easy) The Quadratic Kernel's Hidden Features
>A sensor reports two scaled readings per sample. Two samples are $\mathbf{x} = (1, 2)$ and $\mathbf{z} = (3, -1)$, and the SVM uses the kernel $k(\mathbf{x}, \mathbf{z}) = (1 + \mathbf{x}^T\mathbf{z})^2$.
>
>>[!example]- Find a feature map $\boldsymbol\phi$ with $k(\mathbf{x}, \mathbf{z}) = \boldsymbol\phi(\mathbf{x})^T\boldsymbol\phi(\mathbf{z})$, and check it on the two samples.
>>Expanding the square gives $1 + 2x_1z_1 + 2x_2z_2 + x_1^2z_1^2 + x_2^2z_2^2 + 2x_1x_2z_1z_2$. Each term is a function of $\mathbf{x}$ times the same function of $\mathbf{z}$, so
>>$$\boldsymbol\phi(\mathbf{x}) = \big(1,\ \sqrt{2}x_1,\ \sqrt{2}x_2,\ x_1^2,\ x_2^2,\ \sqrt{2}x_1x_2\big).$$
>>It has $\binom{4}{2} = 6$ entries. For the two samples, $\mathbf{x}^T\mathbf{z} = 3 - 2 = 1$, so $k = (1 + 1)^2 = 4$. The feature vectors are $(1, \sqrt{2}, 2\sqrt{2}, 1, 4, 2\sqrt{2})$ and $(1, 3\sqrt{2}, -\sqrt{2}, 9, 1, -3\sqrt{2})$. Their inner product is $1 + 6 - 4 + 9 + 4 - 12 = 4$, which matches. The kernel needed one 2-dimensional inner product and a square, while the explicit route built two 6-dimensional vectors.

>[!example] (Medium) Staircase Light Switches
>A staircase light has one switch at the bottom and one at the top. Each switch is coded $+1$ (up) or $-1$ (down). The light is on ($y = +1$) when the switches agree and off ($y = -1$) when they differ. The training inputs are $(1, 1)$ and $(-1, -1)$ with $y = +1$, and $(1, -1)$ and $(-1, 1)$ with $y = -1$. No line separates them.
>
>>[!example]- Train a hard-margin SVM with $k(\mathbf{x}, \mathbf{z}) = (1 + \mathbf{x}^T\mathbf{z})^2$ and find its decision function.
>>Each input has $\mathbf{x}^T\mathbf{x} = 2$, so the diagonal kernel entries are $(1 + 2)^2 = 9$. Opposite inputs have $\mathbf{x}^T\mathbf{z} = -2$ and orthogonal inputs have $0$, so every off-diagonal entry is $1$. The Gram matrix is $\mathbf{K} = 8\mathbf{I} + \mathbf{1}\mathbf{1}^T$. The problem is symmetric, so try equal multipliers $\alpha_i = a$, which satisfy $\sum_i \alpha_i y_i = 0$. Then $\sum_{i,j} y_iy_jK_{ij} = 8 \cdot 4 + (\sum_i y_i)^2 = 32$, and the dual objective is $4a - 16a^2$. Its maximum is at $a = 1/8$. At this point every partial derivative $1 - a\sum_j y_iy_jK_{ij} = 1 - 8a$ of the dual is zero, so the point is optimal. The decision function is
>>$$f(\mathbf{x}) = \tfrac{1}{8}\big[(1 + x_1 + x_2)^2 + (1 - x_1 - x_2)^2 - (1 + x_1 - x_2)^2 - (1 - x_1 + x_2)^2\big] + b = x_1x_2 + b.$$
>>The point $(1, 1)$ needs $1 + b = 1$, so $b = 0$ and $f(\mathbf{x}) = x_1x_2$. All four points have $y_i f(\mathbf{x}_i) = 1$, so all are support vectors. The boundary is the pair of axes $x_1x_2 = 0$. In feature space $\|\mathbf{w}\|^2 = \sum_i\alpha_i = 0.5$, so the margin width is $2/\sqrt{0.5} \approx 2.83$. The SVM recovered the product feature $x_1x_2$, although no one supplied it as an input.

>[!example] (Hard) Two Greenhouse Readings and the RBF Width
>A greenhouse controller learns from two standardized humidity readings. The reading $x = 0$ is labeled dry ($y = -1$), and $x = 2$ is labeled wet ($y = +1$). The controller uses a hard-margin SVM with the RBF kernel.
>
>>[!example]- Solve the dual for general $\gamma$. Then compare the scores at $x = 0.5$ and $x = 5$ for $\gamma = 0.5$ and $\gamma = 5$.
>>The equality constraint forces $\alpha_1 = \alpha_2 = a$. The kernel values are $k(0, 0) = k(2, 2) = 1$ and $k(0, 2) = e^{-4\gamma}$. The dual objective is $2a - a^2(1 - e^{-4\gamma})$, with maximum at $a = 1/(1 - e^{-4\gamma})$. The bias formula at $x_s = 2$ gives $b = 1 - a(1 - e^{-4\gamma}) = 0$. The score is
>>$$f(x) = a\big(e^{-\gamma(x - 2)^2} - e^{-\gamma x^2}\big).$$
>>For $\gamma = 0.5$, $e^{-2} = 0.135$ and $a = 1.157$. Then $f(0.5) = -0.645$ and $f(5) = 1.157\,(e^{-4.5} - e^{-12.5}) = 0.0128$. For $\gamma = 5$, $a = 1.000$, $f(0.5) = -0.286$, and $f(5)$ is $0$ to four decimals. The reading at $5$ lies well beyond the wet example. Both models still score it almost on the boundary, because $f \to b = 0$ far from the data. The larger $\gamma$ also shortens the distance over which each support vector affects the score. The point $x = 0.5$ lies only a quarter of the way from dry to wet. With $\gamma = 5$ its score is already $-0.29$, far from the dry point's $-1$.
