>[!note] Replacement Policy
>A [[7.1 Cache|cache]]'s replacement policy is a method used to decide which data should be removed from the cache to make space for new data when the cache is full. Replacement policies include:
>- **Least Recently Used (LRU)** policy, where additional cache metadata tracks the order of access for each cache block and removes the block that has not been used for the longest time.
>- **Most Recently Used (MRU)** policy, similar to LRU in architecture, but removes the least recently used block.
>- **Queue types** (FIFO, LIFO, FILO, etc.).
