>[!notes] CSP Filtering
>Filtering improves [[3.1. Constraint Satisfaction Problems|CSP]] performance by **pruning variable domains early**, reducing the number of branches that violate constraints during backtracking search. Instead of waiting to discover a contradiction deep in the search tree, filtering anticipates conflicts and eliminates them ahead of time. There are multiple approaches to this:
>- **Forward checking** immediately prunes values that violate binary constraints from a variable $X$'s **unassigned** neighbors. It does so by checking if $X$'s domain still has at least one valid value. If a neighbor’s domain becomes empty, a backtrack is triggered.
>⠀
>- **Arc consistency (AC-3)** is a generalized version of forward checking, such that every value of a variable should be “supported” by at least one compatible value in each of its neighbors. In other words, given an **arc** $X_{i} \to X_{j}$:
>1. Begin by storing all arcs $X_{i} \to X_{j} \enspace \forall i,j$ in a queue $Q$.
>2. While $|Q| > 0$ or $|\operatorname{dom}(X_{i})| > 0 \enspace \forall i$:
>	- Pop an arc $X_i \to X_j$.
>	- Enforce the condition that for every value $v \in \operatorname{dom}X_i$, there exists some $w \in \operatorname{dom}X_j$ such that $(X_i = v, X_j = w)$ satisfies all constraints.
>		- If no such $w$ exists, remove $v$ from $X_i$’s domain.
>	- If at least one value is removed for $X_{i}$ when enforcing arc consistency for an arc $X_{i} \to X_{j}$, add arcs of the form $X_{k} \to X_{i}$ to $Q$ for all unassigned variables $X_{k}$. Do not add duplicate arcs.
>3. Perform a backtracking search if $\exists i \enspace \operatorname{dom}X_{i}=\emptyset$.
>⠀
>- **$k$-Consistency** is a generalized version of AC-3
