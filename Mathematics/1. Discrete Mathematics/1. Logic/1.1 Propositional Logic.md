>[!note] Propositions and Quantifiers
>A **proposition** is a logical statement which is either true or false. Propositions may be joined together to form propositional forms. We can join two propositions $P$ and $Q$ in the following basic ways:
>1. **Conjunction:** $P \land Q$ ("$P$ and $Q$"). True only when both $P$ and $Q$ are true.
>2. **Disjunction:** $P \lor Q$ ("$P$ or $Q$"). True when either (or both) $P$ or $Q$ are true.
>3. **Negation:** $\neg P$ ("not $P$"). True only when $P$ is false.

# Understanding
There are many more propositional forms, such as XOR ("Exclusive Or," denoted $\oplus$) and NAND ("Not And"). However, any other propositional form may be constructed using one or more of the previously defined fundamental forms. # Properties
##### *(DeMorgan's Laws)* $\neg (P \land Q) \equiv (\neg P \lor \neg Q)$, and $\neg (P \lor Q) \equiv (\neg P \land \neg Q)$.



# Examples
>[!example] Propositional Practice
>Convert the following English sentences into propositional logic. State whether the statement is true or false with a brief justification.
>>[!example]- There is a real number which is not rational.
>>The solution is $(\exists x \in \mathbb{R}) \enspace (x \notin \mathbb{Q})$. This is **true**, for example $\sqrt{ 2 }$ or $\pi$.
>
>>[!example]- All integers are natural numbers or are negative, but not both (XOR).
>>This is translated as $(\forall x \in \mathbb{Z}) \enspace (((x \in \mathbb{N}) \lor (x < 0)) \land \neg((x \in \mathbb{N}) \land (x < 0)))$. This is true, since we can define $0$ to be part of the naturals.
>
>>[!example]- If a natural number is divisible by 6, it is divisible by 2 or it is divisible by 3.
>>We can convert this as $(6 \mid x) \implies (2 \mid x) \lor (3 \mid x)$. This is true, since for all natural numbers $x$, $x=6k=2(3k)=3(2k)$.
>
>Now convert the following propositions into English sentences.
>>[!example]- $\neg(\forall x \in \mathbb{Q})(x \in \mathbb{Z})$
>>Since the negation applies to the statement rather the domain, $\neg(\forall x \in \mathbb{Q})(x \in \mathbb{Z}) \equiv (\exists x \in \mathbb{Q})(x \notin \mathbb{Z})$, which translates to "There exists a rational number that is not an integer." This is trivially true, since we have numbers such as $0.5$.
>
>>[!example]- $(\forall x \in \mathbb{Z})(((2 \mid x) \lor (3 \mid x)) \implies (6 \mid x))$
>>This means that "If any integer is divisible by two or three, then the integer is also divisible by six." This is false, since 2 and 3 are not divisible by 6.
>
>>[!example]- $(\forall x \in \mathbb{N})((x > 7) \implies ((\exists a,b \in \mathbb{N}) (a+b=x)))$
>>This statement directly translates to "If a natural number greater than 7 can be expressed as the sum of two other naturals." This is trivially true, since in one case we can write $a=x$ and $b=0$.
