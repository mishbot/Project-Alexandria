>[!note] Dropout
>**Dropout** sets a random subset of hidden units to zero at every training step. Each unit of a hidden layer $\mathbf{h}_\ell$ is kept with probability $p$, the **keep probability**, and zeroed otherwise, independently of the other units and of earlier steps:
>$$\tilde{h}_\ell[i] = r_i\, h_\ell[i], \qquad r_i \sim \text{Bernoulli}(p).$$
>A zeroed unit removes all of its incoming and outgoing weights for that step, so each step trains a slightly different subnetwork. Typical values are $p = 0.5$ for dense hidden layers and higher values near the input. In the backward pass the gradient is multiplied by the same mask, so zeroed units receive no gradient on that step.
>
>At test time every unit is active, so each unit receives more input than it did on average during training. Three versions handle this:
>- The **weight scaling inference rule** multiplies the activations, or equivalently the outgoing weights, by $p$ at test time.
>- **Inverted dropout**, which PyTorch uses, divides the kept activations by $p$ during training and changes nothing at test time.
>- **Monte Carlo dropout** keeps dropout on at test time, runs the network several times, and averages the predictions.
>
>In the first two a unit's expected training output equals its test output.
>
>Dropout makes the network rely less on any single unit and encourages redundant representations. It also tends to remove sharp kinks in the learned function that lie between training points and do not affect the loss. It acts like data augmentation applied inside the network. For linear regression with dropout on the input features, the expected training loss equals ridge regression with a feature-dependent penalty:
>$$\mathbb{E}_R\big[\|\mathbf{y} - (R \odot X)\check{\mathbf{w}}\|_2^2\big] = \|\mathbf{y} - pX\check{\mathbf{w}}\|_2^2 + p(1-p)\,\|\check{\Gamma}\check{\mathbf{w}}\|_2^2, \qquad \check{\Gamma} = \text{diag}(\|\mathbf{f}_1\|_2, \dots, \|\mathbf{f}_d\|_2).$$
>Here $R$ is a random mask with entries $R_{ij} \sim \text{Bernoulli}(p)$, $\odot$ is the elementwise product, and $\mathbf{f}_j$ is the $j$-th column of $X$. Dropout works well in dense layers and poorly in convolutional layers. Convolutional networks use two variants instead:
>- **Spatial dropout** drops whole channels.
>- **Cutout** masks a square of the input image.

>[!warning] Keep Probability or Drop Probability
>The lecture and the discussions write $p$ for the probability of *keeping* a unit. PyTorch's `nn.Dropout(p)` and the textbook state the probability of *dropping* it, which is $1 - p$ here. With PyTorch's convention the inverted-dropout scale is $1/(1 - p_{\text{drop}})$. Check the convention before plugging $p$ into any formula.

# Intuition

A network can fit its training data with units that only work together. One unit makes the function rise steeply, a second brings it back down, and a third cancels the second. The three create a kink between training points that costs nothing on the training loss and generalizes badly. Removing one of them at random breaks the arrangement and changes the output far from the data, as the figure shows. The next gradient step then pushes the remaining units to make up for the loss. Repeated over many steps, every unit learns to be useful on its own. Large detours that the data never asked for are gradually removed.

The randomness also makes dropout a cheap ensemble. A layer with $n$ units has $2^n$ possible masks, each a different subnetwork, and all of them share one set of weights. Training samples a new subnetwork at every step. Testing with all units active and scaled activations approximates the average prediction of the whole family without training or storing more than one network.

# Properties

#### *(Matching the Expected Activation)* The scaling by $p$ makes each unit's input at test time equal its expected input during training.

A unit that receives $\sum_i w_i\, r_i\, h_i$ during training has expected input $p\sum_i w_i h_i$. At test time, with every $r_i = 1$, its input would be $\sum_i w_i h_i$, larger by the factor $1/p$. Multiplying by $p$ at test time, or dividing by $p$ during training, removes the mismatch. For a linear network the match is exact in expectation. Through nonlinearities it is only approximate, because the average of $a[\cdot]$ over masks is not $a[\cdot]$ of the average input. Monte Carlo dropout avoids this approximation by averaging actual dropout predictions. The spread of those predictions also gives a rough measure of the model's uncertainty.

#### *(Ridge Regression in Disguise)* For linear regression, dropout on the inputs equals generalized ridge regression after rescaling the weights by $p$.

Substituting $\mathbf{w} = p\,\check{\mathbf{w}}$ into the identity in the callout gives
$$\|\mathbf{y} - X\mathbf{w}\|_2^2 + \frac{1-p}{p}\,\|\check{\Gamma}\mathbf{w}\|_2^2 = \|\mathbf{y} - X\mathbf{w}\|_2^2 + \|\Gamma\mathbf{w}\|_2^2, \qquad \Gamma = \sqrt{\frac{1-p}{p}}\;\check{\Gamma}.$$
The map $\check{\mathbf{w}} \mapsto p\,\check{\mathbf{w}}$ is invertible, so it maps the minimizer of the dropout objective to the minimizer of this Tikhonov problem. The factor $p$ is the same test-time scaling as in the weight scaling rule. The penalty on $w_j$ grows with $\|\mathbf{f}_j\|_2$, so features with large values are shrunk more. The strength $\sqrt{(1-p)/p}$ falls to $0$ as $p \to 1$, equals $1$ at $p = 0.5$, and grows like $1/\sqrt{p}$ as $p \to 0$.

#### *(Equal Column Norms)* After the ridge reparameterization, every feature column has the same norm, which resembles the rescaling done by batch normalization.

Rewriting the problem as standard ridge regression with penalty $\lambda\|\tilde{\mathbf{w}}\|_2^2$ requires $\tilde{\mathbf{w}} = \lambda^{-1/2}\Gamma\mathbf{w}$ and the data matrix $\tilde{X} = \sqrt{\lambda}\,X\Gamma^{-1}$. Its $j$-th column is $\sqrt{\lambda p/(1-p)}\;\mathbf{f}_j/\|\mathbf{f}_j\|_2$. All columns therefore have the norm $\sqrt{\lambda p/(1-p)}$. Dropout behaves like ridge regression on features rescaled to a common size. [[4.5.1. Batch Normalization|Batch normalization]] also rescales features, but it centers them as well and uses batch statistics with a learned scale and shift. Equal norms without centering do not give equal variances, so the two operations resemble each other without being equivalent.

#### *(Weak in Convolutional Layers)* Dropping single pixels of a feature map barely changes what the next layer sees, because neighboring pixels carry the same information.

Natural images are smooth, so a feature map's neighboring positions are strongly correlated. When one position is zeroed, its neighbors still pass nearly the same information forward, and the regularizing effect is small. **Spatial dropout** instead zeroes entire channels, the same channels at every position of an example. **Cutout** masks a square patch of the input image. Both remove information that the rest of the input cannot easily supply. Classic CNNs such as AlexNet applied ordinary dropout only to their dense layers.

# Derivation

We want to remove the expectation from the dropout objective for linear regression. Write $A = R \odot X$, so that the $i$-th prediction is $(A\check{\mathbf{w}})_i = \sum_j R_{ij} X_{ij} \check{w}_j$. Since $\mathbb{E}[R_{ij}] = p$, the mean prediction is $\mathbb{E}[A\check{\mathbf{w}}] = pX\check{\mathbf{w}}$. For any random vector $\mathbf{z}$, $\mathbb{E}\|\mathbf{y} - \mathbf{z}\|^2 = \|\mathbf{y} - \mathbb{E}\mathbf{z}\|^2 + \sum_i \text{Var}(z_i)$, so
$$\mathbb{E}\|\mathbf{y} - A\check{\mathbf{w}}\|_2^2 = \|\mathbf{y} - pX\check{\mathbf{w}}\|_2^2 + \sum_{i}\text{Var}\Big(\sum_j R_{ij} X_{ij}\check{w}_j\Big).$$
The mask entries are independent with variance $p(1-p)$, so the variance of each sum is the sum of the variances:
$$\sum_i \sum_j p(1-p)\, X_{ij}^2\, \check{w}_j^2 = p(1-p)\sum_j \check{w}_j^2\, \|\mathbf{f}_j\|_2^2 = p(1-p)\,\|\check{\Gamma}\check{\mathbf{w}}\|_2^2.$$
This is the identity in the callout. The mean term asks the scaled-down predictions to fit the data, and the variance term penalizes weights on features with large norms.

# Examples

>[!example] (Easy) Training and Test Activations
>A layer has activations $\mathbf{h} = [2, 4, 6, 8]$ and keep probability $p = 0.5$. One training step samples the mask $\mathbf{r} = [1, 0, 0, 1]$.
>
>>[!example]- What does the next layer receive on this step with plain dropout and with inverted dropout, and what should it receive at test time in each case?
>>Plain dropout passes $[2, 0, 0, 8]$, and inverted dropout passes $[4, 0, 0, 16]$. Over all masks, plain dropout passes $p\mathbf{h} = [1, 2, 3, 4]$ on average, so at test time the activations must be scaled to $[1, 2, 3, 4]$. Inverted dropout passes $\mathbf{h}$ on average, so at test time it passes $[2, 4, 6, 8]$ unchanged. A next-layer unit that sums its inputs would see $10$ on average during plain-dropout training. At test time it would see $20$ if the scaling were forgotten.

>[!example] (Medium) The Penalty Dropout Imposes
>A linear regression has two features with column norms $\|\mathbf{f}_1\|_2 = 2$ and $\|\mathbf{f}_2\|_2 = 10$, and it is trained with dropout on its inputs.
>
>>[!example]- Write the equivalent ridge penalty $\|\Gamma\mathbf{w}\|_2^2$ for $p = 0.8$ and for $p = 0.5$.
>>Here $\check{\Gamma} = \text{diag}(2, 10)$. For $p = 0.8$ the factor is $\sqrt{0.2/0.8} = 0.5$, so $\Gamma = \text{diag}(1, 5)$ and the penalty is $w_1^2 + 25\,w_2^2$. For $p = 0.5$ the factor is $1$, so $\Gamma = \text{diag}(2, 10)$ and the penalty is $4\,w_1^2 + 100\,w_2^2$. Dropping more units quadruples the penalty here. In both cases the weight on the large-norm feature is penalized $25$ times as heavily as the other, which is the ratio of the squared column norms.

>[!example] (Hard) How Noisy Is Dropout?
>A unit sums $n$ inputs, each equal to $1$, with inverted dropout at keep probability $p$: $z = \frac{1}{p}\sum_{i=1}^{n} r_i$.
>
>>[!example]- Find the mean and standard deviation of $z$ for $n = 100$ with $p = 0.5$ and with $p = 0.9$.
>>The mean is $\frac{1}{p} \cdot np = n = 100$ in both cases. The variance is $\frac{1}{p^2} \cdot np(1-p) = n(1-p)/p$. For $p = 0.5$ this is $100$, a standard deviation of $10$, or $10\%$ of the mean. For $p = 0.9$ it is $100 \cdot 0.1/0.9 \approx 11.1$, a standard deviation of $3.3$. The relative noise falls like $1/\sqrt{n}$, so a wide layer feels dropout less on each unit's total input than a narrow one. Lower keep probabilities inject more noise and therefore regularize more strongly.
