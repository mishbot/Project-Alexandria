**Regression** predicts a numeric response from one or more inputs. This folder starts with ordinary least squares for one predictor and for many, then fits curves on transformed inputs. It then adds penalties that trade a little bias for lower variance and ends with models nonlinear in their parameters. Robust fitting with [[4.4.1. RANSAC|RANSAC]] lives in Computer Vision, and [[2.3.2. Cross-Validation|cross-validation]] for choosing between models lives in Model Evaluation.

## Prerequisites

- [[1. Learning Paradigms]], for supervised learning and the difference between regression and classification.
- [[2. Model Evaluation]], for the error metrics and the train, validation and test splits used to compare fits.

## Contents

- [[3.1. Linear Regression]]: simple linear regression by OLS, the slope as covariance over variance, the Gaussian MLE view and residual checks.
  - [[3.1a. Multiple Linear Regression]]: matrix-form OLS $\hat{\boldsymbol\beta} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}$, the hat matrix, Gauss-Markov and inference with many predictors.
  - [[3.1b. Basis Function Regression]]: curves fit by OLS on polynomial, ReLU, Gaussian or Fourier features of the input.
- [[3.2. Regularization]]: penalized least squares, choosing $\lambda$, and when to use each penalty.
  - [[3.2.1. Ridge Regression]]: the $L_2$ penalty, its closed form, shrinkage along singular directions and weight decay.
  - [[3.2.2. Lasso]]: the $L_1$ penalty, soft-thresholding and sparse coefficient vectors.
  - [[3.2.3. Elastic Net]]: a mix of both penalties that selects groups of correlated predictors.
- [[3.3. Nonlinear Regression]]: models nonlinear in their parameters, fit by Gauss-Newton or Levenberg-Marquardt, with asymptotic inference.

## Recommended path

Read [[3.1. Linear Regression]] and [[3.1a. Multiple Linear Regression]] first. Then read [[3.2. Regularization]] and [[3.2.1. Ridge Regression]], which the deep learning notes use as a model problem. [[4. Classification]] reuses the same machinery for categorical responses.

## Cross-domain applications

- [[2.4 Time Series Regression]] applies these models to trend, seasonal and lagged predictors. It replaces random $k$-fold splits with [[2.4.5 Time-Series Cross-Validation|rolling-origin cross-validation]].
- [[3.8.1 Bayesian Linear Regression]] puts a prior on $\boldsymbol\beta$ and returns a posterior distribution instead of a point estimate.
