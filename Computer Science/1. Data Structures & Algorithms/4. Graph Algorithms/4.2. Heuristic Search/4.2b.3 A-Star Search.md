>[!note] A* Search
>**A* Search** is a search algorithm that expands the frontier node with the lowest estimated total cost, where $f(n) = g(n) + h(n)$. Here, $g(n)$ is the actual path cost from the start to $n$ as used in [[[4.2a.3 Uniform Cost Search|UCS]], and $h(n)$ is the estimated cost from $n$ to a goal. Like Greedy and UCS, it uses a priority queue, but its ordering is by $f(n)$. 
>
>A* is both complete and optimal when the heuristic is **admissible** and **consistent**, where
>- **Admissibility** ensures that the algorithm never overestimates the true cost to the goal, such that for any node $n$, it holds that$0 \le h(n) \le h^*(n)$, where $h^*(n)$ is the true minimal cost from $n$ to the goal.
>- Consistency ensures that $f(n)$ is nondecreasing along paths, such that for every transition $n \xrightarrow{a} n’$ with step cost $c(n,a,n’)$, it holds that $h(n) \le c(n,a,n’) + h(n’)$, where $n'$ is the next node after action $a$ has been applied to it. 
>
> A*'s worst-case time and space complexity are exponential in the depth of the solution, but in practice, a good heuristic can dramatically reduce the number of expanded nodes. It is one of the most widely used search algorithms in AI because it combines the efficiency of heuristic guidance with the guarantees of UCS.
