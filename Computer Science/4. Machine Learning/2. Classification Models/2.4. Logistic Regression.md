>[!note] Logistic Regression
>Logistic regression models a **binary output** $y \in \{0, 1\}$as a **probability** generated by a **linear function** of the inputs $x$. Given a dataset $\{(x_n, y_n)\}_{n=1}^N$, where $x_n \in \mathbb{R}^D$ and $y_n \in \{0,1\}$, we assume the model
>$$p(t=1|x, w) = \sigma(w_0 + w_1x_1 + \dots + w_Dx_D) = \sigma(w^\top x),$$
>where $\sigma(a) = \dfrac{1}{1 + e^{-a}}$ is the **sigmoid** (logistic) function that squashes real values into $[0, 1]$.
>
>One way to estimate the optimal parameters $w^*$ is by [[1.2.1 Maximum Likelihood Estimation|maximizing the likelihood]] of the observed binary (Bernoulli) labels under this probabilistic model. For each observation, it follows that
>$$p(y_n | x_n, w) = (\hat{y}_n)^{y_n} (1 - \hat{y}_n)^{1 - y_n},$$
>where $\hat{y}_n = \sigma(w^\top x_n)$. We minimize the **negative log-likelihood**, also known as the **cross-entropy loss**. Note here since the points are independent, the joint likelihood is just a product of the individual probabilities:
>$$E(w) = -\sum_{n=1}^N [y_n \ln \hat{y}_n + (1 - y_n)\ln(1 - \hat{y}_n)]=\begin{cases} -\ln y_{n} & t_{n}=1 \\ -\ln(1-y_{n}) & t_{n}=0.\end{cases}$$
>This loss is **convex**, ensuring a unique global minimum. Unlike linear regression, there is **no closed-form solution** for logistic regression, because $y_n = \sigma(w^\top x_n)$ depends nonlinearly on $w$.

# Derivation
To reason about logistic regression, we need to think in terms of probabilities. Take in the following sentence: logistic regression models the log-odds of class $C_{1}$ versus $C_{2}$ as a linear model. Essentially, we have
$$\ln\left( \frac{P(C_{1} \mid x)}{P(C_{2} \mid x)} \right) = \ln\left( \frac{P(C_{1} \mid x)}{1-P(C_{1} \mid x)} \right)=w^Tx,$$
