# Computer Vision

Computer vision studies how to extract geometric and semantic structure from images, and computational photography studies how to create and edit them. The field's two grand questions, *where is this in 3D?* and *what is this?*, drive the sections below: classical image processing and geometry (sections 1 to 6), statistical models of images (section 9), and modern learned representations and generators (sections 7 and 8).

## Deep Learning Foundations
Section 8 relies on four notes from [[5. Deep Learning]]. They sit there so that CS 182 notes can build on them. Read each one before the section 8 note that uses it.
- [[10.3.2. Flow Matching|Flow Matching]]: a network learns the velocity that moves a noise sample toward a clean image. Sampling follows that velocity with Euler steps. [[8.6. Flow-Based Image Editing]] uses a pretrained flow model for every edit.
- [[10.3.2. Classifier-Free Guidance|Classifier-Free Guidance]]: the model predicts one velocity with the prompt and one without it. Guidance pushes the final velocity further in the direction from the second to the first. [[8.6. Flow-Based Image Editing]] applies it in every application.
- [[10.1. Generative Adversarial Networks|Generative Adversarial Networks]]: a generator learns to make images that a discriminator cannot tell apart from real ones. [[8.4. Pix2Pix]] and [[8.5. CycleGAN]] add this adversarial loss to their translation losses.
- [[6.4. U-Net|U-Net]]: an encoder-decoder network with skip connections, so the output keeps the input's fine spatial detail. It is the generator in [[8.4. Pix2Pix]] and the velocity network in the Project 3 flow model.
