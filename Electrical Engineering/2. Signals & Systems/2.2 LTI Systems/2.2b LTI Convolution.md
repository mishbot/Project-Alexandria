>[!note] LTI Convolution Representation
>Given a discrete-time input signal $x(n)$, the output of a discrete-time [[2.2a LTI System|LTI system]] $y(n)$ can be represented as a weighted combination of impulse responses $h[n]$, such that
>$$y(n) = x(n) * h(n) = \sum^{\infty}_{k=-\infty}x(k)h(n-k)=\sum^{\infty}_{k=-\infty}x(n-k)h(k).$$ 
>Similarly, given a continuous-time input signal $x(t)$, the output of a continuous-time LTI system $y(t)$ can be represented as
>$$y(t) = x(t) * h(t) = \int^{\infty}_{-\infty}x(\tau)h(t-\tau)d\tau = \int^{\infty}_{-\infty}x(t - \tau)h(\tau)d\tau.$$

# Properties
#### (*Polynomialization*) If for the polynomials $\hat{y}(z)=\hat{x}(z)\hat{h}(z)$, then $y_k=(h * x)_k$ where $\hat{y}(z)=\sum^{\infty}_{k=-\infty}y_kz^k$.
We start by expanding with the fact that $\hat{y}(z)=\sum^{\infty}_{i=-\infty}\sum^{\infty}_{j=-\infty}(x_iz^i)(h_jz^j)$. We can perform a change of variables for $k=i+j$, such that
$$\hat{y}(z)=\sum^{\infty}_{k=-\infty}\sum^{\infty}_{j=-\infty}x_kh_{k-i}z^k.$$
By definition, $\hat{y}(z)=\sum^{\infty}_{k=-\infty}y_kz^k$, and therefore $y_k=\sum^{\infty}_{j=-\infty}y_kz^kx_kh_{k-i}$.

#### (*Multiplication in Frequency*) If $y(t) = (x\ast h)(t)$, then $Y(\omega) = X(\omega)H(\omega)$.

>[!example] Cascade
>Suppose we have two FIR filters, $a(n)$ and $b(n)$, such that their impulse response is given by
>$$\begin{align}
>a(n) &= a_0\delta(n) + a_1\delta(n-1)+ \ldots + a_N\delta(n-N) && (\text{where } N \in \mathbb{N}), \\  &\text{and} \\ b(n) &= b_0\delta(n) + b_1\delta(n-1)+ \ldots + b_M\delta(n-M) && (\text{where } M \in \mathbb{N}).
>\end{align}$$
>The two filters are placed in a cascade $C$, such that the final system is
>$$x \rightarrow \boxed{\boxed{A} \rightarrow \boxed{B}}^C \rightarrow y.$$
>We can find the cascade by setting $x(n) = \delta(n)$. Then,
>$$\begin{align}
>y(n) &= [(x * a) * b].
>\end{align}$$
>Since the impulse response of any system is its filter, we can simplify this into
>$$\begin{align}
>c(n) &= (a * b) \\
>&= \sum^{\infty}_{k=-\infty} a(k)b(n-k) \\
>\end{align}$$
>Here, we can see that $a(k)b(n-k)$ is equal to
>$$a_0b_0\delta(k)\delta(n-k) + a_0b_1\delta(k)\delta(n-k-1) + a_1b_0\delta(k-1)\delta(n-k) + a_1b_1\delta(k-1)\delta(n-k-1) + \ldots,$$
>and therefore
>$$\begin{align}
>c(n) &= a_0b_0\delta(n) + (a_0b_1 + a_1b_0)\delta(n-1) + (a_0b_2 + a_1b_1 + a_2b_0)\delta(n-2) + \ldots
>\end{align}$$
>This means that we can model any coefficient $c_n$ of the cascade ($n \leq N$) as
>$$c_n = \sum^{n}_{k=\max(0, n - M)}a_kb_{n-k},$$
>where $k=\max(0, n-M),$ as the two systems are of different sizes, and we need to account for cases where $M < N$. Finally, we can express $c$ as
>$$c(n) = c_0\delta(n) + c_1\delta(n-1) + \ldots + c_{N+M}\delta(n-N-M).$$
