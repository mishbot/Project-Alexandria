>[!note] Subgame Perfect Nash Equilibrium
>A strategy profile $s^*$ constitutes a subgame perfect Nash equilibrium if for every [[3.2a Subgame|subgame]] $G_E^d$ with root note $d$  in $G_E$, $s^*$ constitutes a [[2.2c Nash Equilibrium|Nash equilibrium]] within $G_E^d$.
>
>Equivalently, a strategy profile $s^*$ constitutes an SPNE if $\forall s_i \in s^*$, every $s_i$ is [[3.2 Sequential Rationality|sequentially rational]] at the root node.
>
>The path of play in a subgame perfect Nash equilibrium is known as the **equilibrium path**.
>>[!warning] Note!
>>The SPNE can never involve mixing in extensive form games of perfect information, since every player's action is observable.
# Intuition
What is the difference between NE and SPNE? Well:
- Nash equilibrium requires rational behavior (best response) only on the path of play.
- SPNE requires rational behavior **ON AND OFF** the path of play.
	- Done to add credibility to threats; if a strategy is not rational, then threatening with it will be irrational.

How do we find SPNEs? Using backward induction. Start at the last non-terminal node. Check the best response of the player at that node. Do so for all nodes on that level. Go back one level, and do the same for the other player. More on this in the future!

# Properties
#### *(Existence)* At least one SPNE exists in any finite extensive form game.
#### (*Uniqueness)* If no players are indifferent between terminal nodes, there is a unique SPNE.
