>[!note]
>A set $\mathcal{X} \subseteq \mathbb{R}^n$ is **open** if for any $x \in \mathcal{X}$, there exists an Euclidean ball $B_{\epsilon}(x)=\{ y \in \mathbb{R}^n : \| y-x \|_{2} \}$ with some radius $\epsilon > 0$, such that $B_{\epsilon}(x) \subseteq \mathcal{X}$. Similarly, $\mathcal{X}$ is said to be **closed** if its complement $\mathbb{R}^n \backslash \mathcal{X}$ is open. An example of an open set is any interval $(a,b)$.
