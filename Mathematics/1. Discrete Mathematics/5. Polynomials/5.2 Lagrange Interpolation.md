>[!note] Lagrange Interpolation
>**Lagrange interpolation** is a method for constructing the unique [[5.1 Polynomials|polynomial]] of degree at most $d$ that passes through a given points number of points. For $d+1$ points $(x_1, y_1), \dots, (x_{d+1}, y_{d+1})$ with all $x$-values distinct, the **Lagrange interpolating polynomial** is defined as
>$$f(x)=\sum^{d+1}_{i=1}y_{i} \cdot \Delta_{i}(x),$$
>where each $\Delta_i(x)$ is a polynomial that equals $1$ at $x_i$ and $0$ at all other $x_j$, defined by
>$$\Delta_{i}(x)=\dfrac{\prod^{}_{j \neq i}(x-x_{j})}{\prod^{}_{j \neq i}(x_{i}-x_{j})}.$$
>
>Each term $y_i \cdot \Delta_i(x)$ “activates” the value $y_i$ at point $x_i$, and the sum reconstructs a polynomial that agrees with all $d+1$ given points.
# Intuition
At its core, the Lagrange interpolation polynomial $f(x)$ acts like a selector. It’s designed so that at any known input $x_i$, only the corresponding output value $y_i$ “activates,” while all the other terms go to zero. That means at each known data point, the polynomial behaves exactly like a switchboard: it connects the input $x_i$ to the output $y_i$, and only that one. For all other $x_j \neq x_i$, the function returns zero, so their corresponding $y_j$ values are effectively ignored at that moment.

The key to this selective behavior lies in the construction of each basis function $\Delta_i(x)$. The numerator of $\Delta_i(x)$ includes the variable $x$ and every $x_j$ where $j \neq i.$ That’s why $\Delta_i(x)$ is zero when $x = x_j$ for any $j \neq i$: it contains a factor like $(x - x_j)$, which kills the whole term. But when $x = x_i$, none of those subtracted terms zero out, so the numerator becomes a meaningful, nonzero number. This structure ensures that $\Delta_i(x) $only “activates” for the one point it’s designed to represent.

The denominator plays the role of a normalizing constant. It’s calculated by plugging the target input $x_i$ into the same expression used in the numerator. Since we know that’s the only input that makes the numerator nonzero, we simply scale the entire fraction so that $\Delta_i(x_i) = 1$. This is critical, as it ensures that when we multiply $\Delta_i(x) by y_i$, the result is exactly $y_i$ at $x = x_i$, not some scaled version of it. For every other $x_j$, the numerator vanishes, and $\Delta_i(x_j) = 0$, meaning $y_j$ won’t interfere.
# Examples
>[!example] (Medium) Lagrange? More like Lamegrange.
>In this problem, you will walk through an alternative to Lagrange interpolation.
>
>To begin, let’s say we wanted to interpolate a polynomial through a single point, $(x_{0}, y_{0})$.
>>[!example]- What would be the polynomial that we would get?
>>Since we’re only given a single point, there’s not enough information to determine any slope or curvature. The only polynomial that fits is a constant function, so we get a degree-zero polynomial $f_{0}(x) = y_0$.
>
>Call the polynomial from the previous part $f_{0}(x)$. Now say we wanted to define the polynomial $f_{1}(x)$ that passes through the points $(x_{0}, y_{0})$ and $(x_{1}, y_{1})$.
>
>>[!example]- If we write $f_{1}(x) = f_{0}(x) + a_{1}(x−x_{0})$, what value of $a_{1}$ causes $f_{1}(x)$ to pass through the desired points?
>>Let $f_{0}(x)=y_{0}$. Then, $f_{1}(x)=y_{0} + a_{1}(x-x_{0})$. For the nontrivial input-output pair $(x_{1}, y_{1})$, the polynomial turns into $y_{1}=y_{0}+a_{1}(x_{1}-x_{0}) \iff a_{1}=\dfrac{y_{1}-y_{0}}{x_{1}-x_{0}}$, which is precisely the slope of the line connecting the two points.
>
>Now say we want a polynomial $f_2(x)$ that passes through $(x_{0}, y_{0})$, $(x_{1}, y_{1})$, and $(x_{2}, y_{2})$. 
>>[!example]- If we write $f_{2}(x) = f_{1}(x) + a_{2}(x−x_{0})(x−x_{1})$, what value of $a_{2}$ gives us the desired polynomial?
>>Let $f_{2}(x)=y_{0}+\dfrac{y_{1}-y_{0}}{x_{1}-x_{0}}(x-x_{0})+a_{2}(x-x_{0})(x-x_{1})$. Plugging $(x_{2}, y_{2})$, we obtain $$y_{2}=y_{0}+\dfrac{y_{1}-y_{0}}{x_{1}-x_{0}}(x_{2}-x_{0})+a_{2}(x_{2}-x_{0})(x_{2}-x_{1}),$$
and solve for $a_{2}$ such that
$$a_{2}=\frac{y_{2}-y_{0}}{(x_{2}-x_{0})(x_{2}-x_{1})}-\frac{y_{1}-y_{0}}{(x_{1}-x_{0})(x_{2}-x_{1})} = \frac{ \frac{y_2 - y_0}{x_2 - x_0} - \frac{y_1 - y_0}{x_1 - x_0} }{x_2 - x_1}.$$
