>[!note] Markov Chain
>A **discrete-time Markov chain (DTMC)** is a model used to represent systems that move randomly between states in discrete steps, where the future state depends only on the current state. Formally, a sequence of random variables $(X_{n})_{n \in \mathbb{N}}$ is a DTMC on the state space $\mathcal{X}$ if it satisfies the **Markov property**,
>$$\mathbb{P}(X_{n+1} = x_{n+1} \mid X_{n} = x_{n}, \ldots, X_{0} = x_{0}) = \mathbb{P}(X_{n+1} = x_{n+1} \mid X_{n} = x_{n})=P(x_{n}, x_{n+1}).$$
>When  $\mathcal{X}$ is finite, the set of one-step transition probabilities $\{ P(x_{n}, x_{n+1}) : x_{n},x_{n+1} \in \mathcal{X}\}$ can be organized into a row-stochastic one-step **transition probability matrix** $P \in \mathbb{R}^{|\mathcal{X}| \times |\mathcal{X}|}$, such that its rows sum to one. Then, the $k$-step transition equation is given as $P_{k}(x,y)=\mathbb{P}(X_{k}=y \mid X_{0} = x) = P^k(x,y)$.
>
>States in $\mathcal{X}$ can be characterized using hitting times. The **hitting time** $T_{x} = \min\{n \in \mathbb{Z}_{+} : X_{n}=x\}$ of a state $x \in \mathcal{X}$ in a Markov chain is a random variable denoting the number of time steps required for the chain to visit $x$ for the first time. Let $\rho_{x,y}=\mathbb{P}(T_{y} < \infty \mid X_{0}=x)$ be the probability of reaching state $y$ when starting at state $x$. Then:
>- State $x$ is **transient** if there's a nonzero chance of never returning after leaving (i.e., $\rho_{x,x} < 1$).
>- State $x$ is **recurrent** if you're guaranteed to return to it eventually (i.e., $\rho_{x,x}=1$). That is:
>	- State $x$ is **null recurrent** if the chain takes an infinite amount of time, on average, to return to $x$ (i.e., $\mathbb{E}[T_{x} \mid X_{0} = x] = \infty$).
>	- State $x$ is **positive recurrent** if $\mathbb{E}[T_{x} \mid X_{0} = x] < \infty$.
>		- State $x$ is **absorbing** if you never leave it once you enter it (i.e., $\mathbb{E}[T_{x} \mid X_{0} = x]=0$).
>
>We say that state $x$ **communicates** with state $y$ (i.e., $x \leftrightarrow y$) if it is possible to reach both state $y$ from state $x$ and state $x$ from state $y$, for which $\rho_{x,y} >0$ and $\rho_{y,x} > 0$. A **communicating class** is a maximal set of states $C \subseteq \mathcal{X}$ which communicate with each other, such that $x \leftrightarrow y, \space \forall x,y \in C$. A Markov chain is **irreducible** if every state can be reached from every other state, such that $C=\mathcal{X}$. More particularly:
>- If a finite Markov chain is irreducible, then it contains exclusively positive recurrent states.
>- If an infinite Markov chain is irreducible, then it contains exclusively positive recurrent, null recurrent, or transient states.
> 
>>[!warning] Dependence on Past States
>>The fact that knowledge of the current state $X_{n}$ fully determines the distribution of the next state $X_{n+1}$ does not imply that $X_{n+1}$ is independent of all $X_{n-k}$ for $k \geq 1$. In general, the random variables in a Markov chain are *not independent*.
