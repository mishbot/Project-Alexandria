>[!note] Multi-Level Paging
>Multi-level paging employs multiple page tables to handle large address spaces without requiring an excessively large single-level page table, which would consume significant memory. There are two parts of a multi-level paging system:
>- One **first-level page table**, stored in RAM (memory), that contains the PPN of all second-level page tables.
>- Multiple **second-level page tables**, which contain the PPNs of the desired data, and can be offloaded to the disk.
