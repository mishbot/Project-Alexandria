>[!note] Multilevel Caching
>Multilevel [[7.1 Cache|caching]] is a hierarchical cache system designed to bridge the speed gap between a computer’s processor and its main memory. As caches get further away from the CPU, their size usually increases and their speed becomes slightly slower. For an $i$-th level cache in an $n$-level caching system:
>- Cache level $i$'s **hit time** is $T_{H_i}=\sum^{i}_{j=1}H_j$, where each $H_j$ is instead the access time of each cache $j<i$.
>- Cache level $i$'s hit/miss rates are independent of the previous cache levels.
