>[!note] Random Variable
>A **random variable** is a real-valued function $X$: $\Upomega \to \mathbb{R}$ that assigns to each [[1.1 Probability Space|sample point]] (outcome) $\upomega \in \Upomega$ a real number, $X(\upomega) \in \mathbb{R}$. 
>
>- **Discrete random variables** feature a *countable* range $\mathcal{X} = \set{X(\upomega): \upomega \in \Upomega}$, such that for every $x \in \mathcal{X}$, the set
>$$\set{\upomega \in \Upomega: X(\upomega) = x} \in \mathcal{F}$$
>is an **event** in the sample space containing all the outcomes where the random variable $X$ equals the specific value $x \in \mathcal{X}$.
>‎ 
>- **Continuous random variables** can take on any value within a given interval of the [[1.1 Probability Space|continuous sample space]], such that they feature an *uncountable* range $\mathcal{X}=[a, b]$ for some bounds $a,b \in \mathbb{R}$.
>
