>[!note] Moore-Penrose Pseudoinverse
>Any matrix $A \in \mathbb{R}^{m \times n}$ with rank $r \leq \mathrm{min}(m, n)$ and [[13. Singular-Value Decomposition|SVD]] $A=U\Sigma V^T$ has a **Moore-Penrose pseudoinverse**, defined as 
>$$
>A^\dagger = V\Sigma^\dagger U^T \in \mathbb{R}^{n \times m},
>$$
>where $\Sigma^\dagger = \begin{bmatrix}\Upsigma_r^{-1} & 0_{r \times (m-r)} \\ 0_{(n-r) \times r} & 0_{(n-r) \times (m-r)}\end{bmatrix} \in \mathbb{R}^{n \times m}$, with $\Upsigma^{-1}_{r} = \operatorname{diag}(\dfrac{1}{\sigma_{1},}, \ldots, \dfrac{1}{\sigma_{r}}) \in \mathbb{S}^r_{++}$.

# Properties
#### (*Left Inverse*) If $\operatorname{Rank}(A) = n \leq m$ (full col. rank), $A^{\dagger}A = V_{r}V_{r}^T=VV^T=I_{n}$.

#### (*Right Inverse*) If $\operatorname{Rank}(A) = m \leq n$ (full row rank), $AA^{\dagger} = U_{r}U_{r}^T = UU^T=I_{m}$.

#### (*Left Decomposition*) If $\operatorname{Rank}(A) = n \leq m$, then $A^{\dagger} = (A^TA)^{-1}A^T$.
#### (*Right Decomposition*) If $\operatorname{Rank}(A) = m \leq n$, then $A^{\dagger} = A^T(AA^T)^{-1}$.
#### (*Reflexivity*) $AA^{\dagger}A = A$ and $A^{\dagger}AA^{\dagger} = A^{\dagger}$.
#### (Invertibility Equality) If $A$ is invertible, $A^{\dagger} = A^{-1}$.
#### (*Orthogonal Projectors*) $P_{\mathcal{R}(A)}=AA^{\dagger} = U_{r}U_{r}^T$ and $P_{}A^{\dagger}A = V_{r}V_{r}^T$.
