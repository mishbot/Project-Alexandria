>[!note] Page Fault
>Page faults are exceptions that occur when an accessed [[8.2b Page Table|page table entry]] has a valid bit off, which suggests that the entry's data is stored in the disk rather than in physical memory.
>
>Page faults are handled by the [[8.3a Trap Handler|trap handler]], which loads data from the disk. Sometimes, if loading from disk takes many cycles, the trap handler may also perform a [[8.3b Context Switches|context switch]] to allow another process to utilize the CPU in the meantime.
