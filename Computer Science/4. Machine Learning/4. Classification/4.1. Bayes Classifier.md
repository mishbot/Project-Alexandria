>[!note] Bayes Classifier
>**Classification** assigns an input $\mathbf{x} \in \mathbb{R}^d$ to one of $K$ discrete classes, labeled $k = 1, \dots, K$. The problem is **binary classification** when $K = 2$ and **multi-class classification** when $K > 2$. Binary problems usually label the classes $0$ and $1$. A classifier $h : \mathbb{R}^d \to \{1, \dots, K\}$ splits the input space into **decision regions** $\mathcal{R}_k = \{\mathbf{x} : h(\mathbf{x}) = k\}$. The surfaces between the regions are the **decision boundaries**. For a linear classifier each boundary is a $(d-1)$-dimensional hyperplane: a point when $d = 1$, a line when $d = 2$ and a plane when $d = 3$. A dataset is **linearly separable** when some hyperplane puts all points of each class on their own side.
>
>A classifier is scored by its **0-1 risk**, the probability that it predicts the wrong class:
>$$R(h) = \mathbb{P}\big[h(\mathbf{x}) \neq y\big] = \mathbb{E}\big[\mathbb{1}\{h(\mathbf{x}) \neq y\}\big].$$
>Here $(\mathbf{x}, y)$ is drawn from the joint distribution of inputs and labels. The indicator $\mathbb{1}\{\cdot\}$ equals $1$ when its condition holds and $0$ otherwise. The **Bayes classifier** picks the class with the largest posterior probability. [[1.6 Bayes' Rule|Bayes' rule]] writes that posterior with class densities and priors:
>$$h^*(\mathbf{x}) = \arg\max_k\, \mathbb{P}(y = k \mid \mathbf{x}) = \arg\max_k\, p(\mathbf{x} \mid y = k)\, \pi_k.$$
>Here $p(\mathbf{x} \mid y = k)$ is the **class-conditional density** of class $k$, and $\pi_k = \mathbb{P}(y = k)$ is its **prior**. No classifier has a lower 0-1 risk than $h^*$. The risk of $h^*$ is the **Bayes error rate**,
>$$R^* = \mathbb{E}_{\mathbf{x}}\Big[1 - \max_k\, \mathbb{P}(y = k \mid \mathbf{x})\Big],$$
>where the expectation runs over the input distribution. $R^*$ is positive whenever the classes overlap.
>
>Unequal error costs move the binary threshold. Let $c_{\text{FP}}$ be the cost of a false alarm and $c_{\text{FN}}$ the cost of a missed positive. The rule with the lowest expected cost predicts class $1$ when
>$$\mathbb{P}(y = 1 \mid \mathbf{x}) > \frac{c_{\text{FP}}}{c_{\text{FP}} + c_{\text{FN}}}.$$
>Equal costs give the threshold $1/2$, which is the Bayes classifier.
>
>The true posterior is unknown, so practical classifiers take one of three approaches (Bishop, *PRML*, ch. 4):
>
>- **Discriminant functions** map an input straight to a class, with no probabilities. Examples are [[4.2. Linear Discriminants|linear discriminants]], the [[1. Perceptrons|perceptron]] and [[4.4. Support Vector Machines|support vector machines]].
>- **Generative models** fit $p(\mathbf{x} \mid y = k)$ and $\pi_k$, then apply Bayes' rule. Examples are [[6.5. Naive Bayes|naive Bayes]] and the Gaussian models LDA and QDA in [[4.2. Linear Discriminants]].
>- **Discriminative models** fit $\mathbb{P}(y = k \mid \mathbf{x})$ directly and never model how $\mathbf{x}$ arises. Examples are [[4.3. Logistic Regression|logistic regression]] and [[4.3a. Softmax Regression|softmax regression]], both trained by minimizing cross-entropy.
>

# Intuition

Picture healthy and faulty machines whose vibration readings overlap. Suppose that at one reading, 80% of machines are faulty. Any rule must guess there. Guessing "faulty" is wrong 20% of the time, and guessing "healthy" is wrong 80% of the time. The Bayes classifier takes the more probable class at every input. It therefore makes the smallest possible error at each input. It carries Bayes' name because it computes the posterior with Bayes' rule, from the class densities and the class frequencies.

Nobody knows the true distribution, so the Bayes classifier serves as a benchmark. Each practical method estimates some part of it from data. A generative model estimates the densities and the priors. A discriminative model estimates the posterior. A discriminant function learns only the boundary. The Bayes error is the error that remains with perfect knowledge. A better model can remove the part of its error above $R^*$. No model can reach an error below $R^*$.

Each curve is a class prior times its density. The Bayes rule predicts the class with the higher curve, and the gray area is the Bayes error. As the prior $\pi_1$ grows, the boundary moves and the error falls.

# Properties

#### *(Zero Bayes Error)* The Bayes error is zero only when the label is a deterministic function of the input.

For two classes, write $\eta(\mathbf{x}) = \mathbb{P}(y = 1 \mid \mathbf{x})$. The Bayes error becomes $R^* = \mathbb{E}[\min(\eta(\mathbf{x}), 1 - \eta(\mathbf{x}))]$, which vanishes only if $\eta$ is $0$ or $1$ for almost every input. Label noise and missing features keep $\eta$ away from $0$ and $1$. An informative new feature can lower $R^*$, because the posterior then conditions on more information. When the training error falls far below any plausible Bayes error, the model is [[2.3. Generalization|overfitting]]. It has then fit noise that no rule can predict on new data.

#### *(Separable Is Not Error-Free)* A linearly separable training set says little when the dimension is large compared with the sample size.

Any $n \le d + 1$ points in general position in $\mathbb{R}^d$ are linearly separable under all $2^n$ labelings. Cover (1965) counted the separable labelings for larger $n$. At $n = 2(d + 1)$ points, exactly half of all labelings are separable. A separable sample in many dimensions can therefore arise by chance, even when the classes overlap heavily. On separable data, unregularized [[4.3. Logistic Regression|logistic regression]] has no finite solution, and its weights grow without bound.

#### *(Shifting Priors)* When class frequencies change between training and deployment, the posterior odds change by the ratio of the priors.

Bayes' rule in odds form splits the posterior odds into a likelihood ratio and the prior odds:
$$\frac{\mathbb{P}(y = 1 \mid \mathbf{x})}{\mathbb{P}(y = 0 \mid \mathbf{x})} = \frac{p(\mathbf{x} \mid y = 1)}{p(\mathbf{x} \mid y = 0)} \cdot \frac{\pi_1}{\pi_0}.$$
A generative model can adapt to new priors $\pi_0', \pi_1'$ by swapping them in, with no retraining (Bishop, *PRML*, sec. 1.5.4). A discriminative model needs its log-odds shifted by $\log(\pi_1'\pi_0 / (\pi_0'\pi_1))$. This correction assumes the class densities stay the same. A model trained on balanced data and deployed where 1% of cases are positive needs a shift of $\log(0.01/0.99) = -4.60$.

#### *(Reject Option)* A classifier can refuse to decide when its largest posterior is too small.

With a threshold $\theta$, the rule outputs a class only when $\max_k \mathbb{P}(y = k \mid \mathbf{x}) \ge \theta$ and defers otherwise (Bishop, *PRML*, sec. 1.5.3). Raising $\theta$ toward $1$ rejects more inputs, and any $\theta \le 1/K$ rejects none. A screening model in a hospital can pass its uncertain cases to a doctor. The error rate on the accepted inputs falls as the reject rate rises. The rule needs calibrated probabilities, which [[2.2.4. Log Loss|log loss]] measures.

#### *(Generative Versus Discriminative)* Generative classifiers often win with little data, and discriminative classifiers often win with a lot.

A generative model must describe the whole input distribution, which is hard when $d$ is large. In exchange, its extra assumptions give it lower variance. Ng and Jordan (2002) compared naive Bayes with logistic regression on the same features. Naive Bayes approached its limiting error with a number of samples logarithmic in $d$. Logistic regression needed a number linear in $d$. Logistic regression reached a lower limiting error when the naive Bayes independence assumption was wrong.

# Derivation

We want to show that no classifier has a lower 0-1 risk than $h^*$. Conditioning on the input, the law of total expectation gives
$$R(h) = \mathbb{E}_{\mathbf{x}}\Big[\mathbb{P}\big(y \neq h(\mathbf{x}) \mid \mathbf{x}\big)\Big] = \mathbb{E}_{\mathbf{x}}\Big[1 - \mathbb{P}\big(y = h(\mathbf{x}) \mid \mathbf{x}\big)\Big].$$
The choice of $h(\mathbf{x})$ at one input does not affect the bracket at any other input. So the risk is smallest when the bracket is smallest at each $\mathbf{x}$ separately. The bracket is smallest for the class with the largest posterior, which is $h^*(\mathbf{x})$. The bracket then equals $1 - \max_k \mathbb{P}(y = k \mid \mathbf{x})$, and its expectation is $R^*$.

The same argument handles costs. Fix an input and write $p = \mathbb{P}(y = 1 \mid \mathbf{x})$. Predicting $1$ costs $c_{\text{FP}}$ when $y = 0$, so its expected cost is $c_{\text{FP}}(1 - p)$. Predicting $0$ has expected cost $c_{\text{FN}}\,p$. Predicting $1$ is cheaper when $c_{\text{FN}}\,p > c_{\text{FP}}(1 - p)$, which rearranges to $p > c_{\text{FP}}/(c_{\text{FP}} + c_{\text{FN}})$. In terms of densities, the rule predicts $1$ when the likelihood ratio $p(\mathbf{x} \mid y = 1)/p(\mathbf{x} \mid y = 0)$ exceeds $c_{\text{FP}}\pi_0/(c_{\text{FN}}\pi_1)$.

# Examples

>[!example] (Easy) A One-Word Spam Filter
>A spam filter sees one feature: whether an email contains the word "free". Of all emails, 30% are spam. The word appears in 60% of spam emails and in 5% of legitimate ones.
>
>>[!example]- What does the Bayes classifier predict for each kind of email, and what is its error rate?
>>For emails with "free", the joint probabilities are $0.3 \cdot 0.6 = 0.18$ for spam and $0.7 \cdot 0.05 = 0.035$ for legitimate mail. The posterior is $\mathbb{P}(\text{spam} \mid \text{free}) = 0.18/0.215 = 0.837$, so the filter predicts spam. For emails without the word, the joint probabilities are $0.3 \cdot 0.4 = 0.12$ and $0.7 \cdot 0.95 = 0.665$. The posterior of spam is $0.12/0.785 = 0.153$, so the filter predicts legitimate. The errors are the legitimate emails with "free" and the spam emails without it, so $R^* = 0.035 + 0.12 = 0.155$. No filter that sees only this feature can do better than 15.5%.

>[!example] (Medium) Vibration Sensors and a Rare Fault
>A factory measures the vibration $x$ of each pump. Healthy pumps give $x \sim \mathcal{N}(0, 1)$ and faulty pumps give $x \sim \mathcal{N}(2, 1)$.
>
>>[!example]- Find the Bayes threshold and error when half the pumps are faulty. Then repeat with 10% faulty, and check the old threshold under the new rate.
>>With equal priors the two densities cross at the midpoint, so the Bayes classifier predicts "faulty" for $x > 1$. Each class falls on the wrong side with probability $\Phi(-1)$, where $\Phi$ is the standard normal CDF. The Bayes error is $\Phi(-1) = 0.159$. With $\pi_1 = 0.1$, the posterior odds of a fault are $e^{2x - 2} \cdot (0.1/0.9)$. They exceed $1$ when $x > 1 + \tfrac{1}{2}\ln 9 = 2.099$. The Bayes error drops to $0.9\,(1 - \Phi(2.099)) + 0.1\,\Phi(0.099) = 0.016 + 0.054 = 0.070$. Keeping the old threshold $x > 1$ still gives error $0.159$. That is worse than calling every pump healthy, which errs on the 10% that are faulty.

>[!example] (Hard) When a Missed Fault Costs Ten False Alarms
>Continue with 10% faulty pumps. A missed fault costs \$5000 in damage, and a false alarm costs \$500 for an inspection.
>
>>[!example]- Find the cost-minimizing threshold on $x$ and compare its expected cost and error rate with the error-minimizing rule.
>>The posterior threshold is $500/(500 + 5000) = 1/11 = 0.091$, so the odds threshold is $1/10$. Setting $e^{2x - 2}/9 > 1/10$ gives $x > 1 + \tfrac{1}{2}\ln 0.9 = 0.947$. At this threshold the false-alarm rate per pump is $0.9\,(1 - \Phi(0.947)) = 0.1546$. The miss rate is $0.1\,\Phi(-1.053) = 0.01462$. The expected cost is $500 \cdot 0.1546 + 5000 \cdot 0.01462 = \$150.40$ per pump. The error-minimizing threshold $2.099$ costs $\$277.70$ per pump. Never raising an alarm costs $\$500$, and always raising one costs $\$450$. The cost-minimizing rule makes more errors, $16.9\%$ against $7.0\%$, but most of them are cheap false alarms.
