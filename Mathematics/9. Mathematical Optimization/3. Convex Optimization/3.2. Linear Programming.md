>[!note] Linear Program
>A **Linear Program (LP)** is a [[3.1. Convex Optimization|convex optimization problem]] where the objective function and constraints are all affine. Its **matrix form** is given as
>$$\begin{aligned}\min_{x \in \mathbb{R}^n} \quad & a_0^\top x \\ \text{s.t.} \quad & Ax = b, \\ & Cx \le d. \end{aligned}$$
>where $A, C \in \mathbb{R}^{m \times n}$, and $b, d \in \mathbb{R}^m$ for some $x \in \mathbb{R}^n$
>
>Each **equality constraint** $a_i^\top x = b_i$ defines a **hyperplane**, while each **inequality constraint** $c_j^\top x \le d_j$ defines a **half-space**. The feasible set of an LP is therefore the intersection of finitely many hyperplanes and half-spaces:
>$$\mathcal{S}_{\text{LP}}=\left(\underbrace{\bigcap_{i=1}^m\{x\in\mathbb{R}^n\mid a_i^\top x=b_i\}}_{\text{hyperplane}}\right)\cap\left(\underbrace{\bigcap_{j=1}^k\{x\in\mathbb{R}^n\mid c_j^\top x\le d_j\}}_{\text{half-space}}\right).$$
>This set is called a **polyhedron**. If it is bounded, it is called a **polytope**. In **two dimensions**, a polyhedron is simply a **(possibly unbounded) convex polygon**.
>
>A key structural property of LPs is that if an LP has an optimal solution, then at least one optimal solution occurs at a vertex (extreme point) of the feasible set. Vertices correspond to points where **enough constraints are active** (tight) to uniquely determine a solution. In $\mathbb{R}^n$, this typically means selecting $n$ linearly independent active constraints and solving the resulting linear system. Algebraically, this is known as a **basic feasible solution**.
>
>Two vertices of a non-degenerate LP are **adjacent** if they differ in exactly one active constraint. Equivalently, they share all but one of their zero components in the standard form representation. This adjacency structure forms the edges of the polyhedron.
>
>The **simplex algorithm** exploits this geometry to solve LPs as follows:
>1. Start at any feasible vertex $y$.
>2. Check all adjacent vertices to $y$. 
>3. If an adjacent vertex $\hat{y}$ exists, such that $a_{0}^T\hat{y} < a_{0}^Ty$, update the parameter $y$ to be $\hat{y}$ and repeat the process starting from 2.
>4. Otherwise, if no adjacent vertices exist or meet the condition, $y$ is the optimal solution to the LP.
>
>To convert a general optimization problem to an LP, one can employ **slack variables** through the **epigraph technique**. The problem
>$$\min_{x \in \mathbb{R}^n} f(x) \quad \text{s.t. } x \in S$$
> can be rewritten using the **epigraph technique** as
>$$\begin{aligned}\min_{x \in \mathbb{R}^n, t \in \mathbb{R}} \quad & t \\ \text{s.t.} \quad & x \in \mathcal{S}, \\ & f(x) \le t. \end{aligned}$$
>For LPs, since $f(x)$ is affine, the constraint $f(x) \le t$ is also affine, preserving linearity. Minimizing $t$ geometrically pushes the upper bound down until it touches the graph of $f$.
# Intuition
Intuitively, in linear programming:
- You have a collection of variables $x_1, x_2, \dots, x_n$.
- You form a linear expression $c_1 x_1 + c_2 x_2 + \dots + c_n x_n$ (the “objective”) that you want to make as large (maximize) or as small (minimize) as possible.

At the same time, each variable combination must satisfy a series of linear constraints, such as:
- $a_{1,1} x_1 + a_{1,2} x_2 + \dots + a_{1,n} x_n \;\le\; b_1,$
- $a_{2,1} x_1 + a_{2,2} x_2 + \dots + a_{2,n} x_n \;\le\; b_2,$
and possibly some equalities, like
- $a_{3,1} x_1 + a_{3,2} x_2 + \dots + a_{3,n} x_n \;=\; b_3.$

Each constraint chops off a portion of the space of all possible $x$. Because the constraints are linear, the feasible region (the set of all allowable solutions) is a **convex polytope** (think of a polygon in 2D, a polyhedron in 3D, etc.).

>[!example] Formulating LPs I
>Formulate the problem
>$$\min_{x \in \mathbb{R}^n}f(x)$$
>for the following functions using the epigraph technique or explain why you cannot.
>>[!example]- $f_{1}(x) = \max x - \min x$
>>We can initialize two slack variables, $t_{1}$ and $t_{2}$ that bound the two functions, such that
>>$$\begin{aligned}
>>& x_{i} \le t_{1} \\
>>& x_{i} \ge t_{2} \qquad \text{for } i = 1, \ldots, n,
>>& t_1 \ge 0,
>>& t_2 \ge 0.
>>\end{aligned}$$
>>Then, the objective becomes $t_{1}-t_{2}$. Note that the non-negativity of slack variables is not implied by the maximum and minimum here, and the two additional constraints should be explicitly added.
>
>>[!example]- $f_{2}(x)=\sum^{n}_{i=1}|x_{i}|$
>>We initialize a vector $t \in \mathbb{R}^n$, such that
>>$$-t_{i} \le x_{i} \le t_{i} \qquad \text{for } i=1, \ldots, n,$$
>>and $t \geq 0$ (which is implied by the constraint). The objective is simply $1^Tt$.
>
>>[!example]- $f_{3}(x)=\|Ax-y\|_{\infty} + \|x\|_{1}$
>>Since $\|Ax-y\|_{\infty}=\max(|Ax-y|)$ is a single variable we only need the slack variable $t \in \mathbb{R}$. We add the constraint 
>>$$-t \leq (Ax-y)_{i} \leq t \qquad \text{for } i=1,\ldots,m.$$
>>However, because the L1 norm uses all vector elements, we must define a slack variable $u_{i}$ for each $x_{i}$. As such, we add the constraint
>>$$-u_{i} \le x_{i} \le u_{i} \qquad \text{for } i=1,\ldots, n.$$
>>Then, the objective function becomes $t + 1^Tu$ and we minimize over $x,t,u$. Non-negativity of slack variables is implied by the rest of the constraints.

>[!example] Formulating LPs II
>Given constants $\alpha_1, \ldots, \alpha_n$, consider the optimization problem
>$$\begin{aligned} \min_{x \in \mathbb{R}^n} \quad & \exp\!\left(\sum_{i=1}^n \alpha_i x_i\right) \\ \text{s.t.} \quad & \left(\lVert x \rVert_\infty + 10 \lVert x \rVert_1\right)^2 \le 5 .\end{aligned}$$
>>[!example] Formulate this problem as an LP.
>>Since $e^x$ is non-decreasing in $x$, we can reduce the objective function to simply  $\sum_{i=1}^n \alpha_i x_i$. As done before, for the constraint we introduce two slack variables: $t \in \mathbb{R}$ and $u \in \mathbb{R}^n$. For $\|x\|_{\infty}=t$,  we add the constraint
>>$$-t \leq x_{i} \leq t \qquad \text{for } i=1,\ldots,n,$$
>>whereas for $\|x\|_{1}$, we introduce the constraint
>>$$-u_{i} \le x_{i} \le u_{i} \qquad \text{for } i = 1, \ldots, n.$$
>>Our original constraint becomes
>>$$t+10 \cdot 1^Tu \le \sqrt{ 5 }.$$
