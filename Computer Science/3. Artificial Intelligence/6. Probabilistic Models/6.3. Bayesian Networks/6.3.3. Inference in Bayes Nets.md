>[!note] Inference in Bayes Nets
>Inference in a [[6.3.1. Bayesian Networks|Bayesian Network]] is the process of reasoning under uncertainty - computing how beliefs about some variables should change when others are observed. The objective is to determine the posterior probability of one or more **query variables** $Q$ given **evidence variables** $e$, such that
>$$P(Q \mid e) = \alpha \, P(Q, e) = \alpha \sum_{h} \prod_i P(X_i \mid \text{Parents}(X_i)),$$
>where $h$ are hidden variables, and $\alpha = \frac{1}{P(e)}$ is a normalization constant.
>
>Exact inference computes this posterior **without approximation** and can be performed using several methods that differ mainly in efficiency. 
>1. [[7.2. Inference by Enumeration|Inference by enumeration]] computes $P(Q \mid e)$ directly by expanding the full joint distribution defined by the network. We begin with the standard [[6.3.1. Bayesian Networks|factorization formula]] for Bayes nets over all variables $\{Q, h, e\}$. We then marginalize out the hidden variables $h$ to keep only the query $Q$ and the evidence $e$:
>$$P(Q, e) = \sum_h P(Q, h, e) = \sum_h \prod_i P(X_i \mid \text{Parents}(X_i)),$$
>after which we normalize to turn this joint into a conditional over $Q$:
>$$P(Q \mid e) = \frac{P(Q, e)}{P(e)} = \alpha \sum_h \prod_i P(X_i \mid \text{Parents}(X_i)), \quad \alpha = \frac{1}{P(e)}.$$
>Although conceptually straightforward, the number of terms grows exponentially with the number of hidden nodes.
>2. [[7.3. Variable Elimination|Variable elimination]] produces the same $P(Q \mid e)$, but it does not form $\sum_h$ in one giant step. Instead, it eliminates hidden variables one at a time.
