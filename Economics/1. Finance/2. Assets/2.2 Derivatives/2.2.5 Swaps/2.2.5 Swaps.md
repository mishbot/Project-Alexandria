>[!note] Swaps
>A swap is an over-the-counter (OTC) contract in which two parties exchange streams of cash flows on set future dates. Each stream is a leg. Payments are computed on a notional amount, which in an interest rate swap never changes hands. When both legs are in one currency, only the net difference changes hands on each date. An interest rate swap or a currency swap works like a series of forward contracts, one for each payment date. There are four common types:
>- An [[2.2.5a Interest Rate Swap|interest rate swap]] exchanges fixed-rate interest for floating-rate interest on the same notional.
>- A [[2.2.5b Currency Swap|currency swap]] exchanges principal and interest in one currency for principal and interest in another.
>- A [[2.2.5c Total Return Swap|total return swap]] exchanges an asset's total return, its price change plus income, for fixed or floating interest.
>- A [[2.2.5d Credit Default Swap|credit default swap]] exchanges periodic premiums for a payment that covers the loss if a borrower defaults.
>
>Most swaps have one fixed leg and one floating leg. Floating-for-floating (basis) swaps and fixed-for-fixed currency swaps also exist. Commodity, [[2.3.5c Volatility Trading|variance]], and correlation swaps exchange a fixed level for a commodity price, a realized variance, or a realized correlation. A dealer can replicate interest rate, currency, and total return swaps with a portfolio set up once and then held. Options need a portfolio that is adjusted over time, as [[2.3.3 Option Pricing]] shows.
