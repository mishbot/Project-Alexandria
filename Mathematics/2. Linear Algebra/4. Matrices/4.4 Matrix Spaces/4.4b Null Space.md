>[!note] Null Space
>The null space (or kernel) of a general [[4.1 Matrix|matrix]] $A \in \mathbb{R}^{m \times n}$  is a [[3.4a Vector (Sub)spaces|subspace]] of $\mathbb{R}^n$ that includes the set of all vectors that output the zero vector when multiplied by $A$, such that
>$$\mathcal{N}(A) = \{ x \in \mathbb{R}^n \mid A x = 0 \} \subseteq \mathbb{R}^n.$$
