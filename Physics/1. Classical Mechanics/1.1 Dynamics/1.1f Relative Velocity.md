>[!note] Relative Velocity
>**Relative velocity** is the velocity of one object as observed from the reference frame of another moving object. It quantifies how fast and in what direction one object appears to move relative to another. Each velocity is typically expressed with two subscripts: the first indicating the object, and the second indicating the reference frame. Relative velocity is usually calculated by subtracting the velocity of the second object (the reference frame) from the velocity of the first object, such that for two objects $A$ and $B$,
>$$\vec{v}_{AB} = \vec{v}_A - \vec{V}_B,$$
>where $\vec{v}_{AB}$ is the velocity of object $A$ relative to object $B$.
