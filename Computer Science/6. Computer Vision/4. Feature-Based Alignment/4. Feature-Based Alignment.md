# Feature-Based Alignment

Feature-based alignment is the pipeline that turns two (or more) images of the same scene into a set of pixel-to-pixel correspondences, and then uses those correspondences to estimate a geometric transformation between the images. It is the workhorse of classical computer vision: everything from [[3.4. Homographies|image mosaicing]] to [[5.3. Epipolar Geometry|epipolar geometry]] to [[6.1. Structure from Motion (SfM)|structure from motion]] rests on this three-stage recipe.

The pipeline decomposes into three stages, each with its own set of design choices:

1. **[[4.1. Feature Detection|Feature Detection]]** — find repeatable, well-localized keypoints in each image.
2. **[[4.3. Feature Description|Feature Description]]** — summarize each keypoint's neighborhood as a matchable descriptor vector.
3. **[[4.4. Feature Matching|Feature Matching]]** — pair descriptors across images, filter ambiguous pairs, and verify geometric consistency with [[4.4.1. RANSAC|RANSAC]].
