>[!note] Gradient Boosted Trees
>**Gradient boosting** (Friedman, 2001) builds a model as a sum of $M$ shallow regression trees, fit one after another. Each new tree corrects the errors of the trees before it. The model after $M$ rounds is
>$$F_M(\mathbf{x}) = F_0 + \eta\sum_{m=1}^{M} f_m(\mathbf{x}),$$
>where $f_m$ is the tree from round $m$ and $\eta \in (0, 1]$ is the learning rate, also called shrinkage. $F_0$ is the constant with the lowest training loss. It is the mean of $y$ for squared error and the log-odds of the positive rate for log loss. Round $m$ first computes the **pseudo-residuals**, the negative gradients of the loss $\ell(y, F)$ at the current predictions:
>$$r_{im} = -\frac{\partial \ell(y_i, F)}{\partial F}\bigg|_{F = F_{m-1}(\mathbf{x}_i)}.$$
>It grows a small tree $f_m$ on the pairs $(\mathbf{x}_i, r_{im})$ with squared error. It sets each leaf's value to the constant with the lowest loss on that leaf's points, and it updates $F_m = F_{m-1} + \eta f_m$. For squared error $\ell = \frac{1}{2}(y - F)^2$, the pseudo-residual is the ordinary residual $y_i - F_{m-1}(\mathbf{x}_i)$. For log loss with $p_i = \sigma(F_{m-1}(\mathbf{x}_i))$, it is $y_i - p_i$.
>
>**XGBoost** (Chen and Guestrin, 2016) fits each tree to a second-order expansion of the loss. It uses $g_i = \partial\ell/\partial F$ and $h_i = \partial^2\ell/\partial F^2$ at $F_{m-1}(\mathbf{x}_i)$. A tree has $T$ leaves (CART writes $|T|$), and $w_j$ is the output value of leaf $j$. This $w_j$ is a leaf weight, unlike the linear weights $\mathbf{w}$ elsewhere in this folder. XGBoost penalizes each tree by
>$$\Omega(f) = \gamma T + \frac{1}{2}\lambda\sum_{j=1}^{T} w_j^2,$$
>where $\gamma$ charges for each leaf and $\lambda$ shrinks the leaf values. Let $I_j$ be the set of training points in leaf $j$, with $G_j = \sum_{i \in I_j} g_i$ and $H_j = \sum_{i \in I_j} h_i$. The best leaf value and the gain from splitting a leaf into children $L$ and $R$ are
>$$w_j^* = -\frac{G_j}{H_j + \lambda}, \qquad \text{Gain} = \frac{1}{2}\left[\frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda}\right] - \gamma.$$
>XGBoost ranks candidate splits by this gain and prunes splits whose gain is negative. Four further controls limit overfitting:
>
>- **Shrinkage**: a learning rate $\eta$ between $0.01$ and $0.3$ scales every tree.
>- **Tree size**: a maximum depth of about $3$ to $8$ limits how many features can interact.
>- **Subsampling**: each tree sees a random fraction of the rows (Friedman, 2002) and of the columns.
>- **Early stopping**: training stops when the validation loss has not improved for a set number of rounds.
>
>Two other libraries follow the same design:
>
>- **LightGBM**: Ke et al. (2017) bin each feature into a histogram and grow each tree leaf by leaf, which is fast on large data.
>- **CatBoost**: Prokhorenkova et al. (2018) encode each categorical value by the mean target of earlier rows in a random order. A row's own label therefore never enters its own feature.
>
>Gradient boosted trees are usually the most accurate model on tabular data. They need more tuning than a [[5.2. Random Forests|random forest]], and they are harder to read than a single [[5.1. Decision Trees|decision tree]].

# Intuition

Gradient boosting starts from a constant prediction, such as the average target. Each new tree is trained on what the current model still gets wrong. With squared error that is the residual of each point, so each tree is a regression on the residuals. With other losses, each tree fits the negative gradient of the loss instead. It gives the direction and size of the change that would lower each point's loss. The learning rate $\eta$ scales each tree down before the model adds it. Many small corrections fit the data more carefully than a few large ones, and they need more trees. The name joins two ideas. Boosting combines many weak models in sequence, where a weak model is only slightly better than a constant. "Gradient" means each model follows the negative gradient of the loss. A random forest averages independent deep trees, each a full model on its own. Boosted trees are shallow and depend on each other, and only their sum predicts well.

# Properties

#### *(Bias Falls Step by Step)* Boosting starts from a high-bias model and lowers the bias with every tree.

The constant $F_0$ underfits completely. Each shallow tree adds a small, coarse correction, so the training loss falls round by round. The tree depth sets which patterns the sum can express. Stumps, trees with one split, give an additive model $\sum_j g_j(x_j)$ with no interactions between features. A tree of depth $k$ can model interactions among up to $k$ features. ESL (ch. 10) recommends trees with $4$ to $8$ leaves. It reports that results change little within that range.

#### *(Gradient Descent in Function Space)* Each round approximates one step of gradient descent on the training loss, with the predictions as the parameters.

Treat the $n$ training predictions $\mathbf{F} = (F(\mathbf{x}_1), \dots, F(\mathbf{x}_n))$ as the unknowns. The gradient of the training loss $\sum_i \ell(y_i, F(\mathbf{x}_i))$ with respect to $\mathbf{F}$ has entries $\partial\ell/\partial F(\mathbf{x}_i)$. Its negative is the vector of pseudo-residuals. A step of [[6.4. Gradient Descent|gradient descent]] would move each training prediction by $\eta r_{im}$. That step defines nothing for new inputs. A tree fit to the $r_{im}$ turns the step into a function defined everywhere. Gradient boosting therefore accepts any differentiable loss, such as [[2.1.3. Huber Loss]] for robust regression.

#### *(Each Leaf Takes a Newton Step)* XGBoost's leaf value is a damped Newton step on the loss of the points in that leaf.

For one point, [[6.2. Newton's Method|Newton's method]] moves the prediction by $-g_i/h_i$. A leaf must give all its points one shared value, so XGBoost pools the derivatives into $-G_j/H_j$. The $\lambda$ in the denominator damps the step, most strongly in leaves with a small $H_j$. For squared error with $\ell = \frac{1}{2}(y - F)^2$, every $h_i = 1$. The leaf value is then $\sum_{i \in I_j} r_{im} / (|I_j| + \lambda)$, a shrunken mean of the residuals. For log loss, $h_i = p_i(1 - p_i)$, which is small when $p_i$ is near $0$ or $1$. A leaf of confidently misclassified points could then take a huge step. The `min_child_weight` setting prevents this by requiring $H_j$ above a threshold.

#### *(Smaller Steps Need More Trees)* Lowering $\eta$ raises the number of trees needed, and it usually lowers the test error.

With $\eta = 1$, each tree removes as much of the residual as it can. Later trees then fit the noise that remains. With a small $\eta$, many trees each contribute a little, so no single tree's errors dominate. Friedman (2001) found that $\eta \le 0.1$ gave much lower test error than $\eta = 1$. The cost is training time. For small $\eta$ the training loss depends mostly on the product $\eta M$. Halving $\eta$ therefore roughly doubles the number of rounds needed. A common recipe fixes $\eta$ at $0.05$ or $0.1$ and lets early stopping choose $M$.

#### *(More Trees Can Overfit)* Every new tree fits the training residuals further, so the validation loss eventually rises.

The training loss keeps falling as $M$ grows, toward zero if trees can isolate single points. The validation loss falls, flattens, and then climbs once the trees fit noise. $M$ is therefore a real hyperparameter, chosen by early stopping or [[2.3.2. Cross-Validation|cross-validation]]. A random forest has no such turning point, because its trees are independent and their average converges. Early stopping in boosting resembles early stopping of gradient descent on a linear model, which acts like a [[3.2.1. Ridge Regression|ridge]] penalty.

Each round fits a stump to the current residuals and adds $0.3$ times it to the model. Validation error is lowest after 30 rounds, so early stopping keeps $F_{30}$.

# Derivation

At round $m$, XGBoost looks for the tree $f$ that minimizes the penalized training loss
$$\sum_{i=1}^{n} \ell\big(y_i, F_{m-1}(\mathbf{x}_i) + f(\mathbf{x}_i)\big) + \Omega(f).$$
A second-order Taylor expansion of each loss term around $F_{m-1}(\mathbf{x}_i)$ gives
$$\sum_{i=1}^{n} \Big[\ell\big(y_i, F_{m-1}(\mathbf{x}_i)\big) + g_i f(\mathbf{x}_i) + \tfrac{1}{2} h_i f(\mathbf{x}_i)^2\Big] + \gamma T + \tfrac{1}{2}\lambda\sum_{j=1}^{T} w_j^2.$$
The first term in the brackets does not depend on $f$. Every point in leaf $j$ gets $f(\mathbf{x}_i) = w_j$, so grouping the points by leaf leaves
$$\sum_{j=1}^{T}\Big[G_j w_j + \tfrac{1}{2}(H_j + \lambda) w_j^2\Big] + \gamma T.$$
Each bracket is a parabola in $w_j$ with its minimum at $w_j^* = -G_j/(H_j + \lambda)$ and minimum value $-\frac{1}{2}G_j^2/(H_j + \lambda)$. Splitting one leaf into $L$ and $R$ replaces its term by two terms and adds one leaf, which costs $\gamma$. The resulting drop in the objective is the gain formula. A convex loss has $h_i \ge 0$, so each parabola opens upward whenever $\lambda > 0$.

# Examples

>[!example] (Medium) Two Rounds of Boosting by Hand
>A drone company predicts delivery time from distance. Four past deliveries covered $1, 2, 5, 12$ km and took $2, 4, 12, 30$ minutes. The model uses squared error, stumps and $\eta = 0.5$.
>
>>[!example]- Run two rounds. What are the predictions and the training MSE after each round?
>>The start is $F_0 = 12$, the mean time, with residuals $-10, -8, 0, 18$ and MSE $122$. Round 1 tries the thresholds $1.5$, $3.5$ and $8.5$ km on the residuals. Their summed squared errors are $354.7$, $164$ and $56$, so the stump splits at $8.5$ km. Its leaves hold the mean residuals $-6$ and $18$. Adding half of each gives $F_1 = (9, 9, 9, 21)$ with MSE $41$. The new residuals are $-7, -5, 3, 9$. Round 2 scores the same thresholds at $98.7$, $20$ and $56$, so this stump splits at $3.5$ km. Its leaves hold $-6$ and $6$, which gives $F_2 = (6, 6, 12, 24)$ and MSE $14$. The first stump had removed half of the long trip's error. The remaining residuals separate short trips from long ones, so the second stump chose a new split.

>[!example] (Hard) One XGBoost Split for Fraud Detection
>Six card transactions are labeled fraud ($y = 1$) or legitimate ($y = 0$), and three are fraud. The model starts at $F_0 = 0$, so every $p_i = 0.5$. A candidate split asks whether the merchant is foreign. The $4$ domestic transactions include $1$ fraud, and the $2$ foreign ones are both fraud. The loss is log loss, with $\lambda = 1$ and $\gamma = 0$.
>
>>[!example]- Find the leaf weights, the gain, and the new fraud probabilities with $\eta = 0.3$. Would the split survive $\gamma = 1$?
>>For log loss, $g_i = p_i - y_i$ and $h_i = p_i(1 - p_i)$, as in [[4.3. Logistic Regression]]. So $g_i = 0.5$ for a legitimate transaction, $g_i = -0.5$ for fraud, and $h_i = 0.25$ for all six. The domestic leaf has $G_L = 3(0.5) - 0.5 = 1$ and $H_L = 1$. The foreign leaf has $G_R = -1$ and $H_R = 0.5$. The weights are $w_L = -1/(1 + 1) = -0.5$ and $w_R = 1/(0.5 + 1) = 0.667$. The parent has $G_L + G_R = 0$, so its term in the gain vanishes:
>>$$\text{Gain} = \frac{1}{2}\left[\frac{1^2}{2} + \frac{(-1)^2}{1.5} - 0\right] = \frac{1}{2}(0.5 + 0.667) = 0.583.$$
>>With $\eta = 0.3$, the domestic score becomes $-0.15$ and the foreign score $0.2$. The probabilities become $\sigma(-0.15) = 0.463$ and $\sigma(0.2) = 0.550$. The mean log loss falls from $0.693$ to $0.638$. With $\gamma = 1$, the gain is $0.583 - 1 < 0$, so XGBoost would not split. Without $\lambda$, the Newton steps would be $-1$ and $2$. The penalty shrank the two-point foreign leaf by a factor of $3$. It shrank the domestic leaf by a factor of $2$.
