>[!note] RISC-V 5-Stage Datapath
>The RISC-V 5-stage datapath is a simplified representation of a pipeline used in RISC-V processors when executing instructions. It consists of the following stages:
>1. ***Instruction Fetch (IF)***: the instruction is fetched from memory, and the program counter (PC) is updated to point to the next line of code.
>3. ***Instruction Decode (ID)***: the fetched instruction is decoded (its type is determined).
>4. ***Execute (EX)***: respective calculations are performed. This may include arithmetic and logic operations, or the calculation of the effective address for memory instructions.
>5. ***Memory Access (MEM):*** data is read from or written to memory. This only applies to load/store instructions.
>6. ***Write Back (WB):*** if any registers are modified, the result of the instruction is written back into the register file.
