>[!note] Divide-and-Conquer
>**Divide-and-conquer** is a problem-solving paradigm that breaks a complex problem into smaller, more manageable subproblems, solves each subproblem recursively until it bottoms out (i.e. reaches the recursive base case), and then combines their solutions to solve the original problem. It consists of three steps:
>1. **Divide** the problem into subproblems that are smaller instances of the same problem.
>2. **Conquer** the subproblems by solving them recursively.
>3. **Combine** the subproblem solutions to form a solution to the original problem.
>
>Divide-and-conquer problems are analyzed using **recurrences** $T(n)$ that describe the overall running time of an algorithm in terms of the running time of its subproblems. There are a few methods for solving recurrences. Namely, these are:

# Examples
>[!example] Square Matrix Multiplication (D&C and Strassen's Algorithm)
>There are numerous ways to compute the product of two matrices. One way to do so is using a simple divide-and-conquer algorithm with two input matrices $A$ and $B$, and one zero-initialized output matrix $C$. In the algorithm: 
>1. We will partition each $n \times n$ matrix into four $\frac{n}{2} \times \frac{n}{2}$ sub-matrices.
>2. We will recursively call the function for each of the eight pairs of submatrices.
>3. At the base case, each recursive call adds the product of the scalars $A$ and $B$ to the designated element of $C$.
>
>We can characterize the worst-case running time of this algorithm as $T(n)$. Since each recursive call multiplies two $\frac{n}{2} \times \frac{n}{2}$ matrices, it contributes $T(n/2)$ to the overall running time. Since there are eight recursive calls, $T(n)$ can be expressed as
>$$T(n)=8T(n/2)+\Theta(1),$$
>where $\Theta(1)$ is the base case, which is always constant since $C$ is updated in-place. The solution to the recurrence is $\Theta(n^3)$.
