**Dimensionality reduction** maps each data point from $d$ features to $k < d$ numbers while keeping the structure that matters. It is a form of [[1. Learning Paradigms#Unsupervised Learning|unsupervised learning]], used to compress data, plot it, remove noise and speed up later models. This folder covers PCA, the reasons high-dimensional data are hard to learn from, and t-SNE for plotting.

## Prerequisites

- [[1. Learning Paradigms]], for what makes a task unsupervised.
- [[13.1 Singular Value Decomposition]], the factorization that PCA reads its directions from.
- [[13.3 Low-Rank Approximation]], for the Eckart-Young theorem.
- [[4.5. k-Nearest Neighbors]], the method that suffers most directly in high dimensions.

## Contents

- [[7.1. Principal Component Analysis]]: centering, the SVD, principal directions and scores, variance explained, choosing $k$, standardizing, and PCA as a linear autoencoder.
- [[7.2. Curse of Dimensionality]]: volume near the boundary, the edge length $r^{1/d}$, distance concentration, slow learning rates, and the role of structure.
- [[7.3. t-SNE]]: neighbor probabilities, perplexity, the Student-t kernel, how to read a t-SNE plot, and UMAP.

## Recommended path

Read [[7.2. Curse of Dimensionality]] first for the motivation, then [[7.1. Principal Component Analysis]]. Read [[7.3. t-SNE]] before reading 2D plots of embeddings. Continue with [[6.2. Autoencoders]] for nonlinear codes learned by networks. PCA often runs before [[6.1. K-Means]] on data with many features.
