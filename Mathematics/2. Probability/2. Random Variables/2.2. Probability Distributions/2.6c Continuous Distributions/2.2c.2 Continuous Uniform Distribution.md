>[!note] Continuous Uniform Distribution
>A continuous random variable $X$ with $a<b$ follows the **Uniform distribution** $X \sim \text{Uniform}(a, b)$ if it is equally likely to take any value in the interval $[a,b]$.  Formally, the Uniform distribution of a random variable is given by the PDF
>$$f_{X}(x)=\begin{cases}
\dfrac{1}{b-a} & \text{if } x \in [a, b], \\
0 & \text{otherwise,}
\end{cases}$$
>so that every subinterval of $[a,b]$ of the same length has the same probability.
>
>Then, the CDF of $X$ is given by
>$$F_{X}(x)=\begin{cases}
0 & x \leq a, \\
\dfrac{x-a}{b-a} & x \in (a, b), \\
1 & x \geq b.
\end{cases}$$

# Examples
>[!example] Meeting Probability
>Two bankers each arrive at the station at some uniformly random time between 5:00AM and 6:00AM. They stay exactly 5 minutes, and then leave.
>>[!example]- What is the probability that they meet on a given day?
>>Let $X, Y \sim_\text{iid}\text{Uniform}(0, 60)$ represent the exact time (in minutes) of each banker's arrival. We are trying to solve for the constraint $|X-Y|\leq 5$, such that $p=\mathbb{P}(|X-Y| \leq 5)$. With this inequality, we get $Y \geq X-5$ and $Y \leq X+5$. The following is a visual representation of the area between our two lines:
>>```tikz
>>\usepackage{pgfplots}
>>
>>\begin{document}
>>\begin{tikzpicture}
>>  \begin{axis}[
>>    width=8cm, height=8cm,
>>    xmin=0, xmax=60,
>>    ymin=0, ymax=60,
>>    axis equal image,
>>    xlabel={$X$},
>>    ylabel={$Y$},
>>    ylabel style={rotate=-90},
>>    title={Region $|X-Y| \leq 5$}
>>  ]
>>    % Shade the region |x - y| < 5 by plotting its polygonal boundary:
>>    \addplot [
>>      draw=none,
>>      fill=black,
>>      opacity=0.1,
>>    ] coordinates {
>>      (0,0)   % lower‐left corner of the square
>>      (5,0)   % intersection of y = x - 5 with y=0
>>      (60,55) % intersection of y = x - 5 with x=60
>>      (60,60) % upper‐right corner of the square (still inside |x-y|<5)
>>      (55,60) % intersection of y = x + 5 with y=60
>>      (0,5)   % intersection of y = x + 5 with x=0
>>      (0,0)   % back to (0,0) to close the polygon
>>    };
>>
>>    % Draw the boundary lines y = x + 5 and y = x - 5:
>>    \addplot [
>>      domain=0:60,
>>      samples=2,
>>      thick,
>>    ] {x + 5} node[midway, sloped, above] {$Y = X + 5$};
>>
>>    \addplot [
>>      domain=0:60,
>>      samples=2,
>>      thick,
>>    ] {x - 5} node[midway, sloped, below] {$Y = X - 5$};
>>
>>    % Draw the square [0,60]×[0,60]:
>>    \draw[black] (axis cs:0,0) rectangle (axis cs:60,60);
>>  \end{axis}
>>\end{tikzpicture}
>>\end{document}
>>```
>>To find the area between the curves, we can integrate and remove the extra parts. However, an easier method would be to think of the unshaded area as two triangles, each with area $\frac{1}{2}55^2$, and subtract them from the total area of $60^2$. That area of the inequality is
>>$$60^2-55^2=(60-55)(60+55)=575.$$
>>Since our sample space has an area of $60^2=3600,$
>>$$\mathbb{P}(|X-Y| \leq 5) = \frac{575}{3600}=\frac{23}{144}.$$

>[!example] Stick Cutting
>You break a stick twice uniformly at random.
>>[!example]- What is the probability that the 3 segments can form a triangle?
>>Let $X,Y \sim_{\text{iid}}\text{Uniform}(0, 1)$ represent the points of the first two cuts. Using these two random variables, we can cut the stick into 3 pieces: if $X < Y$, the 3 cuts are $X$, $Y-X$ and $1-Y$, and vice-versa for $X > Y$:
>>```tikz
>>\begin{document}
>>\begin{tikzpicture}[xscale=10,yshift=0cm]
>>
>>  %─── Case X<Y ──────────────────────────────────────────────────────────
>>  \begin{scope}[shift={(0cm,0cm)}]
>>    % choose sample positions (you can adjust these)
>>    \coordinate (X) at (0.3,0);
>>    \coordinate (Y) at (0.7,0);
>>
>>    % the stick
>>    \draw[thick] (0,0) -- (1,0);
>>    % cut‐marks
>>    \draw[dashed] (X) -- ++(0,0.1) node[above] {$X$};
>>    \draw[dashed] (Y) -- ++(0,0.1) node[above] {$Y$};
>>    % segment‐length arrows
>>    \draw[<->] (0,-0.2) -- (X|-0,-0.2) node[midway,below] {$X$};
>>    \draw[<->] (X|-0,-0.2) -- (Y|-0,-0.2) node[midway,below] {$Y-X$};
>>    \draw[<->] (Y|-0,-0.2) -- (1,-0.2) node[midway,below] {$1-Y$};
>>    % case label
>>    \node[above,font=\small\bfseries] at (0.5,0.5) {Case \(X<Y\)};
>>  \end{scope}
>>
>>  %─── Case X>Y ──────────────────────────────────────────────────────────
>>  \begin{scope}[shift={(0cm,-2.5cm)}]
>>    \coordinate (Y2) at (0.4,0);
>>    \coordinate (X2) at (0.8,0);
>>
>>    \draw[thick] (0,0) -- (1,0);
>>    \draw[dashed] (Y2) -- ++(0,0.1) node[above] {$Y$};
>>    \draw[dashed] (X2) -- ++(0,0.1) node[above] {$X$};
>>
>>    \draw[<->] (0,-0.2) -- (Y2|-0,-0.2) node[midway,below] {$Y$};
>>    \draw[<->] (Y2|-0,-0.2) -- (X2|-0,-0.2) node[midway,below] {$X-Y$};
>>    \draw[<->] (X2|-0,-0.2) -- (1,-0.2) node[midway,below] {$1-X$};
>>
>>    \node[above,font=\small\bfseries] at (0.5,0.5) {Case \(X>Y\)};
>>  \end{scope}
>>  
>>\end{tikzpicture}
>>\end{document}
>>```
>>By the triangle inequality, 3 lines can form a triangle if and only if the sum of any two of the three lines is larger than the third line. As such, for the case of $X < Y$, we have:
>>$$\begin{align}
>>X+(Y-X) > 1-Y &\implies Y > 1/2 \\
>>X+1-Y>Y-X &\implies Y < 1/2 + X \\
>>Y-X+1-Y > X &\implies X < 1/2
>>\end{align}$$
>>We use symmetry on $X>Y$, and get the following two feasible regions:
>>```tikz
>>\begin{document}
>>\begin{tikzpicture}[scale=6]
>>
>>  % Draw the unit square
>>  \draw[thick] (0,0) rectangle (1,1);
>>
>>  % Draw the two mid‐lines
>>  \draw[thick] (0.5,0) -- (0.5,1);
>>  \draw[thick] (0,0.5) -- (1,0.5);
>>
>>  % Draw the two “triangle‐inequality” diagonals in each half
>>  \draw[thick] (0,0.5) -- (0.5,1) node[midway, sloped, above] {$y=x+1/2$};
>>  \draw[thick] (0.5,0) -- (1,0.5) node[midway, sloped, below] {$y=x-1/2$};
>>
>>  % Shade the two feasible triangles:
>>  %   Top‐left triangle: vertices (0,0.5),(0.5,0.5),(0.5,1)
>>  \fill[black, opacity=0.1] (0,0.5) -- (0.5,0.5) -- (0.5,1) -- cycle;
>>  %   Bottom‐right triangle: vertices (0.5,0),(1,0.5),(0.5,0.5)
>>  \fill[black, opacity=0.1] (0.5,0) -- (1,0.5) -- (0.5,0.5) -- cycle;
>>
>>  % X-Axis Ticks
>>  \node[below left] {0};
>>  \node[below] at (0.5, 0) {1/2};
>>  \node[below] at (0.5, -0.1) {$X$};
>>  \node[below] at (1, 0) {1};
>>  
>>  % X-Axis Ticks
>>  \node[left] at (0, 0.5) {1/2};
>>  \node[left] at (-0.15, 0.5) {$Y$};
>>  \node[left] at (0, 1) {1};
>>\end{tikzpicture}
>>\end{document}
>>```
>>Because 2 of the 8 half-quadrants (equivalently, 1 of the 4 quadrants) of the sample space are feasible, the probability that the 3 segments can form a triangle is $1/4$.
