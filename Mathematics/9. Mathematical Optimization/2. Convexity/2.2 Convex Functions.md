>[!note] Convex Function
>A function $f: \mathbb{R}^n \to \mathbb{R}$ is **convex** if its domain $D$ is a [[2.1 Convex Sets|convex set]], and:
>1. (**Zeroth-Order Condition**) For all points $\vec{x}_{1},\vec{x}_{2}\in D$ and $\alpha \in [0,1]$, the graph of $f$ lies below (or on) the line segment connecting $f(\vec{x}_{1})$ and $f(\vec{x}_{2})$, such that
>$$f(\alpha \vec{x}_{1}+(1-\alpha)\vec{x}_{2}) \leq \alpha f(\vec{x}_{1})+(1-\alpha)f(\vec{x}_{2}).$$
>2. (**First-Order Condition**) If $f$ is differentiable, it holds that for all $x, y \in D$, the tangent line (or tangent plane in higher dimensions) at any point $x$ lies below the function everywhere else:
>$$f(y) \geq f(x) + \nabla f(x)^T(y-x).$$
>3. (**Second-Order Condition**) If $f$ is twice-differentiable, it holds that the Hessian of $f$ for all $x \in D$ is positive semi-definite (i.e., $\nabla^2f(x) \succeq 0$).
>

# Properties
#### (*Envelope Representation*) If $f$ is convex and l.s.c., $f(x)=\sup\limits_{a \leq f}a(x)$, where $a$ is a collection of affine functions such that $a(x) \leq f(x)$ for all $x \in X$.
You can imagine all of $f$'s tangents "enveloping" $f$: they only intersect one point of $x$, which, in terms of all tangent lines on $f$, constructs $f$. The largest value of any affine $a$ on $x$ will be the point where the affine tangent intersects $f$. We use the supremum instead of the maximum to keep the behavior well-defined for discontinuities.



# Examples
>[!example] Zeroth-Order Condition on Parametrized Functions
>Consider a convex function $f : \mathbb{R}^{n} \to \mathbb{R}$. Given two arbitrary points $y, z \in \mathbb{R}^{n}$, we define the scalar function $g : \mathbb{R} \to \mathbb{R}$ as follows:
>$$g(t) = f(y + tz), \qquad \forall t \in \mathbb{R}.$$
>The function $g$ is the restriction of the function $f$ to a line parametrized by a scalar $t$. 
>>[!example]- By analyzing the domain of $g$ and using the zeroth-order convexity condition, show that the function $g$ is convex.
>>To begin, we  define $\text{dom}(g) = \{ t \mid y+tz \in \text{dom}(f) \}$. For some $\alpha \in [0, 1]$, we must show that the domain of $g$ is convex, such that for any two $t_{i}$, it follows that $\alpha t_{1} + (1-\alpha)t_{2} \in \text{dom}(g)$. In terms of $\text{dom}(f)$, this is equivalent to showing that
>>$$y + (\alpha t_{1}+(1-\alpha)t_{2})z \in \text{dom}(f).$$
>>However, since $y + (\alpha t_{1}+(1-\alpha)t_{2})z=\alpha(y+t_{1}z)+(1-\alpha)(y+t_{2}z) \in \text{dom}(f)$, it follows that $\text{dom}(g)$ is convex.
>>
>>Now, we must show that
>>$$g(\alpha t_{1}+(1-\alpha)t_{2}) \leq \alpha g(t_{1})+(1-\alpha)g(t_{2}),$$
>>equivalent to saying
>>$$f(y+[\alpha t_{1}+(1-\alpha)t_{2}]z) \leq \alpha f(y+t_{1}z) +(1-\alpha)f(y+t_{2}z),$$
>>where the LHS factorizes into $f(y+[\alpha t_{1}+(1-\alpha)t_{2}]z)=f(\alpha[y+t_{1}z]+(1-\alpha)[y+t_{2}z])$. To simplify further, take $x_{1}=y+t_{1}z$ and $x_{2}=y+t_{2}z$, such that
>>$$f(\alpha x_{1}+(1-\alpha)x_{2}) \leq \alpha f(x_{1})+(1-\alpha)f(x_{2}).$$
>>This fact is given by definition since $f$ is convex, and therefore $g$ is convex.

>[!example] Zeroth-Order Condition on Composite Functions
>Consider two functions $f : \mathbb{R}^n \to \mathbb{R}$ and $h : \mathbb{R} \to \mathbb{R}$. Define the composite function $g : \mathbb{R}^n \to \mathbb{R}$ such that $g(x) = h(f (x))$. Assume that for every $x$ in the domain of $f$, the point $f(x)$ is in the domain of $h$, which implies that $g(x)$ is defined for every $x$ in the domain of $f$. Assume that all of the following conditions hold:
>- $f$ and $h$ are both convex, and may be non-differentiable
>- $h$ is a non-decreasing function, meaning that $h(y_{1}) \leq h(y_{2})$ for all $y_{1}, y_{2} \in \mathbb{R}$ such that $y_{1} \leq y_{2}$
>
>>[!example]- By using the zeroth-order convexity condition, show that $g$ is convex.
>>Since $f$ is convex, $\mathrm{dom}(f)$ **is convex**, and because $g$ is defined wherever $f$ is defined (as assumed), $\mathrm{dom}(g)=\mathrm{dom}(f)$, hence convex. We must only show that for some $x_{1}, x_{2} \in \text{dom}(g)$ and $\alpha \in [0, 1]$, it follows that
>>$$\begin{align}
>>g(\alpha x_{1}+(1-\alpha)x_{2})&=h(f(\alpha x_{1}+(1-\alpha)x_{2})) &(1) \\
>>& \leq h(\alpha f(x_{1})+(1-\alpha)f(x_{2})) &(2)\\
>>& \leq \alpha h(f(x_{1})) + (1-\alpha)h(f(x_{2})) &(3) \\
>>&= \alpha g(x_{1}) + (1-\alpha)g(x_{2}),
>>\end{align}$$
>>where the RHS transition from $(1)$ to $(2)$ is both due to $h$ being non-decreasing and $f$ being convex, whereas the transition from $(2)$ to $(3)$ is due to $h$ being convex.
