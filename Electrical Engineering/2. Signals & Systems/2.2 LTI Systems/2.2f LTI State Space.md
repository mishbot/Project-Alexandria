>[!note] LTI State Space Representation
>The **state-space** of an LTI system is a mathematical representation in terms of a set of first-order difference equations. It describes the system dynamics using **state variables**, an **input**, and an **output**, in a compact matrix form. For a discrete-time LTI system, the state evolution equation is given by
>$$\begin{alignat}{0}
>q(n + 1) = Aq(n) + Bx(n),
\end{alignat}$$
whereas the output equation is given as
$$y(n) = Cq(n) + Dx(n),$$
>where $q(n) = \begin{bmatrix}q_{1}(n) & q_{2}(n) & \ldots & q_{N}(n)\end{bmatrix}^T \in \mathbb{R}^N$ is the $N$-dimensional state vector,  $x(n), \enspace y(n) \in \mathbb{R}$ are the 1-dimensional input and output of the system, and $A \in \mathbb{N \times N}$, $B \in \mathbb{R}^N$, $C \in \mathbb{R}^{1 \times N}$, and $D \in \mathbb{R}$ are the coefficients of the state evolution equation.
>
>Similarly, the state evolution equation of a continuous-time LTI system is given as
>$$\frac{d}{dt}q(t) = Aq(t) + Bx(t),$$
>whereas the output equation is given as
>$$y(t) = Cq(t) + Dx(t).$$

>[!example] (Discrete-Time) Find the State Space of the LCCDE
>Suppose we have the LCCDE representation of a discrete-time LTI system, such that
>$$y(n) = x(n) - 2x(n - 1) + \frac{5}{2}y(n - 1) - y(n - 2).$$
>This LCCDE can be described using the DAG,

>
>Each delay represents a single state space. As such, we can represent the two elements of the state space vector as
>$$\begin{alignat}{0}
q_{1}(n + 1) = -2x(n)+\frac{5}{2}y(n)+q_{2}(n), \\
>\text{and} \\
>q_{2}(n + 1) = -y(n).
>\end{alignat}$$
>Here, we can also substitute $y(n) = x(n) + q_{1}(n)$, such that the elements of the state vector equate
>$$\begin{alignat}{0}
q_{1}(n + 1) = -2x(n)+\frac{5}{2}x(n)+\frac{5}{2}q_{1}(n) + q_{2}(n), \\
>\text{and} \\
>q_{2}(n + 1) = -x(n)-q_{1}(n).
>\end{alignat}$$
>
>With the knowledge of the elements of the state vector $q(n+1)$, we can now find the matrices $A = \begin{bmatrix}\frac{5}{2} & 1 \\ -1 & 0\end{bmatrix}$, and $B = \begin{bmatrix}\frac{1}{2} \\ -1\end{bmatrix}$ to solve for the state evolution equation.
>
>We proceed with a similar approach to solve the output equation, and find that $C=\begin{bmatrix}1 & 0\end{bmatrix}$  and $D = 1$ (since $y(n) = q_{1}(n) + x(n)$ as substituted earlier).

>[!example] (Continuous-Time) Find the State Space of the LCCDE
>Consider a standard series RLC circuit, which has the LCCDE (each dot represents an order of the function's integral),
>$$\ddot{v}_{o}(t) = -\frac{R}{L}\dot{v}_{o}(t) - \frac{1}{LC}v_{o}(t) + \frac{1}{LC}v_{s}(t) \iff v_{o}(t) = -\frac{R}{L}\int\dot{v}_{o}(t) - \frac{1}{LC}\int \int v_{o}(t) + \frac{1}{LC}\int \int v_{s}(t)$$
>We can model this system into its state space form, such that
>$$\dot{q}_{1}(t) = -\frac{R}{L}v_{o}(t) + q_{2}(t),$$
>and
>$$\dot{q}_{2}(t) = -\frac{1}{LC}v_{o}(t) + \frac{1}{LC}v_{s}(t).$$
>Substituting $v_o(t) = q_{1}(t)$, we get
>$$\dot{q}_{1}(t) = -\frac{R}{L}q_{1}(t) + q_{2}(t),$$
>and
>$$\dot{q}_{2}(t) = -\frac{1}{LC}q_{1}(t) + \frac{1}{LC}v_{s}(t).$$
>By definition, $A = \begin{bmatrix}-\frac{R}{L} & 1 \\ \frac{1}{LC} & 0\end{bmatrix}$, $B = \begin{bmatrix}0 \\ \frac{1}{LC}\end{bmatrix}$. Then, $C=\begin{bmatrix}1 & 0\end{bmatrix}$, and $D=0$.
