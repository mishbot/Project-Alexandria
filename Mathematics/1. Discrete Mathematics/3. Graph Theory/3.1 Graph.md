>[!note] Graph
>A graph is a mathematical structure consisting of a set of vertices (nodes) $V$, and a set of edges $E \subseteq V \times V$, using which the vertices are connected together in some way. Graphs can be
>- **Directed graphs**, used to model one-way relationships between vertices by arrows. The set $E$ of a directed graph is a set of pairs.
>- **Undirected graphs**, modeling relationships of vertices that go both ways. The set $E$ of an undirected graph is a set of unordered sets.
>
>The **degree** of a vertex (denoted $\deg v$) is the number of edges connected to it. In directed graphs, each vertex has an **in-degree**, and an **out-degree**.
>
>Furthermore, we say that an edge $e=\{u, v\}$ is **incident** on vertices $\{u, v\}$, and that the vertices $u$ and $v$ are *adjacent*.
# Properties
#### (*Handshaking Lemma*) In an undirected graph, $\sum^{}_{v \in V}\deg v=2|E|$.
This lemma is intuitive, since in an undirected graph each edge adds 1 to the degree of both endpoints. For a formal proof, we proceed by induction:
- **Base Case:** The lemma is true for a graph with zero edges (i.e., $|E|=0$).
- **Hypothesis:** Assume the lemma is true for all graphs with $\leq k-1$ edges.
- **Step**: We want to prove for a graph with $k$ edges. We remove 1 edge, and the degrees of both affected edges is decreased by 1.

#### (Edge Bounds for Connected Undirected Graphs) A connected, undirected graph can consist of between $e \in \left[v-1,  \dfrac{v(v-1)}{2} \right]$ edges.
We will see later that a connected undirected graph with $v-1$ edges is known as acyclic, or a tree. Although we can prove this, there is no need to. Same for the maximum.
