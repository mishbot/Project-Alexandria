# Carhart Four-Factor Model

**Status:** stub. Forward-linked from [[8.8.1. Cross-Sectional Momentum]], [[8.8. Momentum]].

Carhart ($1997$) extends the Fama-French three-factor model (market, SMB, HML) with a fourth factor: **UMD** ("up-minus-down"), the [[8.8.1. Cross-Sectional Momentum|cross-sectional momentum]] WML portfolio. The four-factor model is included because no combination of the original three factors absorbs the WML alpha — momentum is itself an irreducible factor in the empirical asset-pricing toolkit.
