>[!note] SIMD (Single Intruction, Multiple Data) Instructions
>SIMD is a parallel computing paradigm that enables the simultaneous execution of the same operation on multiple data elements. SIMD instructions are a type of computer instruction that allows a single instruction to process multiple data points concurrently by leveraging data-level parallelism.
>
>>[!warning] Note!
>>Most of the speed up from SIMD instructions come from doing a large memory load/store at a time, rather than from the computation of multiple data.
