>[!note] Muon
>**Muon** (MomentUm Orthogonalized by Newton-Schulz) is an optimizer for the weight matrices of a network's hidden layers. For a layer $\mathbf{h}_\ell = \mathbf{W}_\ell\mathbf{h}_{\ell-1}$ with $\mathbf{W}_\ell \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$, each step has three parts:
>
>- **Momentum**: the buffer $\mathbf{B}_t = \mu\,\mathbf{B}_{t-1} + \nabla_{\mathbf{W}}\mathcal{L}(\mathbf{W}_{t-1})$ accumulates recent gradients with momentum coefficient $\mu$.
>- **Orthogonalization**: $\mathbf{O}_t = \mathrm{NewtonSchulz}(\mathbf{B}_t) \approx \mathbf{U}_t\mathbf{V}_t^T$, where $\mathbf{B}_t = \mathbf{U}_t\boldsymbol{\Sigma}_t\mathbf{V}_t^T$ is the reduced SVD. This sets every nonzero singular value of the buffer to $1$.
>- **Update**: $\mathbf{W}_t = \mathbf{W}_{t-1} - \eta\,\mathbf{O}_t$ with learning rate $\eta$. The lecture writes this step without the shape factor introduced below.
>
>A matrix whose nonzero singular values all equal $1$, such as $\mathbf{U}\mathbf{V}^T$, is called **semi-orthogonal**. For a gradient $\mathbf{G} = \mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^T$, the step $-\eta\,\mathbf{U}\mathbf{V}^T$ minimizes the linearized loss change $\langle \mathbf{G}, \Delta\mathbf{W}\rangle$ over all steps with $\|\Delta\mathbf{W}\|_2 \le \eta$. It is the [[6.4.4. Steepest Descent Under a Norm|steepest-descent]] step under the spectral norm. The $\text{RMS}\to\text{RMS}$ norm $\|\mathbf{A}\|_{\text{RMS}\to\text{RMS}} = \sqrt{d_{\text{in}}/d_{\text{out}}}\,\|\mathbf{A}\|_2$ gives the same direction with a shape-dependent size:
>$$\Delta\mathbf{W}^* = -\eta\sqrt{\frac{d_{\text{out}}}{d_{\text{in}}}}\;\mathbf{U}\mathbf{V}^T, \qquad \|\Delta\mathbf{W}^*\|_{\text{RMS}\to\text{RMS}} = \eta.$$
>The factor $\sqrt{d_{\text{out}}/d_{\text{in}}}$ lets one $\eta$ apply to layers of every shape. Here $\eta$ plays the role of the update budget $\gamma$ in [[4.3. Maximal Update Parameterization|μP]].
>
>**Newton-Schulz iteration** approximates $\mathbf{U}\mathbf{V}^T$ with matrix products only, without an SVD:
>
>- **Normalize**: set $\mathbf{X}_0 = \mathbf{B}_t/\|\mathbf{B}_t\|_F$. Since $\|\mathbf{B}_t\|_F \ge \sigma_{\max}$, every nonzero singular value of $\mathbf{X}_0$ lies in $(0, 1]$.
>- **Iterate an odd polynomial**: set $\mathbf{X}_{k+1} = p(\mathbf{X}_k)$ with $p(\mathbf{X}) = a\mathbf{X} + b\,\mathbf{X}\mathbf{X}^T\mathbf{X} + c\,(\mathbf{X}\mathbf{X}^T)^2\mathbf{X}$. It keeps the singular vectors, $p(\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^T) = \mathbf{U}\,p(\boldsymbol{\Sigma})\,\mathbf{V}^T$, and maps each singular value $\sigma$ to $a\sigma + b\sigma^3 + c\sigma^5$.
>- **Cubic**: $p(x) = \frac{3}{2}x - \frac{1}{2}x^3$ has fixed points $0$ and $\pm 1$. Repeated steps drive every $\sigma \in (0, 1]$ to $1$.
>- **Quintic**: $f(x) = 3.4445x - 4.7750x^3 + 2.0315x^5$, run for $5$ steps. It grows small singular values faster, but $f(1) \neq 1$, so the result has singular values near $1$.
>
>Keller Jordan introduced Muon in a 2024 blog post titled "Muon: An optimizer for hidden layers in neural networks". Tuned AdamW remains the default optimizer. Muon is an alternative for hidden-layer matrices.

# Intuition

The gradient of a hidden-layer weight matrix often has a few large singular values and many small ones. A gradient step moves the weights along each singular direction $\mathbf{u}_i\mathbf{v}_i^T$ by an amount proportional to $\sigma_i$. The weights therefore move mostly along a few directions. The learning rate must also stay small enough for the largest one. Muon keeps the singular directions of the momentum buffer and sets every singular value to $1$. Each direction then moves by the same amount. An exact SVD at every step would be too slow for large matrices. Newton-Schulz iteration instead applies a polynomial that pushes every singular value toward $1$ and leaves the singular vectors unchanged.

# Properties

#### *(Equal Step in Every Direction)* A semi-orthogonal update moves the weights by the same amount along every singular direction of the gradient.

Write the gradient as $\mathbf{G} = \sum_i \sigma_i\,\mathbf{u}_i\mathbf{v}_i^T$. The gradient step $-\eta\,\mathbf{G}$ moves the weights by $\eta\sigma_i$ along the direction $\mathbf{u}_i\mathbf{v}_i^T$. The Muon step moves them by $\eta$ along every direction. All nonzero singular values of $\mathbf{U}\mathbf{V}^T$ equal $1$, so its condition number $\sigma_{\max}/\sigma_{\min}$ is $1$. Jordan (2024) reports that momentum and Adam updates for transformer weight matrices are nearly low rank. A few directions dominate them. Under a gradient step, a direction with $\sigma_i = \sigma_1/100$ moves $100$ times less than the top direction. Muon gives it the same step as the top direction. The update keeps only the directions and discards the relative sizes $\sigma_i$.

#### *(Odd Polynomials Keep Singular Vectors)* An odd matrix polynomial changes only the singular values, so Newton-Schulz never needs $\mathbf{U}$ or $\mathbf{V}$.

Let $\mathbf{X} = \mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^T$ be the reduced SVD, so $\mathbf{U}^T\mathbf{U} = \mathbf{V}^T\mathbf{V} = \mathbf{I}$ and $\boldsymbol{\Sigma}$ is square and diagonal. Then
$$\mathbf{X}\mathbf{X}^T\mathbf{X} = \mathbf{U}\boldsymbol{\Sigma}(\mathbf{V}^T\mathbf{V})\boldsymbol{\Sigma}(\mathbf{U}^T\mathbf{U})\boldsymbol{\Sigma}\mathbf{V}^T = \mathbf{U}\boldsymbol{\Sigma}^3\mathbf{V}^T.$$
Repeating the step gives $(\mathbf{X}\mathbf{X}^T)^k\mathbf{X} = \mathbf{U}\boldsymbol{\Sigma}^{2k+1}\mathbf{V}^T$, and summing the terms gives $p(\mathbf{X}) = \mathbf{U}\,p(\boldsymbol{\Sigma})\,\mathbf{V}^T$. Only odd powers have the form $\mathbf{U}\boldsymbol{\Sigma}^k\mathbf{V}^T$. An even term such as $\mathbf{X}\mathbf{X}^T = \mathbf{U}\boldsymbol{\Sigma}^2\mathbf{U}^T$ is $d_{\text{out}} \times d_{\text{out}}$ and loses $\mathbf{V}$. Every odd polynomial has $p(0) = 0$, so zero singular values stay zero. For a gradient of rank $r$, the iteration therefore approaches $\mathbf{U}_r\mathbf{V}_r^T$ and adds no new directions.

#### *(Fixed Points of the Cubic)* Iterating the cubic drives every value in $(0, \sqrt{3})$ to $1$, and near $1$ the error shrinks quadratically.

Solving $p(x) = x$ gives $x(1 - x^2) = 0$, so the fixed points are $0$ and $\pm 1$. The derivative $p'(x) = \frac{3}{2}(1 - x^2)$ equals $\frac{3}{2}$ at $0$, so values near $0$ move away from it. It equals $0$ at $\pm 1$, so values near $\pm 1$ move toward them. Writing $e = 1 - x$ for the error, the identity
$$1 - p(x) = \tfrac{1}{2}(1 - x)^2(2 + x) \quad\Longrightarrow\quad e_{k+1} = \tfrac{1}{2}\,e_k^2\,(3 - e_k)$$
shows quadratic convergence near $1$. On $(0, 1]$, $p(x) - x = \frac{1}{2}x(1 - x^2) \ge 0$ and $p(x) \le 1$, so the iterates rise steadily to $1$. On $(1, \sqrt{3})$, $p(x) = \frac{1}{2}x(3 - x^2)$ is positive and below $1$, so one step moves the value into $(0, 1)$. At $x = \sqrt{3}$ the value maps to $0$, and above $\sqrt{3}$ it turns negative.

#### *(Why Normalize First)* The Frobenius norm gives a cheap scale that puts every singular value where the cubic converges.

Without normalization, a singular value of $3$ maps to $p(3) = 4.5 - 13.5 = -9$, and its direction flips. The Frobenius norm satisfies $\|\mathbf{G}\|_F^2 = \sum_i \sigma_i^2 \ge \sigma_1^2$, so $\mathbf{G}/\|\mathbf{G}\|_F$ has largest singular value at most $1$. It needs one pass over the entries, while the exact $\sigma_1$ needs an SVD or a power iteration. Multiplying $\mathbf{G}$ by any $c > 0$ leaves $\mathbf{U}$ and $\mathbf{V}$ unchanged. The Frobenius bound is loose, though. If a matrix has $r$ equal singular values, each becomes $1/\sqrt{r}$, about $0.044$ for $r = 512$. Near $0$ the cubic only multiplies a value by $1.5$ per step, so these small values need many steps.

#### *(The Quintic Trades Accuracy for Speed)* The quintic multiplies small singular values by $3.4445$ per step but never converges to $1$.

The slope at the origin is $f'(0) = 3.4445$, against $p'(0) = 1.5$ for the cubic. A singular value of $0.01$ reaches $1.093$ after four quintic steps. Higher-degree polynomials can grow values faster, but each step costs more products. The quintic gives $f(1) = 0.701$, so $1$ is not a fixed point. The fixed point closest to $1$ is $x \approx 0.868$, where $f'(0.868) \approx -1.58$. Because $|f'| > 1$ there, nearby values move away. The iterates keep moving back and forth around $0.868$, between about $0.71$ and $1.10$. A numerical check over all starting values in $[0.01, 1]$ shows that after $5$ steps every value lies in $[0.68, 1.14]$. Later steps keep it there. The band runs from the local minimum $f(1.050) = 0.682$ up to $f(0.682) = 1.134$. Jordan (2024) tuned the coefficients to maximize the slope at zero while keeping values within about $0.3$ of $1$. He reports that errors of this size did not hurt training.

#### *(Cost and Memory)* A cubic step costs two matrix products and a quintic step three, and Muon stores one buffer per weight matrix.

>[!warning] Not Taught in Lecture
>Lecture did not count the cost. A homework problem analyzed the cubic step, and the quintic code and overhead estimate come from Jordan (2024).

A cubic step forms the Gram matrix $\mathbf{A} = \mathbf{X}\mathbf{X}^T$ and then the product $\mathbf{A}\mathbf{X}$. A quintic step forms $\mathbf{A} = \mathbf{X}\mathbf{X}^T$, then $\mathbf{A}^2$, then $(b\mathbf{A} + c\mathbf{A}^2)\mathbf{X}$, and adds $a\mathbf{X}$. Since $(\mathbf{X}\mathbf{X}^T)^k\mathbf{X} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^k$, an implementation can form whichever Gram matrix is smaller. With $m = \min(d_{\text{out}}, d_{\text{in}})$ and $n = \max(d_{\text{out}}, d_{\text{in}})$, each product then costs at most about $m^2 n$ multiply-adds. Jordan's code transposes tall matrices for this reason and runs the products in bfloat16. On a GPU, a few large matrix products take much less time than one SVD of the same matrix. Jordan estimates the total overhead at under $1\%$ of training FLOPs for large-batch language-model training. For memory, Muon keeps one buffer $\mathbf{B}_t$ per weight matrix, as SGD with [[6.4.2. Momentum|momentum]] does. [[6.4.3. Adam|Adam]] keeps two, the first- and second-moment estimates.

#### *(Which Parameters Use Muon)* Muon handles the 2D weight matrices of hidden layers, and the other parameters usually stay on AdamW.

>[!warning] Not Taught in Lecture
>Lecture did not cover which parameters Muon should handle. This split follows Jordan (2024). The convolution reshape appeared in a homework problem.

A convolution kernel of shape $C_{\text{out}} \times C_{\text{in}} \times K \times K$ is reshaped to a $C_{\text{out}} \times C_{\text{in}}K^2$ matrix before orthogonalization. This is the matrix that multiplies the unfolded patches in the [[5.2.1. Convolutional Layer|im2col]] form of a convolution, so $d_{\text{in}} = C_{\text{in}}K^2$. Biases and the gains of normalization layers are vectors. A $d \times 1$ matrix has one singular value, so orthogonalizing it gives $\mathbf{g}/\|\mathbf{g}\|_2$, the normalized gradient. Jordan recommends AdamW for these vectors, for the embedding layer and for the output head. A training run therefore uses two optimizers at once. His public implementation also uses Nesterov-style momentum in place of the plain buffer $\mathbf{B}_t$.

#### *(Results)* Muon set training-speed records, and it has been used to train large language models.

In the NanoGPT speedrun, contributors compete to train a small GPT-2 model to a fixed validation loss. The lecture showed the record falling from $45$ minutes to about $3$ minutes. Muon was one of several changes along the way. In Jordan's wall-clock comparison, Muon lowered the validation loss faster than Adam, Distributed Shampoo and SOAP. Its time per step was nearly the same as Adam's. Moonshot AI's report "Muon is Scalable for LLM Training" (Liu et al., February 2025) applied Muon to large language models.

# Examples

>[!example] (Easy) One Step on a Diagonal Gradient
>A $2 \times 2$ layer receives the gradient $\mathbf{G} = \mathrm{diag}(6, -8)$.
>
>>[!example]- Normalize $\mathbf{G}$, apply one cubic Newton-Schulz step, and compare the result with $\mathbf{U}\mathbf{V}^T$.
>>The Frobenius norm is $\sqrt{36 + 64} = 10$, so $\mathbf{X}_0 = \mathrm{diag}(0.6, -0.8)$. Its singular values are $0.6$ and $0.8$. The minus sign belongs to $\mathbf{U} = \mathrm{diag}(1, -1)$, with $\mathbf{V} = \mathbf{I}$, so $\mathbf{U}\mathbf{V}^T = \mathrm{diag}(1, -1)$. For a diagonal matrix, $\mathbf{X}\mathbf{X}^T\mathbf{X}$ cubes each entry, and one step gives
>>$$\mathbf{X}_1 = \tfrac{3}{2}\,\mathrm{diag}(0.6, -0.8) - \tfrac{1}{2}\,\mathrm{diag}(0.216, -0.512) = \mathrm{diag}(0.792, -0.944).$$
>>The signs survive because $p$ is odd. The errors $1 - \sigma$ fell from $0.4$ to $0.208$ and from $0.2$ to $0.056$. Both match $e_{k+1} = \frac{1}{2}e_k^2(3 - e_k)$. The smaller error shrank by the larger factor, as quadratic convergence predicts.

>[!example] (Medium) Orthogonalizing a Non-Symmetric Gradient
>A $2 \times 2$ layer receives the gradient
>$$\mathbf{G} = \begin{bmatrix} 3 & 0 \\ 4 & 5 \end{bmatrix}.$$
>
>>[!example]- Find $\mathbf{U}\mathbf{V}^T$ from the SVD. Then run the cubic iteration from $\mathbf{G}/\|\mathbf{G}\|_F$ and compare.
>>The matrix $\mathbf{G}^T\mathbf{G} = \begin{bmatrix} 25 & 20 \\ 20 & 25 \end{bmatrix}$ has eigenvalues $45$ and $5$, so $\sigma_1 = 3\sqrt{5} \approx 6.708$ and $\sigma_2 = \sqrt{5} \approx 2.236$. Since $(\mathbf{G}^T\mathbf{G})^{-1/2} = \mathbf{V}\boldsymbol{\Sigma}^{-1}\mathbf{V}^T$, the product $\mathbf{G}(\mathbf{G}^T\mathbf{G})^{-1/2}$ equals $\mathbf{U}\mathbf{V}^T$. Here $(\mathbf{G}^T\mathbf{G})^{1/2} = \sqrt{5}\begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix}$, and
>>$$\mathbf{U}\mathbf{V}^T = \frac{1}{\sqrt{5}}\begin{bmatrix} 2 & -1 \\ 1 & 2 \end{bmatrix} \approx \begin{bmatrix} 0.894 & -0.447 \\ 0.447 & 0.894 \end{bmatrix},$$
>>a rotation by $26.6^\circ$. For the iteration, $\|\mathbf{G}\|_F = \sqrt{50}$, so the starting singular values are $0.949$ and $0.316$. The cubic steps give
>>$$\mathbf{X}_1 \approx \begin{bmatrix} 0.530 & -0.085 \\ 0.566 & 0.771 \end{bmatrix}, \quad \mathbf{X}_3 \approx \begin{bmatrix} 0.779 & -0.332 \\ 0.486 & 0.856 \end{bmatrix}, \quad \mathbf{X}_5 \approx \begin{bmatrix} 0.893 & -0.446 \\ 0.448 & 0.894 \end{bmatrix}.$$
>>The larger singular value reaches $1.000$ after two steps. The smaller one goes $0.459$, $0.640$, $0.829$, $0.958$, $0.997$. After five steps no entry differs from $\mathbf{U}\mathbf{V}^T$ by more than $0.002$. Five quintic steps instead give singular values $1.134$ and $0.753$. Neither equals $1$, because $f(1) \neq 1$.

>[!example] (Medium) The Update of a Convolutional Layer
>A convolutional layer has $C_{\text{out}} = 128$ filters of size $64 \times 3 \times 3$. Its gradient has full rank. Muon orthogonalizes it exactly and applies the step $\Delta\mathbf{W} = -\eta\sqrt{d_{\text{out}}/d_{\text{in}}}\,\mathbf{U}\mathbf{V}^T$.
>
>>[!example]- Find the matrix shape Muon sees, and the spectral norm, $\text{RMS}\to\text{RMS}$ norm and RMS entry size of the update.
>>Reshaping gives a $128 \times 576$ matrix, since $d_{\text{in}} = 64 \cdot 9 = 576$. The scale is $\sqrt{128/576} = \sqrt{2}/3 \approx 0.471$. Every nonzero singular value of $\mathbf{U}\mathbf{V}^T$ equals $1$, so $\|\Delta\mathbf{W}\|_2 = 0.471\,\eta$. The $\text{RMS}\to\text{RMS}$ norm multiplies this by $\sqrt{576/128} \approx 2.121$, which gives exactly $\eta$. The matrix $\mathbf{U}\mathbf{V}^T$ has rank $128$, so $\|\mathbf{U}\mathbf{V}^T\|_F = \sqrt{128}$. The RMS entry of the update is therefore
>>$$\frac{0.471\,\eta\,\sqrt{128}}{\sqrt{128 \cdot 576}} = \frac{0.471\,\eta}{24} \approx 0.0196\,\eta.$$
>>A patch with RMS $1$ changes the layer's output RMS by at most $\eta$. A random patch with unit-variance entries changes it by about $0.47\,\eta$. This is smaller because the update acts on only $128$ of the $576$ input directions.

>[!example] (Hard) How Many Steps for a Small Singular Value
>After Frobenius normalization, a $512 \times 512$ momentum buffer has singular values between $0.01$ and $0.5$.
>
>>[!example]- How many cubic steps make every singular value at least $0.9$? How many matrix products is that, and what do five quintic steps give instead?
>>On $[0, 1]$ the cubic is increasing, since $p'(x) = \frac{3}{2}(1 - x^2) \ge 0$. It keeps the singular values in order, so the smallest one arrives last. Starting from $0.01$, the iterates are $0.015$, $0.0225$, $0.0337$, $0.0506$, $0.0758$, $0.114$, $0.170$, $0.252$, $0.370$, $0.529$, $0.720$, $0.893$ and $0.984$. The cubic needs $13$ steps. Pure growth by $1.5$ would need $12$, since $\log 90/\log 1.5 \approx 11.1$, and the $-\frac{1}{2}x^3$ term slows the last steps. At two products per step, that is $26$ products of size $512 \times 512 \times 512$. Five quintic steps take $15$ such products. From $0.01$ they give $0.0344$, $0.118$, $0.400$, $1.093$ and $0.699$. Every starting value in $[0.01, 0.5]$ ends in $[0.68, 1.14]$. The quintic gives a rougher result with about $42\%$ fewer products.
