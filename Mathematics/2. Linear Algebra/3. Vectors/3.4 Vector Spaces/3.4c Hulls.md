>[!note] Hull
>A **hull** of a set of vectors $\mathcal{P}=\{ \vec{v}_{1}, \ldots, \vec{v}_{n} \}$ is some finite set generated by all possible linear combinations of $\mathcal{P}$ under certain constraints (i.e., a finite subset of the [[3.4b Span|span]]):
>- An **affine hull** is the set of all linear combinations of $\mathcal{P}$, such that the coefficients $\alpha_{i}$ sum to one:
>$$\operatorname{aff}(\mathcal{P}) = \left\{  \sum^{n}_{i=1}\alpha_{i}\vec{v}_{i} : \space \sum^{n}_{i=1}\alpha_{i}=1 \right\}.$$
>The affine hull is the smallest **affine set** containing $\mathcal{P}$.
>- A **conic hull** is the set of all linear combinations of $\mathcal{P}$, such that the coefficients are non-negative:
>$$\operatorname{conic}(\mathcal{P}) = \left\{  \sum^{n}_{i=1}\alpha_{i}\vec{v}_{i} : \space \alpha_{i} \geq 0 \right\}.$$
>- A **convex hull** is the set of all linear combinations of $\mathcal{P}$, such that the coefficients are constrained by both sum-to-one and non-negativity:
>$$\operatorname{co}(\mathcal{P}) = \left\{  \sum^{n}_{i=1}\alpha_{i}\vec{v}_{i} : \space \sum^{n}_{i=1}\alpha_{i}=1, \alpha_{i} \geq 0 \right\}.$$
>
>It always holds that $\operatorname{co}(\mathcal{P}) \subset \operatorname{aff}(\mathcal{P})$ and $\operatorname{co}(\mathcal{P}) \subset \operatorname{cone}(\mathcal{P})$. Furthermore, if $\vec{0} \in \mathcal{P}$ (i.e., $\mathcal{P}$ is a subspace), then it holds that $\operatorname{co}(\mathcal{P}) \subset \operatorname{cone}(\mathcal{P}) \subset \operatorname{aff}(\mathcal{P})$:

>\end{scope}

>% Convex Hull: Draw the triangle (blue)
>\draw[thick, blue] (A) -- (B) -- (C) -- cycle;
>\fill[blue, opacity=0.25] (A) -- (B) -- (C) -- cycle;
