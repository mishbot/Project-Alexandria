>[!note] Insertion Sort
>**Insertion sort** is a simple sorting algorithm that works by sequentially traversing a list, while splitting it into two subarrays. As the list is being traversed, the current element (the **key**) is iteratively compared to the element before it, and "exchanges" indices with that element until there are no more elements that are smaller than the key. The Python code of insertion sort is given as
>```python
>def insertionSort(l):  
>    for i in range(1, len(l)):  
>        key = l[i]  
>        j = i
>        while j > 0 and l[j - 1] > key:  
>            l[j], l[j - 1] = l[j - 1], l[j]  
>            j -= 1  
>        l[j] = key  
>    return l
>```
